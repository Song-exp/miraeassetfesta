# 📘 국내채권 작업 전체 — 한 문서로 보기 (2026-08-26 · 08-27 쉬운 말로 다시 씀)

> **이 문서가 하는 일** — 국내채권(`domestic_bonds`) 작업을 08-10 첫 EDA 부터 지금까지 **무엇을 만들었고, 무엇이 바뀌었고, 지금 어디까지 왔는지** 한 장으로 잇는 **지도**다. 자세한 내용은 각 문서로 링크한다. **새로운 사실은 여기에 쓰지 않는다** — 여기는 지도이고, 사실은 원래 문서에 있다.
>
> **급하면 §10 부터 읽어라.** §10 은 "결국 뭐가 확정됐고, 뭐는 사용자에게 되물어야 하고, 뭐는 지금 답을 못 하는가"를 세 갈래로 정리한 결론이다. §0~§9 는 그 결론이 왜 나왔는지의 근거다.
>
> ⚠️ **데이터가 두 판이다 — 가장 먼저 알아야 할 것.**
> - **1차**: 기준일 2026-07-11 · 42,394행 × 40컬럼
> - **2차**: 기준일 2026-08-22 · 21,882행 × 58컬럼
>
> 주최 측이 1차를 "데이터 정합성 문제"로 **폐기**했고, `main` 브랜치는 08-25 에 2차로 갈아탔다. 그런데 **이 저장소의 채권 문서 대부분과 `eda/domestic_bonds` 브랜치의 작업은 1차 데이터로 한 것**이다. 그래서 어떤 숫자를 인용하든 "이거 1차야, 2차야?"를 반드시 확인해야 한다 — §3 참고.

## 용어 먼저 — 이 문서에 자주 나오는 말

| 용어 | 뜻 (이 문서에서 쓰는 의미) |
| :-- | :-- |
| **EDA** | 탐색적 데이터 분석. 데이터를 처음 받아서 "뭐가 들어 있고, 어디가 이상한가"를 훑는 작업 |
| **yaml** (`ontology/enums/domestic_bonds.yaml`) | 우리가 내린 판정·규칙을 적어 둔 **정본 파일**. 챗봇이 쿼리를 만들 때 이 파일의 규칙을 따른다 |
| **PK (기본키)** | 한 행을 유일하게 구분하는 열쇠. 1차는 종목코드(`PD_NO`) 하나였고, 2차는 네 컬럼을 합쳐야 한 행이 정해진다(**복합 PK**) |
| **LOT** | 2차에서 "당사가 파는 조건 한 묶음". 같은 종목이라도 시장·기준일·판매순번이 다르면 다른 LOT(=다른 행) |
| **듀레이션** | 금리가 움직일 때 채권 가격이 얼마나 흔들리는지의 척도(년 단위). 길수록 금리에 민감 |
| **잔존만기** | 기준일부터 만기일까지 남은 기간 |
| **위장결측** | 값이 있어 보이지만 실제론 "없음"을 뜻하는 값. 예: `0`, `99991231`, 다른 컬럼을 그대로 복사한 값 |
| **센티넬** | 위장결측 중 특정 숫자로 "없음"을 표시한 것 (`0`·`99`·`99991231`) |
| **특수구조** | 콜·풋·전환·후순위·영구 같은 **특별한 조건이 붙은 채권**. 일반 채권과 섞어 추천하면 위험해서 기본 제외 |
| **콜(callable)** | 발행사가 만기 전에 갚아버릴 수 있는 권리 · **풋(puttable)** 투자자가 미리 팔 수 있는 권리 · **CB** 주식으로 바꿀 수 있는 전환사채 · **EB** 다른 회사 주식으로 바꾸는 교환사채 · **BW** 신주인수권부사채 · **FRN** 변동금리채 · **코코본드** 은행이 위기 시 상각·전환하는 조건부자본증권 · **AT1** 코코본드 중 가장 후순위인 신종자본증권 · **분리채권(스트립)** 국고채의 이자와 원금을 쪼갠 것 |
| **유동화(ABS·MBS)** | 대출·매출채권 등을 묶어 만든 채권. 발행사 이름만 보면 정체를 알기 어려움 |
| **역질문 (`clarify`)** | 질문이 여러 뜻으로 읽힐 때 **사용자에게 되묻는 것**. 이 공모전에서는 되묻기도 정답으로 채점된다 |
| **무응답 기본값** | 되물었는데 사용자가 답을 안 하면 "이 가정으로 답합니다"라고 밝히고 쓰는 값. 없으면 파이프라인이 멈춘다 |
| **축(axis)** | 채권을 가르는 기준 하나. 예: 이자유형 축, 발행주체 축, 담보 축 |
| **코드북** | "이 값은 이 뜻"을 정리한 대조표. 외부에서 수집한 것은 `data/external/lookups/` 에 있다 |
| **정본** | 숫자가 서로 다를 때 "이걸 믿는다"로 정한 출처 |

## 4. 우리가 만든 분류 체계 — 채권을 어떤 기준으로 가르는가

### 4-① 발행 주체 3층 (원본 컬럼) — 🔴 깔끔한 트리가 아니다

```
STD_PD_MCLS_NM 대분류 6종  →  STD_PD_SCLS_NM 소분류 16종  →  BD_KND 채권종류 39종 (2차: 32종)
```

- 소분류 `일반사채` 가 대분류 **회사채(30,116)와 특수채(842) 양쪽에** 걸려 있다. 즉 소분류만 보고 대분류를 거꾸로 알아낼 수 없다 → **하위에서 상위로 역추적 금지**, `axis_issuerType` 은 대분류 컬럼만 보고 정한다 (구조도 §7.1)
- `BD_KND` 빈칸 924 (2차 152) · 앞뒤 공백 때문에 39종이 51종처럼 보임 → TRIM 필수
- 분리채권 221건은 `BD_KND=국고채권` 으로 묻혀 있어서 종목명 말고는 구분할 방법이 없다

### 4-⑥ 등급 · 위험등급 — 이름이 비슷하지만 **다른 것**

- **신용등급** `CRD_GRD` — "이 회사가 돈을 못 갚을 확률"의 등급(AAA~D). `AA0` 처럼 뒤에 0이 붙은 표기를 `AA` 로 정규화해야 한다. 1차에는 평가사별 `PD_EVCO_CRD_GRD`(표기가 100종) 를 합치는 문제가 있었는데 2차에서 그 컬럼이 삭제돼 사라졌다. 국공채·사모는 **등급이 없는 게 정상**이다 (`not_applicable`) — 빈칸이라고 "정보 부족"이 아님.
- **위험등급** `PD_RISK_GCD` — 금융회사가 상품에 매기는 1~6등급. **숫자가 낮을수록 위험** (1=매우높은위험 … 6=매우낮은위험). 1차 때는 🔸 추정이었으나 08-26 에 ✅ 확정 (ETF·펀드의 이름 컬럼 실물 + `zeroin_methodology.md` + 국공채 2,137건이 전부 6). 2차는 `pd_risk_nm` 이 등급 이름을 직접 준다. 🔴 **그런데 런타임 코드에는 아직 이 방향 규칙이 없다** → `additional_bonds.md` F-2-10.
- 두 등급은 **다른 축이다** — 위험등급 1(최고위험)인데 신용등급 AAA 인 것이 498건 있다. 신용은 최고지만 만기가 길어 **금리위험**이 크면 위험등급은 높게 나온다.

### 4-⑦ 결측 7유형 (노트 §B.2) — "빈칸이라고 다 같은 빈칸이 아니다"

① 구조적으로 없는 것(국채의 신용등급) ② 상태 표현(호가 없음 = 안 파는 중) ③ 아직 계산 안 됨 ④ 다른 컬럼에서 복구 가능 ⑤ 센티넬 위장(`0`·`99`·`99991231`) ⑥ 복사 위장(`DIRTY=EVAL_PRICE` 처럼 다른 컬럼 값을 그대로 복사) ⑦ 정상값인데 빈칸처럼 보이는 것(`SRFC_IRT=0` — 할인채·CB 는 표면금리 0 이 맞음).

판정 순서는 ⑦→⑤⑥→④→①②③. `IS NULL` 만 세면 ⑤⑥⑦을 놓친다.

### 4-⑧ 역질문 (`clarify`) — 되묻기는 유효한 답변

- 3단 기준(노트 §I.2): ① 데이터만으로 결정 가능 → 그냥 답한다 ② 합리적 기본값이 있음 → 기본값으로 답하고 "이 가정입니다"라고 밝힌다 ③ 뜻이 갈리거나 다의어 → 되묻는다
- 10종 확정 + 무응답 기본값 전건 (B9) — 기본값을 **금지**한 건 '싸다' 1종뿐. 2차에 '가격' 추가 → 11종
- 08-26 신규 후보 2종 (#11 발행사_단위 · #12 투자기구_포함) + **되묻기 전 모수 검사** 규칙 → `additional_bonds.md` K-7
- 자세한 목록은 §10-B
