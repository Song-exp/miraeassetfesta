## 2. 실행 계획 — 4단계

### P0 · 조인 키 검증 + ① 마감 해소 (8/18–19, 반나절) 🔴 최우선

1. **키 검증**: 마스터 예탁원 대표번호 10건으로 상세 페이지 조회 성공률 확인.
   실패 시 펀드명 검색 API 응답의 코드 체계 역추적으로 대체 키 확보.
2. **① 운용사·수탁사**: 기존 계획대로 종목명 접두 최빈 브랜드 유도(내부, `source: rule`)
   → 코드당 당사취급 대표 종목 1건씩 페이지 조회해 **운용사·수탁사 법인명 채집** (67+18건 = 페이지 ~85회)
   → 유도 브랜드와 대조해 `source: miraeasset_web` 으로 승격. **8/19 `organization.yaml` 마감 충족.**
   - 이 경로면 "80% 유도 + 추정 딱지"가 아니라 **전 코드 법인명 확정**까지 갑니다.

### P1 · 상세 페이지 크롤 (8/19–21)

- **범위**: 1차 = 판매중 × 당사취급 (질의 노출 최대 집단). 2차 = 당사취급 전체 (~10,444종목).
- **수집 필드**: 설정일⑤ · 총보수④ · 추가형/단위형·개방/폐쇄⑥⑬ · 펀드유형 표시 · 문서 PDF URL.
- **코드 검증 세트** (전량 크롤 전에 표본으로 먼저):
  `fd_set_pcd='20'` 20건(⑬) · `pfiv_sale_cntl_tcd` 66건 전수(Q2) · `or_attr_desc='06'` 30건(Q3).
- 예의: 요청 간격 1~2초 · UA 명시 · 실패 재시도 1회. 10k건 ≈ 4~6시간, 야간 배치 1회면 충분.

### P2 · 투자설명서 PDF 수집 → 파싱 (8/21–26)

- P1에서 채집한 문서 URL로 **작성기준일 ≤ 7/11 판** 우선 다운로드.
- 파싱 산출물 (필수 구성요소 1번 `[Parsing]` 소스코드 채점 동시 충족⑦):
  - **모자 구조 서술 → 자펀드↔모펀드 매핑③ + M109 가설 검증⑧** (M109 보유/미보유 각 15건 대조)
  - 환매 조건 → ⑥ 보강 · 보수 상세 → ④ 확정판 · 가입자격 → Q2 교차 확인
- 우선 파싱 대상: 예시 질의 직결 펀드(국민성장펀드 등) → 순자산 상위 → 나머지.
- 부수: funddoctor/제로인 공개 페이지에서 ⑮ 방법론 문서 확인.

### P3 · 시계열·비(非)미래에셋 출처 (8/22–, P1·P2와 병행 가능)

| 작업 | 출처 | 닫는 항목 |
| :--- | :--- | :--- |
| 7/10 기준일 순자산 조회 (0값 294종목) | 금투협 펀드다모아·전자공시 (기준일 지정 조회) | ⑰ Q5 |
| `kofia_fd_ccd` 자리 정의서 | 금투협 자율규제 공시 규정 별표 | ⑪ |
| Holdings — **모펀드 단위** | 자산운용보고서 (금투협 전자공시 `dis.kofia.or.kr`), ③의 매핑이 전제 | ②③ |
| 지수 마스터 (복합식 파싱 선행) | MSCI·FnGuide·KIS·KAP 공개 목록 | ⑭ |

### P4 · 종결 처리 (8/27–)

- ⑨ → 역설계 규칙 + `evidence_grade: C` 확정. ⑰ Q1 → 미확정 확정. Q4 → 정책 반영.
- ⑯ 금감원 원부 → 기존 결론대로 `unresolved` 확정 (착수 안 함).
- ⑩ 테마 시계열 → 전 단계 완료 후 잔여 시간으로만 판단.
- 결과를 `ontology/enums/public_funds.yaml` (`value_semantics`·`missing_profile`) 및 값 사전에 역반영.
