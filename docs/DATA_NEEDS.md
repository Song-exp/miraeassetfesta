### ⑨ `axis_classDifferentiation` 축의 정의 — 주최 측 요청 필요

주최 측 정답 샘플(`PRFD01N001_..._schema.xlsx` `Sheet2_Sample` 100건)에서 이 축이
**같은 펀드 안에서 값이 갈립니다** (40묶음 중 9개):

```
코레이트셀렉트단기채증권투자신탁[채권] C      → SingleClass
코레이트셀렉트단기채증권투자신탁[채권] C-F    → MultiClass
```

*"이 펀드가 다클래스인가"* 라는 뜻이면 도메인상 성립할 수 없습니다(같은 펀드가 동시에

정확도 88%짜리 규칙이 나오는데, 근거가 라벨 노이즈일 가능성이 있습니다.

### ⑬ `fd_set_pcd` · `pfiv_sale_cntl_tcd` 코드값 정의 — ⑰ Q1·Q2 와 동일 출처

⑰에서 질문으로 묶었으나, 정식 코드표를 받으면 다음이 함께 확정됩니다.

```
fd_set_pcd '20' = 단위형   현재 B(조건부) — 정답 100건 표본이 1건뿐이라 단독 판정 불가
                           보조 근거: 부동산펀드 전량(임대형 15/15·대출형 2/2) · 이름의 목표전환형·N년만기
                           → 표본이 확대되면 B → A
```

**대안 경로**: 주최 측 정답 라벨(`Sheet2_Sample`)의 **표본 확대 요청**. `axis_issuanceType` 의
`'20'` 사례가 1건뿐이어서 판정이 막혀 있습니다 — 코드표 대신 라벨 20~30건이면 충분합니다.
