## 8. 이 세션에서 **되돌린** 것 (반복하지 말 것)

**H2 처방 — `종목단위` 문장 한정.** 리드 지시대로 트리거로 내리지 않고 문장을 자기 범위로 한정해 봤다:

```
종목단위: 개별 조회는 행 = itm_no (클래스 단위). 개수·집계·랭킹은 `펀드단위` 규칙을 따른다.
```

개별 조회 21문항은 통과(결과집합 20/21 동일)였는데 **개수 문항에서 불합격**했다. `KG-025` 가 깨졌고 **양쪽 3회씩 재실행해 3/3 재현**이다:

| | ETF 가지 운용사 필터 | 답변 |
| :-- | :-- | :-- |
| before | 3/3 유지 | 공모펀드 207 · 국내 ETF **240** |
| after | 3/3 소실 | 공모펀드 207 · 국내 ETF **1,160** ← 전체 (삼성은 265) |

펀드 축은 양쪽 다 맞고, 무너진 것은 **UNION 의 다른 가지**다. 펀드 규칙 문장을 늘리자 ETF 가지에서 운용사 조건이 사라졌다. → **되돌렸다.** 모순은 P0-2a 슬롯이 축을 닫는 쪽으로 처리했고, 두 규칙은 여전히 동시 always_on 이다.

교훈: **규칙 문장 한 줄을 늘리는 것도 부작용이 있다.** H3 기각과 같은 방향의 증거다.

## 9. 🔴 함정 기록 — 다음 사람을 위해

### 9-1. 코드·설정

| # | 함정 | 증상 |
| :-: | :-- | :-- |
| ① | `load_context()` 는 `@lru_cache(maxsize=1)` | 두 번 불러도 **같은 객체**다. A/B 비교에서 한쪽만 덮으면 양쪽이 바뀌는데 **에러가 아니라 "블록 크기가 정확히 같다"** 는 그럴듯한 숫자가 나온다. 조건별 컨텍스트는 반드시 `copy.deepcopy` |
| ② | YAML 1.1 에서 `off`·`on`·`yes`·`no` 는 **불리언** | 슬롯을 `off: true` 로 끄면 딕셔너리에 `False` 키가 생기고 `.get("off")` 가 영원히 `None` — 슬롯이 안 꺼진다. 키는 `enabled: false` |
| ③ | `planner_context` 가 dict 규칙을 통째로 덤프했다 | `enforce` 를 붙이면 `when`·`action`·`sql`·`mark` 가 프롬프트로 샌다. `text` 만 싣도록 고쳤다(`loader.py`) — 절차 산출물 목록에 없던 항목 |
| ④ | 슬롯 `when.tables` 를 **라우팅 테이블**로 판정하면 안 된다 | `public_funds` 가 SQL 에 없는 holdings 조인 질의에 `sale_yn` 을 주입해 깨뜨린다. 라우팅은 "질문이 어디를 향하는가", 슬롯은 "이 SQL 이 무엇을 읽는가" — 다른 축. `guard.sql_tables(가지별)` 로 본다 |
| ⑤ | UNION 가지에서 **열 수를 바꾸면** SQL 이 죽는다 | `COUNT(*)` → 두 컬럼 치환이 양쪽 SELECT 열 수를 어긋내 실행 불가. `sql_union`(열 수 보존판)을 선언하고 없으면 불개입 |
| ⑥ | `replace_expr` 의 `from` 은 리터럴이라 **별칭을 못 먹는다** | `COUNT(*) AS 개수` 에서 별칭이 남아 `AS "펀드수" AS 개수` 로 문법이 깨진다. `from_pattern`(정규식)을 쓴다 |
| ⑦ | 슬롯과 코드 가드가 **다른 확정식**을 쓰면 영원히 갈린다 | 펀드키에서 `printf('%08d', …)` 정규화가 빠져 있었다(운용사 코드 7·8자 혼재). 정의는 `guard.FUND_KEY_EXPR` **한 곳** |

## 11. 판단 규칙 (이 트랙에서 굳은 것)

1. **회귀는 결과집합으로 본다.** SQL 문자열 diff 는 HCX 비결정성 노이즈다.
2. **"실행 가능한가" 와 "실행됐는가" 는 다르다.** trace 의 `[Execute]` 가 근거다.
3. **이득은 운영 형상으로 보고한다.** 가드를 뺀 실험값은 회귀 검출용이다.
4. **슬롯이 발동했는지는 표식(`/*M:mark*/`)으로 귀속한다.** 추측하지 않는다.
5. **가드를 먼저 지우지 않는다.** 슬롯 점등 → 침묵 확인 → 두 라운드 후 삭제.
6. **규칙 문장을 늘리는 것도 개입이다.** §8 의 H2 가 그 실례다.
7. **문항별 분기를 만들지 않는다.** 부류 단위 매핑 하나로 쓸 수 없으면 그 처방은 틀렸다.
