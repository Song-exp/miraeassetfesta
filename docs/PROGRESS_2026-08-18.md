## 4. 🔴 수집 데이터의 git 취급 — public 저장소 주의

**이 저장소는 public입니다** (2026-08-18 GitHub API 확인). 수집 데이터는 push하지 않습니다:

| 대상 | 크기 | push | 이유 |
| :-- | :-- | :-: | :-- |
| `data/external/miraeasset_web/raw/` (HTML 원본) | 305MB | ❌ | 미래에셋증권 웹 콘텐츠 재배포 — 저작권·약관 리스크 + 용량 |
| `prospectus/` (PDF 186개) | 119MB | ❌ | 공시 문서라도 public 재배포 부적절 + 용량 |
| `fund_pages_full.csv` 등 파생 CSV | ~27MB | ❌ | **주최측 마스터에서 조인된 컬럼(펀드명·코드 등) 포함** — 대회 제공 데이터의 public 재배포가 됨 |
| 코드북(`ontology/codebooks/*.csv`) | KB | ✅ | 코드↔이름 매핑(공개 사실)만 — 기존 예외 규정 유지 |
| 코드·문서·yaml·ttl·노트북 | KB | ✅ | 정상 커밋 대상 |

- `.gitignore`가 이미 `data/`·`*.csv`를 막고 있어 **그대로 커밋하면 데이터는 자동 제외**됩니다. 예외 해제하지 말 것.
- **팀 공유가 필요하면**: 파생 CSV 4개(fund_pages_full·holdings_full·mo_fund_map·audit)만 비공개 채널(NCP Object Storage·드라이브)로. 최종 제출 시에도 대용량은 "클라우드 스토리지 다운로드 링크" 규정(PROJECT.md §2).
- **재현 경로**: `python scripts/crawl_miraeasset_full.py` (153분, 캐시 재개 가능) → `python scripts/load_external_web.py`.
