## 1. 🔴 `dom_ticker` 승인 — 제일 급함

**㉡ 이 들어갔는데도 국내ETF 구성종목은 여전히 못 붙음.**

`gen_security_auto.py` 가 국내 구성종목을 이렇게 가름:

```python
if re.fullmatch(r"\d{6}", tk):   nid = f"Sec_kr_{tk}"      # CSV kr_ticker 로 붙음
else:                            nid = f"Sec_d_{sha(tk)}"  # 🔴 CSV 에 붙일 키가 없음
```

**103종 중 6자리 한국 티커가 0종임.** 전부 국내 ETF 가 담은 외국주식이라
`2015 HK` · `LI US` · `300308 C2` 같은 **블룸버그식**이라서.

| 갈래 | 종수 | 국내ETF 연결 |
| :-- | --: | --: |
| **ⓐ 블룸버그 티커 있음** | **11** | **102건** |
| ⓑ 티커 아예 없음 | 92 | 111건 (각 1~3개뿐 → **보류 제안**) |

**ⓐ 11종이 실질 전부임** — 종수는 11%인데 끊긴 연결의 절반이 여기 몰려 있음.
Zhongji Innolight 16개 · Li Auto 16개 · BeOne 13개 · Midea 11개 · WuXi 10개.

**수정 범위는 2줄**임 (`gen_security_auto.py` 169행 근처, 기존 `kr_ticker` 처리 옆):

```python
for dt in (r.get("dom_ticker") or "").split("|"):
    if dt.strip(): targets.append(f"Sec_d_{sha(dt.strip())}")
```

CSV 에 `dom_ticker` 열 추가. **빈 값이면 무동작이라 기존 18행에 영향 없음.**

11종 식별자 조사는 끝나 있음 → [`kg_dom_ticker_11_2026-08-30.md`](kg_dom_ticker_11_2026-08-30.md)

> **❓ 생성기를 내가 건드려도 되는지.** 리드가 *"생성기 안 건드림이 깨지는 지점"* 이라 표시해 두셔서 여쭤봄.
