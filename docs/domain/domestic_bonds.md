## 1. 채권이란 무엇인가

### 1.1 한 문장

📖 **채권(債券)** 은 *"돈을 빌리면서 써준 차용증인데, 그 차용증 자체를 시장에서 사고팔 수 있게 만든 것"* 입니다.

핵심은 **"사고팔 수 있다"** 는 점입니다. 이것 하나가 채권의 모든 성질을 만들어냅니다.

- 차용증이니까 → **갚을 날(만기)과 이자율이 처음부터 정해져** 있습니다
- 사고팔 수 있으니까 → **시장 가격이 따로 생깁니다.** 그리고 이 가격은 액면과 다릅니다
- 빌려준 상대가 망할 수 있으니까 → **신용등급**이 필요합니다

### 1.2 은행 예금과 무엇이 다른가

📖 예금도 "내가 은행에 돈을 빌려주는 것"입니다. 채권과의 결정적 차이는 **중간에 남에게 넘길 수 있느냐**입니다.

| | 예금 | 채권 |
| :--- | :--- | :--- |
| 돈을 빌리는 쪽 | 은행 | 정부·공기업·기업 등 **누구나** |
| 중도에 남에게 팔기 | ❌ 불가 (해지만 가능, 이자 손해) | ✅ **가능** |
| 중간 가격 | 없음 | **매일 변함** |
| 원금 보장 | 5천만원까지 예금자보호 | ❌ **없음.** 발행자가 망하면 못 받음 |
| 이자율 | 가입 시점에 고정 | 표면금리는 고정, **시장 수익률은 매일 변함** |

> 🔑 **"중간 가격이 매일 변한다"** — 이게 채권 데이터에 가격 컬럼과 수익률 컬럼이
> 잔뜩 들어 있는 이유입니다. 예금이라면 필요 없는 정보입니다.

### 1.3 주식과 무엇이 다른가

📖

| | 주식 | 채권 |
| :--- | :--- | :--- |
| 법적 지위 | 회사의 **주인(지분)** | 회사에 대한 **채권자(빚)** |
| 받는 것 | 배당 — 회사가 벌어야 줌 | **이자 — 벌든 못 벌든 약속대로** |
| 만기 | 없음 (영구) | **있음** — 그날 원금 받고 소멸 |
| 회사 파산 시 순서 | **맨 마지막** (보통 0원) | 주주보다 **먼저** 받음 |
| 최대 수익 | 무제한 | **정해져 있음** (약속된 이자 + 원금) |
| 최대 손실 | 투자금 전액 | 투자금 전액 (발행자 부도 시) |

> 📖 **채권은 "안전한 대신 수익이 정해진" 상품입니다.**
> 이 성격 때문에 개인 투자자에게는 *"예금보다 조금 더 주는 것"*, 기관에게는
> *"자산의 안정적인 축"* 으로 팔립니다. 미래에셋 같은 증권사가 개인에게 채권을 파는
> 이유도 이겁니다.

### 1.4 발행시장과 유통시장 ★

📖 채권에는 **인생 두 단계**가 있습니다. 이걸 구분 못 하면 데이터가 안 읽힙니다.

```
 ① 발행시장 (Primary)                    ② 유통시장 (Secondary)
 ─────────────────────                   ──────────────────────
 발행자가 돈을 빌리는 순간                   이미 발행된 채권을 투자자끼리 사고팜
                                          
 삼성카드 ──[채권 발행]──> 최초 투자자   →   투자자 A ──[매매]──> 투자자 B
           5,000억 조달                        가격은 시장이 결정
                                          
 이때 정해지는 것:                          이때 정해지는 것:
   · 액면가 (10,000원)                       · 시장가격 (EVAL_PRICE)
   · 표면금리 (SRFC_IRT)                     · 시장수익률 (APPLIED_YIELD)
   · 만기일 (MAT_DT)                         · 매수 가능 여부 (BUY_YIELD)
   · 발행일 (ISU_DT)                        
   → 한 번 정해지면 안 바뀜                   → 매일 바뀜
```

> 🔑 **이 테이블 40컬럼은 이 두 그룹으로 갈립니다.**
> **발행 조건**(`SRFC_IRT` `MAT_DT` `ISU_DT` `ISU_BAL_AMT`)은 결측이 거의 0%인데,
> **유통 정보**(`BUY_YIELD` 계열)는 결측이 97.9%입니다.
> 전자는 채권이 존재하면 반드시 있는 값이고, 후자는 **"지금 실제로 거래되고 있는가"** 에 달렸기 때문입니다.

### 1.5 액면가 — 모든 계산의 기준

📖 **액면가(Face Value)** 는 만기에 돌려받기로 약속된 원금입니다. 📊 **한국 채권은 관행적으로 10,000원**이고, 이 데이터에도 액면가 컬럼은 따로 없습니다.

그래서 채권의 모든 숫자는 **"액면 10,000원짜리 한 장 기준"** 으로 읽습니다.

```
표면금리 3.0%  →  매년 300원씩 이자를 준다
평가가격 9,800원 →  지금 시장에서 9,800원에 거래된다 (액면보다 싸게 = 할인)
평가가격 10,300원 → 액면보다 비싸게 거래된다 (= 할증)
```

📊 이 데이터의 `EVAL_PRICE`도 이 기준입니다. 예를 들어 `7252.44` 는 *"액면 10,000원짜리가 지금 7,252원"* 이라는 뜻입니다.

> ⚠️ **실제로 얼마어치 살 수 있는지는 다른 문제입니다.** 채권은 보통 최소 매수 단위가 있고
> (액면 1,000만원 등), 그 정보는 이 데이터에 없습니다. `BUYABLE_QUANTITY`(매수가능수량)만 있습니다.

## 2. 채권의 4대 요소 — 이것만 알면 절반

📖 채권 하나를 이해한다는 건 아래 네 가지를 아는 것입니다. 📊 실제 데이터로 봅시다.

```sql
SELECT * FROM domestic_bonds WHERE TRIM(PD_NO) = 'KR103502GB33';
```

| 요소 | 질문 | 이 채권 | 컬럼 |
| :--- | :--- | :--- | :--- |
| **누가** | 누가 돈을 빌렸나 | 대한민국 | `PD_PBCM` |
| **얼마나** | 이자를 얼마 주나 | 연 1.875% | `SRFC_IRT` |
| **언제까지** | 언제 갚나 | 2051-03-10 | `MAT_DT` |
| **얼마어치** | 이 종목이 시장에 얼마나 풀렸나 | 46.97조원 | `ISU_BAL_AMT` |

### 2.1 누가 — 발행자 (`PD_PBCM`)

📖 **채권의 위험은 거의 전부 "누가 빌렸느냐"에서 나옵니다.** 대한민국 정부가 빌린 돈은 떼일 일이 없고, 신생 중소기업이 빌린 돈은 떼일 수 있습니다.

📊 이 데이터에는 **발행사가 8,018개** 있습니다. 상위 발행사:

| 발행사 | 종목 수 | 성격 |
| :--- | ---: | :--- |
| 한국주택금융공사 | 2,384 | 공기업 — MBS 대량 발행 |
| 한국산업은행 | 1,076 | 국책은행 |
| (주)중소기업은행 | 720 | 국책은행 (IBK) |
| 하나캐피탈(주) | 541 | 캐피탈사 |
| **대한민국** | **535** | 정부 — 국고채 등 |
| 한국토지주택공사 | 534 | 공기업 (LH) |
| 현대캐피탈(주) | 514 | 캐피탈사 |
| 한국전력공사(주) | 511 | 공기업 |

> 📊 **캐피탈사·카드사가 상위에 많습니다.** 이들은 고객에게 할부·카드대금을 빌려주기 위해
> 스스로 돈을 조달해야 해서, **채권을 매우 자주 발행**합니다. 회사 규모 대비 종목 수가 많은 이유입니다.
>
> 📖 카드사는 **오늘 가맹점에 대신 돈을 내주고 다음 달에 고객한테 받고**, 캐피탈사는 **오늘 할부금 전액을
> 내주고 3년에 걸쳐 받습니다.** 그 시차 동안의 돈이 필요한데 은행이 아니라 예금을 받을 수 없으니,
> 채권을 발행해 조달합니다. **남에게 빌려주기 위해 자기가 먼저 빌리는** 구조입니다.
> 게다가 자금 수요가 매달 새로 생기고, 할부 기간이 제각각이라 **만기를 맞춰** 계속 찍어야 합니다.
> 한전·LH처럼 *"가끔 크게"* 가 아니라 **"자주 조금씩"** 빌리는 것입니다.

> 🔑 **종목 수는 "빌린 금액"이 아니라 "빌린 횟수"입니다.**
> 📊 대한민국 535종목 < 하나캐피탈 541종목 — 정부가 비교할 수 없이 큰데 종목 수는 더 적습니다.
> **이 표를 발행사 규모 순위로 읽으면 안 됩니다.** 규모는 `ISU_BAL_AMT`(발행잔액, §2.4)로 봐야 합니다.

> ⚠️ 발행사명 표기가 제각각입니다 — `(주)신한은행` / `하이트진로(주)` / `대한민국`.
> `(주)` 위치가 앞뒤로 다르고, ETF 테이블의 운용사 표기(`삼성`, `미래에셋` 같은 약칭)와도 다릅니다.

### 2.2 얼마나 — 표면금리 (`SRFC_IRT`)

📖 **표면금리(쿠폰금리)** 는 액면가 대비 **매년 지급하기로 약속한 이자율**입니다. 발행할 때 정해지고 **만기까지 안 바뀝니다.**

```
표면금리 3.0%, 액면 10,000원  →  매년 300원
```

📊 분포:

| 구간 | 건수 | |
| :--- | ---: | :--- |
| **0% (할인채)** | 2,758 | 이자를 안 줌 — §3.2 |
| 0~2% | 3,050 | 저금리 시기 발행분 |
| 2~3% | 8,158 | |
| **3~4%** | **10,984** | 가장 많음 |
| 4~5% | 7,744 | |
| 5~7% | 7,048 | |
| 7~10% | 1,981 | |
| 10% 초과 | 671 | 고위험 또는 특수구조 |

> 📖 **표면금리는 발행 당시의 시장금리를 반영합니다.** 2021년(초저금리)에 발행된 국고채는
> 1.875%이고, 2023년(고금리)에 발행된 회사채는 5%대입니다.
> **표면금리가 낮다고 나쁜 채권이 아닙니다** — 발행 시기가 다를 뿐입니다.

> 🔑 **표면금리 ≠ 내가 실제로 버는 수익률.** 이게 §4의 주제입니다.

### 2.3 언제까지 — 만기 (`MAT_DT`, `REMAINING_DAYS`)

📖 **만기일에 원금을 돌려받고 채권은 소멸합니다.** 그 이후로는 존재하지 않습니다.

📊 잔존만기 분포:

| 잔존만기 | 건수 |
| :--- | ---: |
| **0 (이미 만기 도래)** | **7,805** |
| 1년 이하 | 6,783 |
| **1~3년** | **9,899** |
| 3~5년 | 3,908 |
| 5~10년 | 1,419 |
| 10년 초과 | 1,935 |

> 📖 **만기가 길수록 위험합니다.** 돈이 오래 묶이고, 그동안 금리가 어떻게 변할지 모르고,
> 발행자가 망할 확률도 누적됩니다. 그래서 보통 **만기가 길수록 금리를 더 줍니다.**

> 🔴 📊 **이 데이터에는 이미 만기가 지난 채권이 16,180건(38.2%) 남아 있습니다.**
>
> 📖 **채권 자체는 소멸했지만, 마스터가 이력으로 보관하는 것은 실무상 흔합니다.** 오류가 아닙니다.
> 📊 실제로 **발행사 8,015개 중 2,291개(28.6%)와 채권종류 2종(`재정증권` `투자일임회사채`)은
> 만기 도래분에만 존재**합니다. 지우면 *"엠캐피탈 채권 알려줘"* 에 답할 수 없게 됩니다.
>
> 🔑 **문제는 "존재한다"가 아니라 "구분 없이 섞여 있다"는 점입니다.**
> *"지금 살 수 있는 채권"* 에는 나오면 안 되고, *"2020년 발행 채권은 표면금리가 어땠나"* 에는
> **반드시 있어야** 합니다 (📊 2020년 발행분의 **61.8%가 이미 만기 도래**).
>
> **→ 삭제가 아니라 상태 플래그로 구분** — 4상태 분할과 질의별 정책은 `docs/eda/domestic_bonds_notes.md` §D.1.

> ⚠️ 📊 **기준일이 불확실합니다.** 데이터 내부 증거(`PD_STD_INFO_UPDATE` 최댓값 · 잔존일수 역산)는
> **2026-02-24** 를 가리키는데 EDA 노트는 **2026-07-11** 을 씁니다. 만기 도래 건수가 **16,180 vs 11,940** 으로 갈립니다.

### 2.4 얼마어치 — 발행잔액 (`ISU_BAL_AMT`)

📖 **이 종목이 시장에 풀려 있는 총액**입니다. 원 단위.

📊 최대는 국고채권 01875-5103의 **46.97조원**입니다. 국채는 한 종목을 여러 번에 걸쳐 대량 발행하기 때문입니다.

> 📖 **발행잔액이 크면 유동성이 좋습니다.** 많이 풀려 있으니 사고팔 상대를 찾기 쉽습니다.
> 반대로 소량 발행된 회사채는 **팔고 싶을 때 못 파는** 상황이 생깁니다.
> 채권 투자에서 "유동성 위험"이라고 부르는 것입니다.

## 3. 이자를 어떻게 주는가 — 3가지 방식 ★

📖 채권은 이자 지급 방식에 따라 **3종류**로 나뉩니다. 한국 채권 실무의 기본 분류이고, **주최 측 `axis_couponType` 축이 바로 이것**입니다.

### 3.1 이표채 (Coupon Bond) — 가장 흔함

📖 **정해진 주기마다 이자를 나눠 주고, 만기에 원금을 주는** 방식입니다. "이표(利票)"는 옛날에 채권 증서에 붙어 있던 **이자 쿠폰을 잘라서 받으러 가던** 데서 온 말입니다.

```
발행 ─── 3개월 ─── 3개월 ─── 3개월 ─── … ─── 만기
        ↓이자      ↓이자      ↓이자              ↓이자 + 원금 10,000원
        75원       75원       75원
        (표면금리 3% ÷ 4회)
```

📖 한국은 **회사채는 3개월마다, 국고채는 6개월마다** 주는 게 일반적입니다.

> ⚠️ **이 데이터에는 이자 지급 주기 컬럼이 없습니다.** 표면금리는 있지만
> "3개월마다인지 6개월마다인지"는 알 수 없습니다. → §10

### 3.2 할인채 (Zero-Coupon Bond) — 이자를 안 줌

📖 **이자를 한 푼도 안 주는 대신, 액면가보다 싸게 파는** 방식입니다. 차액이 곧 이자입니다.

```
9,700원에 사서 → (이자 없음) → 1년 뒤 10,000원 받음
                                 = 300원 벌었으니 실질 약 3.1%
```

📊 **`SRFC_IRT = 0` 인 것이 2,758건 있습니다.** 🔴 **그런데 이게 전부 할인채는 아닙니다** — 아래 참조.

> 🔑 **표면금리 0%를 "이자를 안 주는 나쁜 채권"으로 읽으면 안 됩니다.**
> *"표면금리가 가장 낮은 채권"* 질의에 할인채 2,758건이 공동 1위로 나오면 오답입니다.
> 할인채는 **가격에 이자가 이미 반영**돼 있습니다.
> 📖 주최 측 축에서 `ZeroCoupon` 으로 따로 분류하는 이유입니다.

> 🔴 **`SRFC_IRT = 0` 을 그대로 할인채로 판정하면 절반 이상이 틀립니다.**
>
> 📊 2,758건의 실제 정체 (종목명 기준, 일부 중복):
>
> | 정체 | 건수 | 비율 |
> | :--- | ---: | ---: |
> | 🔴 **전환사채(CB)** | **1,468** | **53.2%** |
> | 신종자본증권·후순위 | 38 | 1.4% |
> | 변동금리(FRN) | 24 | 0.9% |
> | 그 외 (국민주택2종 등) | 1,253 | 45.4% |
> | 🔴 **통화안정증권** | **0** | **0.0%** |
>
> 📖 **CB의 표면금리 0은 "할인채라서"가 아니라 주식 전환권을 주는 대신 이자를 안 주는 것**입니다 (§6.4).
> 성격이 완전히 다르므로 `ZeroCoupon` 으로 묶으면 오답입니다 — 샘플 정답에도 `ConvertibleCoupon` 이 따로 있습니다.
>
> ⚠️ **[정정] 당초 이 절은 *"통화안정증권과 단기 회사채에 많다"* 고 적었으나, 통안채는 `SRFC_IRT = 0` 이 0건입니다.**

> 🔴 📊 **종목명에 `할인`이 들어간 172건 중 `SRFC_IRT = 0` 인 것은 0건입니다.**
> 이름이 할인채라고 말하는데 표면금리는 0이 아닙니다 — **"표면금리 0 = 할인채" 규칙과 정면으로 어긋납니다.**
> 이 172건의 정체는 **미확인**입니다. `axis_couponType` 규칙을 세우기 전에 반드시 확인해야 합니다.

### 3.3 복리채 (Compound Bond)

📖 **이자를 중간에 안 주고 재투자해서, 만기에 원금+누적이자를 한꺼번에** 주는 방식입니다.

📊 대표적인 게 **국민주택채권**입니다. 집을 사거나 등기할 때 의무적으로 사야 하는 채권으로, 📊 `국민주택1종채권 20-01` 같은 이름에 표면금리 1.0%입니다. 5년 만기 복리로 굴러갑니다.

| 방식 | 중간 이자 | 만기 수령액 | 📊 이 데이터 |
| :--- | :--- | :--- | :--- |
| **이표채** | 있음 (3·6개월) | 원금만 | 대부분 |
| **할인채** | 없음 | 원금 (싸게 샀음) | `SRFC_IRT=0` 2,758건 |
| **복리채** | 없음 | 원금 + 누적이자 | 국민주택채권 등 |

> ⚠️ **이 데이터에는 이 3분류를 직접 담은 컬럼이 없습니다.**
> 표면금리 0 여부와 종목명(`할인` 172건 · `복리` 8건 · `이표` 437건)으로 **추정해야** 합니다.
> → `axis_couponType` 유도가 어려운 이유입니다.

### 3.4 고정금리 vs 변동금리

📖 위 3종과 별개로, **표면금리 자체가 변하는** 채권이 있습니다.

- **고정금리** — 표면금리가 만기까지 그대로. 대부분이 여기
- **변동금리(FRN, Floating Rate Note)** — *"CD금리 + 1.5%"* 처럼 시장금리에 연동돼 주기적으로 바뀜

📊 종목명에 **`변`** 이 붙은 것이 **643건**입니다. 그런데 **표기가 네 갈래 이상으로 흩어져 있어**, 하나만 잡으면 대부분을 놓칩니다.

| 표기 | 📊 건수 | 예시 |
| :--- | ---: | :--- |
| `(변)` | 271 | `한국철도공사220(변)` |
| `(콜/변)` | 232 | `신한은행 15-08 이15-A(콜/변)` |
| `(변동)` `(K변동)` | 29 | `농업금융채권(은행) 2025-12이1Y-A(변동)` — **농협만 쓰는 표기** |
| 그 외 | 111 | `(변/콜)` `(사모/콜/변/후)` `산업금융채권 25변이0100-…` `하나은행…KOFR-변` |
| **합계** | **643** | |

> ⚠️ 📊 **`PD_NM LIKE '%변%'` 은 644건인데 1건은 오탐입니다** — `대전천변고속도로5`(川邊).
> 판정 규칙에 `천변` 제외가 필요합니다.

> 🔴 **`(변)` 만 찾으면 271건, 즉 42%만 잡힙니다.** 네 표기를 모두 커버해야 합니다.
> 📖 `산업금융채권 25변이0100-1104-1M` 처럼 **괄호 없이 `변이`(변동금리 이표채) 로 쓰는 산금채**,
> `하나은행48-07이1갑-21KOFR-변` 처럼 **연동 기준금리(KOFR)를 이름에 박아둔 것**도 있습니다.

> ✅ **`SRFC_IRT`에 무엇이 들어 있나 — "기준일 현재 적용 중인 금리"로 보입니다** 🔸
>
> 📊 살아있는 채권(`REMAINING_DAYS > 0`)을 발행연도별로 가르면 갈립니다.
>
> | 발행연도 | | 건수 | 평균 | **표면금리 범위** |
> | ---: | :--- | ---: | ---: | :--- |
> | 2025 | 고정금리 | 8,538 | 3.700 | **0.1 ~ 20.0** |
> | 2025 | **변동금리** | **129** | **2.753** | **2.60 ~ 2.97** |
> | 2026 | 고정금리 | 912 | 3.714 | 1.0 ~ 15.46 |
> | 2026 | **변동금리** | **42** | **2.786** | **2.66 ~ 2.90** |
>
> **FRN 129건이 폭 0.37%p 안에 뭉쳐 있습니다.** 발행사가 농협·신한·산업은행으로 제각각인데도요.
> 📖 발행 시점에 확정된 조건이라면 발행사 신용도에 따라 고정금리채처럼 흩어져야 합니다.
> 반대로 **"지금 이 순간의 기준금리"** 를 찍어 넣은 값이라면 발행사가 누구든 한 덩어리로 모입니다.
> 📊 이 값(2.6~3.0%)은 `PD_STD_INFO_UPDATE` 최빈값 **2026-02-24** 시점의 단기금리 수준과 부합합니다.
>
> ⚠️ **단, 2012~2019년 발행분(잔존 있는 86건)은 0.03~6.03으로 제각각입니다.**
> 갱신이 멈춘 것으로 보이나 **확정 못 했습니다.** 오래된 FRN의 표면금리는 신뢰하지 마세요.

> 🔑 **그래서 FRN의 `SRFC_IRT`는 다른 채권과 같은 뜻의 숫자가 아닙니다.**
> 일반 채권은 **"발행 당시의 약속"**, FRN은 **"오늘의 스냅샷"** 입니다.
> *"표면금리 높은 채권"* 같은 질의에서 **한 축에 놓고 정렬하면 틀립니다.**

> 🔑 **고정/변동은 §3의 3분류(이표·할인·복리)와 직교하는 별개 축입니다.**
> `신한은행 15-08 이15-A(콜/변)` 의 `이` 가 이표채 표시 — **변동금리이면서 이표채**입니다.
> `axis_couponType` 에 섞어 넣지 말고 따로 두어야 합니다.

## 4. 가격과 수익률 ★★ 이 절이 채권의 핵심

### 4.1 왜 액면가와 다른 가격에 거래되는가

📊 앞서 본 국고채의 평가가격은 **7,252원**입니다. 액면 10,000원짜리인데 왜 7,252원일까요?

📖 **표면금리가 지금 시장금리보다 낮기 때문입니다.** — 이 한 문장을 다섯 단계로 풉니다.

**① 시장금리 = 지금 돈을 빌리면 붙는 "시세"**

📖 돈에도 시세가 있고, 그 시세는 시간에 따라 변합니다.

```
2021년 →  시장금리 약 1.9%   (초저금리 시기)
2026년 →  시장금리 약 3.6%   (지금)
```

📖 **"시장금리"는 곧 지금 새로 발행되는 채권이 주는 이자율**입니다. 오늘 누가 돈을 빌리려면 3.6%를 줘야 한다는 뜻입니다.

**② 표면금리는 "발행 당시의 시세"가 박제된 것**

📖 §2.2의 두 문장을 붙이면 문제가 드러납니다.

- 표면금리는 **발행 당시의 시장금리를 반영**한다 → 2021년 발행이니 **1.875%**
- 표면금리는 **만기까지 안 바뀐다** → 2051년까지 계속 1.875%

```
2021년 발행 시점 :  표면금리 1.875%  =  시장금리 1.9%   ← 딱 맞음
2026년 현재      :  표면금리 1.875%  <  시장금리 3.6%   ← 어긋남
```

> 🔑 **시장금리는 계속 움직이는데 표면금리는 발행된 날 그대로 굳습니다.**
> *"표면금리가 시장금리보다 낮다"* 는 건 이 **어긋남**을 말합니다 —
> 이 채권이 약속한 이자가 **지금 새로 나온 채권보다 적어졌다**는 뜻입니다.

**③ 그래서 아무도 액면가에 안 삽니다**

| | 이 채권 (2021년 발행) | 새 채권 (2026년 발행) |
| :--- | :--- | :--- |
| 표면금리 | 1.875% | 3.6% |
| 매년 받는 이자 | **187.5원** | **360원** |
| 만기에 받는 원금 | 10,000원 | 10,000원 |

📖 둘 다 10,000원이면 **당연히 오른쪽을 삽니다.** 왼쪽은 10,000원에 안 팔립니다.
그런데 가진 사람은 팔고 싶어 하죠. 방법은 하나 — **값을 깎는 것**입니다.

**④ 얼마까지 깎아야 하나 — 만기 1년으로 축소해서 보면**

📖 25년짜리는 계산이 복잡하니 **만기 1년짜리**로 줄여 감을 잡습니다.

```
표면금리 1.875% · 액면 10,000원 · 만기 1년 · 시장금리 3.6%

1년 뒤 받을 돈은 이미 정해져 있음 :  이자 187.5원 + 원금 10,000원 = 10,187.5원

살 사람의 계산 :
  "어차피 딴 데 넣어도 3.6%는 번다. 이 채권도 최소 3.6%는 나와야 산다."

        내가 낼 돈 × 1.036 = 10,187.5원
     →  내가 낼 돈 = 9,833원                 ← 액면보다 167원 싸게
```

📖 9,833원에 사면 1년 뒤 10,187.5원을 받으니 **딱 3.6%**. 새 채권과 조건이 같아졌고, **이제야 살 사람이 나타납니다.**

**⑤ 25년짜리라 7,252원까지 내려간 것**

📖 원리는 같은데 **어긋남이 25년치 쌓입니다.**

```
매년 받는 이자   :  187.5원   (남들은 360원)
매년 덜 받는 돈  :  172.5원
25년 누적       :  약 4,300원 덜 받음
```

📊 실제 할인폭은 10,000 − 7,252 = **2,748원**입니다. 누적 4,300원보다 작은 이유는 📖 **먼 미래에 덜 받는 손해일수록 지금 가치로는 가볍게 쳐주기** 때문입니다 (25년 뒤 172.5원을 못 받는 건 내년에 못 받는 것보다 덜 아픕니다).

```
이 채권 (2021년 발행)      시장에 새로 나온 채권 (2026년)
표면금리 1.875%            표면금리 3.6%
매년 187.5원 이자          매년 360원 이자
        ↓                          ↓
   똑같이 10,000원 주고 살 사람이 있을까? → 없습니다
        ↓
   가격이 내려가야 합니다. 얼마까지?
        ↓
   7,252원에 사면 → 187.5원 이자 + 25년 뒤 10,000원 회수
                 → 계산해보면 연 3.6% 효과
        ↓
   ✅ 여기서 균형. 그래서 7,252원입니다.
```

📊 실제로 `APPLIED_YIELD = 3.602` 로 시장금리와 일치합니다.

**반대 경우도 있습니다**

| 상황 | 표면금리 vs 시장금리 | 가격 |
| :--- | :---: | :--- |
| 고금리 때 발행 → 지금 저금리 | **>** | 액면보다 **비쌈** (할증) |
| 발행 당시 = 지금 | **=** | 액면가 근처 |
| **저금리 때 발행 → 지금 고금리** | **<** | **액면보다 쌈 (할인)** ← 위 사례 |

📖 §1.5에서 본 `평가가격 10,300원`(할증)이 맨 윗줄입니다. 남들보다 이자를 많이 주는 채권이니 **웃돈을 주고서라도** 사려는 것입니다.

> 🔑 **받을 돈(이자·원금)은 발행 때 고정됐는데 시장 시세만 움직이니, 균형을 맞출 수단은 가격밖에 없습니다.**
> 이 문장이 곧 §4.2의 법칙입니다.

### 4.2 그래서 나오는 단 하나의 법칙

> 🔴 **시장금리 ↑ → 채권 가격 ↓**
> 🔴 **시장금리 ↓ → 채권 가격 ↑**
>
> **가격과 수익률은 항상 반대로 움직입니다.** 채권에서 이거 하나만 외우면 됩니다.

📖 뉴스에서 *"금리 인하 기대로 채권 랠리"* 라고 하는 게 이 얘기입니다. 금리가 내리면 기존 채권(높은 표면금리)이 상대적으로 매력적이 되어 값이 오릅니다.

### 4.3 그래서 "수익률"이라는 말이 3가지 뜻으로 쓰입니다 ★

📖 초보자가 가장 많이 헷갈리는 지점입니다.

| 용어 | 뜻 | 변하나 | 📊 컬럼 |
| :--- | :--- | :--- | :--- |
| **표면금리** | 액면 대비 약속된 이자율 | ❌ 고정 | `SRFC_IRT` |
| **만기수익률(YTM)** | **지금 가격에 사서 만기까지 들고 있을 때** 실제 연 수익률 | ✅ 매일 변함 | `APPLIED_YIELD` `BUY_YIELD` |
| **실현수익률** | 실제로 팔았을 때 번 것 | 사후 확정 | (없음) |

```
표면금리 1.875%  ← 이 채권이 약속한 것
시장수익률 3.6%  ← 지금 7,252원에 사는 사람이 얻을 것
```

> 🔑 **사용자가 "수익률 높은 채권"이라고 물으면 거의 항상 YTM을 뜻합니다.**
> 표면금리로 답하면 틀립니다.

### 4.4 세금 — 수익률 컬럼이 7개인 이유

📖 이자소득에는 세금이 붙는데, **누가 사느냐에 따라 세율이 다릅니다.** 그래서 같은 채권인데 손에 쥐는 돈이 사람마다 다르고, 데이터도 경우별로 나눠 담고 있습니다.

📖 한국의 이자소득세는 **15.4%** (소득세 14% + 지방소득세 1.4%)입니다. 📖 이자를 받을 때 **자동으로 떼고 나머지만 입금**됩니다 — 이걸 **원천징수**라고 합니다.

```
이자 1,000원 발생  →  154원 차감  →  846원 입금
                                    ↑
                        0.846 — 이 절의 핵심 상수
```

📊 이 테이블의 수익률 컬럼 7종 (예시행 = `한국전력공사채권1267`):

| 컬럼 | 누구 기준 | 📊 예시값 |
| :--- | :--- | ---: |
| `BUY_YIELD` | 세전 매수수익률 (기준값) | 5.3 |
| `AFTER_TAX_YIELD` | 개인 세후 🔸 | 4.5918 |
| `CORP_PRETAX_YIELD` | 법인 세전 🔸 | 5.2881 |
| `CORP_AFTER_TAX_YIELD` | 법인 세후 🔸 | 5.2881 |
| `PREF_TAX_YIELD` | 세금우대 계좌 🔸 | 4.8681 |
| `AVG_ANNUAL_TAX_YIELD` | 연평균 과세 🔸 | 0.0 |
| `DEPO_EQUIV_YIELD_154` | **예금환산** | 5.4277 |

📖 **컬럼이 7개인 건 상품이 7개라서가 아니라 "누가 사느냐"의 경우의 수가 7개**이기 때문입니다.

| 누가 사나 | 어떻게 다른가 |
| :--- | :--- |
| **개인** | 이자 받을 때 15.4% 원천징수 |
| **법인** | 원천징수 없이 **나중에 법인세로 정산** |
| **세금우대 계좌** | 우대 세율 적용 (ISA 등) |

> ✅ 📊 **`DEPO_EQUIV_YIELD_154` × 0.846 = `AFTER_TAX_YIELD`** — **881건 중 880건에서 정확히 성립**합니다.
> ```
> 5.4277 × 0.846 = 4.5918   ✅
> ```
> 📖 읽는 법: *이 채권은 세후로 **4.59%** 를 손에 쥐어준다. 그런데 예금은 **세전 금리**로 광고하니
> (*"연 5.4%!"*), 세후 4.59%를 주려면 예금은 세전 **5.43%** 여야 한다.*
> → **"이 채권은 연 5.4% 예금과 같다."** 이름 끝의 `154` 가 세율 15.4%를 뜻합니다.
> 🔑 **채권과 예금의 눈금을 맞춰주는 값**이라 일반인에게 가장 친절합니다.

> 📖 **법인이 개인보다 세전 수익률이 높게 나오는 이유** — 법인은 이자소득세를 원천징수당하지
> 않고 법인세로 나중에 정산합니다. 과세 시점과 방식이 달라 표기가 갈립니다. 🔸
> 📊 예시행처럼 **법인 세전 = 법인 세후** 인 행이 39건 있습니다.

**🔴 단순히 15.4%를 곱한 값이 아닙니다**

📊 실제 세후/세전 비율은 **종목마다 0.88~0.95로 다릅니다.** 일괄 0.846이 아닙니다.

📖 **채권 수익은 두 갈래인데 세금은 주로 한쪽에만 붙기 때문입니다.** §4.3에서 YTM을 분해했던 그 두 갈래입니다.

| :--- | :--- |
| **이자** (표면금리) | 과세 ✅ |
| **원금 차익** (싸게 사서 액면으로 상환받는 몫) | 개인은 **비과세** |

📊 그래서 채권 성격에 따라 세금 타격이 갈립니다:

| | 건수 | 평균 세후/세전 | |

| **할증채** (`EVAL_PRICE` > 10,000) | 645 | **0.9042** | 이자가 많다 → 과세 대상이 크다 |

> 🔴 📊 **`교보생명보험신종자본증권 3` — 세전 3.0% 인데 세후 −1.1514%.**
> 1건뿐이지만 명백한 이상값입니다.

### 4.5 가격 컬럼 6개 — 클린 프라이스와 더티 프라이스

📖 채권 가격에는 **두 가지 표기법**이 있습니다. 출발점은 **어긋남 하나**입니다.

```
이자가 쌓이는 방식  :  매일 조금씩   (하루하루 내 몫이 늘어남)
이자를 주는 방식    :  3개월에 한 번 몰아서
```

**① 왜 사는 사람이 물어주나**

📖 표면금리 **4%**, 액면 10,000원, **3개월마다** 지급이면 한 번에 **100원**입니다.

```
 1/1 ────────────── 3/1 ────── 4/1
이표 지급           오늘(매수)   다음 이표 지급
                     ↑            ↑
                  60일 경과     100원 지급
```

📖 **4/1에 나오는 100원은 그날 채권을 갖고 있는 사람이 통째로 가져갑니다.** 3/1에 산 사람은 30일만 보유했는데 100원을 다 받죠. 앞의 60일치는 **판 사람이 벌어놓은 몫**입니다.

```
60일치 = 100원 × 60/90 ≈ 66.7원   ← 판 사람 몫  = 경과이자
30일치 = 100원 × 30/90 ≈ 33.3원   ← 산 사람 몫
```

📖 그래서 **살 때 66.7원을 미리 얹어줍니다.**

| 용어 | 뜻 | 이 예시 | 📊 컬럼 |
| :--- | :--- | ---: | :--- |
| **클린 프라이스** | 채권 자체의 값. **호가·비교에 쓰는 값** | 10,000원 | `EVAL_PRICE` |
| **경과이자** | 판 사람 몫으로 물어주는 돈 | +66.7원 | ⚠️ **컬럼 없음** |
| **더티 프라이스** | **실제로 계좌에서 빠지는 금액** | 10,066.7원 | `DIRTY` |

```
더티 프라이스 = 클린 프라이스 + 경과이자
```

> 📖 더러워서 "더티"가 아니라 **채권 값에 이자가 섞여 있어서** 더티입니다.

**② 왜 표기를 두 개나 두나 — 더티는 톱니 모양이라서**

```
더티 (실제 낼 돈)
 │      ╱│     ╱│     ╱│
 │    ╱  │   ╱  │   ╱  │      ← 이자가 쌓이며 오르다가
 │  ╱    │ ╱    │ ╱    │        이표일에 뚝 떨어짐 (이자를 줬으니)
 └──────┴──────┴──────┴──→
        이표일   이표일   이표일

클린 (호가)
 │ ─────────────────────      ← 톱니를 걷어낸 값
 └──────────────────────→
```

📖 더티만 있으면 이런 오독이 생깁니다:

> *A채권 10,090원 / B채권 10,020원 → "A가 더 비싸네"*
> 그런데 A는 이표일 직전이라 경과이자가 90원 껴 있었을 뿐, **채권 자체 값은 둘 다 10,000원**

> 🔑 **채권끼리 비교하려면 톱니를 걷어내야 합니다.** 호가·정렬·비교에는 **클린(`EVAL_PRICE`)**,
> 실제 결제금액을 말할 때만 **더티(`DIRTY`)** 를 씁니다.

> ⚠️ 📊 **경과이자 컬럼이 없습니다.** `DIRTY − EVAL_PRICE` 로 역산해야 하는데,
> 아래 ③ 때문에 **이 역산값을 그대로 믿으면 안 됩니다.**

**③ 🔴 그런데 `DIRTY` 컬럼은 신뢰도가 낮습니다**

📊 둘 다 값이 있는 29,018건 중 **다른 것은 1,588건뿐**이고 **27,430건(94.5%)이 동일**합니다.

> 🔴 **이 27,430건을 "이표 지급 직후라 경과이자가 0"으로 설명할 수 없습니다.**
> 📖 이 데이터는 **한 시점 스냅샷**이고 채권마다 이표일이 제각각인데, **94.5%가 하필 같은 날
> 이표 직후**일 확률은 사실상 없습니다. 📊 게다가 그 27,430건 중 표면금리가 0인 건 **3.9%뿐** —
> 대부분 **이자를 주는 이표채**입니다.
> **→ `DIRTY` 미산출 시 `EVAL_PRICE` 를 그대로 복사한 것으로 보입니다.** 🔸

📊 다른 1,588건 안에서도 이상값이 나옵니다:

| 현상 | 건수 | 📖 왜 문제인가 |
| :--- | ---: | :--- |
| `DIRTY` > `EVAL_PRICE` (정상) | 1,567 | 경과이자만큼 크다 |
| 🔴 **`DIRTY` < `EVAL_PRICE`** | **21** | **경과이자가 음수 — 불가능** |
| 🔴 └ 그중 **`DIRTY` = 0** | **8** | 클린은 10,168원인데 더티가 0 = 결측을 0으로 |
| 🔴 **경과이자 > 1년치 이자** | **159** | 이표채면 최대 이표 1회분(3~6개월치)이어야 함 |
| 🔴 표면금리 0인데 경과이자 발생 | 3 | 할인채는 줄 이자가 없음 |

```
하이도미네이션제구차1-2(사모)   클린 10,168.66   더티 0.0        ← DIRTY 결측

## 5. 신용등급 — "떼일 위험"의 점수

### 5.1 누가 매기나

📖 국내 신용평가사는 **3곳**입니다: **한국신용평가(KIS)** · **NICE신용평가** · **한국기업평가(KR)**. 회사채는 보통 **2곳 이상에서 평가받아야** 발행할 수 있습니다.

📖 평가사는 발행사의 재무제표·업황·지배구조를 보고 **"이 회사가 약속대로 갚을 능력"** 을 등급으로 표시합니다.

### 5.2 등급 체계

📖

```
 AAA   AA+  AA0  AA-   A+  A0  A-   BBB+ BBB0 BBB-  │  BB+ 이하
 └──────────── 투자등급 (Investment Grade) ────────┘  └─ 투기등급 ─┘
  최고                                    투자 마지노선     "정크본드"
```

📖 읽는 법:
- **알파벳** — 큰 등급. `AAA` > `AA` > `A` > `BBB` > `BB` > `B` > `CCC` > `CC` > `C` > `D`(부도)
- **+ / 0 / −** — 같은 알파벳 안에서 세분. `AA+` > `AA0` > `AA-`

> 🔴 **한국은 중간값에 `0`을 붙여 씁니다.** `AA` 가 아니라 **`AA0`**, `A`가 아니라 **`A0`**.
> 📊 데이터에도 `AA0` 1,713건 · `A0` 904건으로 들어 있습니다.
> **사용자는 "AA등급"이라고 묻지 "AA0"이라고 묻지 않습니다.** 매핑이 필요합니다.

> 📖 **`BBB-`와 `BB+` 사이가 실무의 결정적 경계입니다.** 많은 기관 투자자가 규정상
> **투자등급 이하는 살 수 없습니다.** 그래서 한 단계 강등이 회사에 치명적입니다.

### 5.3 등급과 금리의 관계

📖 **등급이 낮을수록 금리를 더 줘야 합니다.** 위험한 만큼 보상해야 사람들이 사기 때문입니다. 이 추가 금리를 **신용스프레드**라고 부릅니다.

```
국고채 (무위험)     3.0%
AAA 회사채          3.3%   ← 스프레드 +0.3%
A0  회사채          4.2%   ← 스프레드 +1.2%
BBB 회사채          6.5%   ← 스프레드 +3.5%
```

> 🔑 **그래서 "수익률 높은 채권 추천"은 곧 "위험한 채권 추천"일 수 있습니다.**
> 수익률만으로 정렬해 답하면 안 되고 등급을 함께 밝혀야 합니다.

### 5.4 등급이 없는 채권 — 결측이 아니라 "무등급"

📖 **국채·지방채는 신용등급을 매기지 않습니다.** 정부가 부도날 것을 전제로 등급을 매기는 게 무의미하기 때문입니다. (자국 통화 국채는 이론상 무위험 자산으로 봅니다)

📊 `CRD_GRD` 결측이 41.6%인데, 상당 부분이 이 경우입니다. 앞서 본 국고채도 `CRD_GRD`가 비어 있습니다.

> 🔑 **결측 ≠ 정보 없음.** *"확인할 수 없습니다"* 가 아니라
> *"국채라 신용등급이 부여되지 않습니다"* 가 맞는 답변입니다.
> 📖 주최 측 축도 이걸 `NotRated` 로 따로 두고 있습니다.

### 5.5 이 데이터의 등급 컬럼은 2개이고 체계가 다릅니다

📖 **같은 정보의 "원본"과 "요약본"입니다.**

```
PD_EVCO_CRD_GRD  :  'AAA, AAA, AA+'    ← 원본.  §5.1의 평가사 3곳이 각자 매긴 것
CRD_GRD          :  'AAA'              ← 요약본. 대표 등급 하나로 추린 것
```

| 컬럼 | 형태 | 예시 |
| :--- | :--- | :--- |
| `CRD_GRD` | **단일 등급** (중간값에 `0`) | `AAA` · `AA0` · `A+` |
| `PD_EVCO_CRD_GRD` | **평가사별 등급을 콤마로 결합** (`0` 없음) | `'AAA, AAA, AAA'` · `'AA, AA'` |

**① `PD_EVCO_CRD_GRD` 읽는 법 — 콤마 개수 = 평가사 수**

```
'AAA, AAA, AAA'  →  3곳이 평가했고, 셋 다 AAA
'AAA, AAA'       →  2곳만 평가했고, 둘 다 AAA
'A-, CCC, CCC'   →  3곳이 평가했는데 의견이 갈림
```

📊 평가사 수 분포 / 📊 `PD_EVCO_CRD_GRD` 상위값:

| 평가사 수 | 건수 | | 상위값 | 건수 |

| 2곳 | 7,829 | | `'AA-, AA-, AA-'` | 4,118 |
| 1곳 | 2,361 | | `'AAA, AAA'` | 4,065 |
| | | | `'AA, AA'` | 732 |

> ⚠️ **어느 자리가 어느 평가사인지는 알 수 없습니다.** 첫 번째가 한신평인지 NICE인지 데이터에 없습니다.
> **평가사별 비교는 불가능**하고, 알 수 있는 건 *"몇 곳이 봤고, 의견이 갈렸나"* 까지입니다.

## 6. 채권은 어떻게 나뉘는가

📖 채권 분류는 **"누가 발행했나"** 가 1차 기준입니다. 발행자가 곧 위험이기 때문입니다.

### 6.1 3단 계층 — 대분류 → 소분류 → 채권종류

📊 이 데이터는 발행 주체 기준으로 **3단계** 분류를 담고 있습니다.

```
STD_PD_MCLS_NM (6종)  →  STD_PD_SCLS_NM (16종)  →  BD_KND (39종)
   대분류                     소분류                   채권종류
   국공채                      국고채                    국고채권
   회사채                      은행채                    일반은행채
```

> ⚠️ 📊 **결측을 종류로 세면 안 됩니다.** 소분류는 `16종 + 결측 13건`, 채권종류는 `39종 + 결측 924건`입니다.
> 프로파일러가 `NULL` 을 고유값에 포함시켜 **17종·40종으로 집계되기 쉽습니다.**
> 📊 소분류 결측 13건 = **외화채권 6건(소분류 자체가 없음) + 회사채 미부여 7건**.

**소분류 16종 전체** — 📖 대분류를 몇 갈래로만 나눈 것입니다.

| 대분류 | 소분류 | 📊 건수 |
| :--- | :--- | ---: |
| **회사채** | **일반사채** | **30,116** |
| | 은행채 | 1,247 |
| | 기타사채 | 67 |
| | 특수은행채 | 9 |
| | 공사채 | 1 |
| **특수채** | 공사채 | 5,385 |
| | 특수은행채 | 2,427 |
| | 일반사채 | 842 |
| | 중앙은행채 | 101 |
| **국공채** | 지역개발 | 1,266 |
| | 국고채 | 312 |
| | 도시철도 | 240 |
| | 국민주택 | 147 |
| | 공모지방채 | 125 |
| | 기타국채 | 41 |
| | 물가채 | 6 |
| **개인투자용국채** | 10년물 / 20년물 / 5년물 | 19 / 19 / 11 |

> 🔴 **이건 깔끔한 트리가 아닙니다 — 가지가 서로 얽혀 있습니다.**
>
> **① 소분류 3종이 두 대분류에 동시에 걸칩니다**
> ```
> 공사채      → 특수채(5,385)  +  회사채(1)
> 일반사채    → 회사채(30,116) +  특수채(842)
> 특수은행채  → 특수채(2,427)  +  회사채(9)
> ```
> 📖 *"일반사채"* 라는 소분류만 보고는 **특수채인지 회사채인지 알 수 없습니다.**
> 1건·9건은 오분류로 보이나 **특수채 → 일반사채 842건**은 무시할 양이 아닙니다.
>
> **② 채권종류 10종이 여러 소분류에 걸칩니다**
> ```
> 일반회사채      → 일반사채 · 기타사채
> 일반은행채      → 은행채 · 일반사채 · 기타사채
> 일반특수법인채   → 공사채 · 일반사채
> ```
>
> **③ 개인투자용국채는 계층이 뒤집혀 있습니다**
> ```
> BD_KND (채권종류) :  개인투자용국채            ← 1종
> STD_PD_SCLS_NM   :  5년물 / 10년물 / 20년물   ← 3종  🔴 아래 단계보다 더 세밀
> ```
> 📖 여기서는 **만기별 구분이 소분류에** 들어가 있습니다.

> 🔑 **`BD_KND` 하나로 상위 분류를 되짚을 수 없고, 소분류만으로 대분류를 특정할 수도 없습니다.**
> **세 컬럼을 각각 봐야 합니다.**

### 6.4 특수한 구조의 채권 — 이름에 단서가 있습니다

📖 일반 채권과 성질이 다른 것들이 섞여 있습니다. 📊 별도 컬럼이 없어 **종목명으로만** 식별됩니다.

> 🔴 **이건 "예외 처리"할 규모가 아닙니다.**
>
> | | 📊 건수 | 비율 |
> | :--- | ---: | ---: |
> | **특수구조 하나라도 해당** | **15,306** | **36.1%** |
> | 아무것도 해당 안 됨 (순수 일반채권) | 27,088 | 63.9% |
>
> **3건 중 1건입니다.** 소수 예외를 빼는 게 아니라 **분석 설계에 처음부터 넣어야 하는 규모**입니다.

> 🔴 ***"안전한 채권 추천"* 에 AA등급 필터만 걸면 코코본드가 그대로 통과합니다.**

**④ 📖 그래서 어떻게 다뤄야 하나**

**1단계 — `is_*` 플래그 파생 컬럼 세트를 먼저 만들고 모든 분석의 출발점으로 삼습니다.** 매번 `LIKE` 를 새로 짜면 위와 같은 누락이 반복됩니다.

**2단계 — 질의 유형별로 정책을 나눕니다.**

| 질의 유형 | 처리 |
| :--- | :--- |
| **추천·랭킹** (*"안전한 채권"*, *"수익률 높은"*) | **제외**하고, 제외 사실을 **밝히기** |
| **검색·조회** (*"삼성전자 채권"*) | **포함** — 사용자가 그 종목을 물었을 수 있음 |
| **통계·분포** (*"평균 표면금리"*) | **분리 집계** — 섞으면 CB 1,468건이 평균을 끌어내림 |

**3단계 — 축 유도에 반영합니다.**

- `axis_couponType` — CB를 `ZeroCoupon` 으로 넣으면 안 됨. 정답에 `ConvertibleCoupon` 이 별도로 있음
- `axis_collateralType` — **`Subordinated` 1,210건**이 여기서 나옴
- `axis_maturityClass` — **영구채 450건**을 만기 구간에 넣을지 결정 필요

### 6.5 장내 / 장외 (`PD_EXG_MKT`)

📖 채권은 두 시장에서 거래됩니다.

| | **장내** | **장외** |
| :--- | :--- | :--- |
| 어디서 | 한국거래소(KRX) | 증권사와 1:1 상대 거래 |
| 누가 주로 | 개인 | **기관** |
| 가격 | 공개 호가 | 협상 |
| 📊 건수 | 24,749 | 17,645 |

> 📖 **한국 채권 거래의 대부분(금액 기준)은 실제로는 장외에서 일어납니다.**
> 기관끼리 대량으로 주고받기 때문입니다. 개인이 증권사 앱에서 사는 건 장내 위주입니다.

**① ⚠️ 이 컬럼은 "거래 방식"이 아니라 "종목 속성"입니다**

```sql
SELECT COUNT(*)-COUNT(DISTINCT TRIM(PD_NO)) FROM domestic_bonds;   -- ▶ 0
```

📖 현실에선 같은 채권이 장내·장외 양쪽에서 거래될 수 있지만, 📊 **이 데이터는 종목마다 둘 중 하나만 붙여놨습니다.**

> 🔑 **그래서 *"같은 채권의 장내 가격 vs 장외 가격"* 비교는 이 데이터로 불가능합니다.** 한쪽 값밖에 없습니다.

**② 🔴 수익률이 2배 차이 나 보이지만, 시장 효과가 아닙니다**

📊 원시 비교:

| | 장내 | 장외 |
| :--- | ---: | ---: |
| **YTM 평균** (`APPLIED_YIELD`) | **3.200%** | **6.127%** |
| 표면금리 평균 | 3.333% | 4.596% |

📖 여기서 *"장외 채권이 수익률이 높구나"* 라고 결론 내리면 **틀립니다.** 📊 **담긴 채권이 아예 다르기 때문입니다:**

| | 장내 | 장외 |
| :--- | ---: | ---: |
| **회사채 비중** | 59.9% | **94.2%** |
| 특수채 | 31.6% | 5.3% |
| **국공채** | **8.5%** | **0.2%** |
| **등급 없음** | 11.9% | **83.3%** |
| AAA 등급 | 43.6% | 8.2% |
| **특수구조 채권** (§6.4) | 15.2% | **65.4%** |
| 발행잔액 평균 | 1,437억 | **132억** |

📖 **누가 거래하느냐가 무엇이 거래되는지를 결정합니다.**

```
장내 = 거래소 = 개인도 참여   →  표준화되고 등급 있는 우량채여야 팔림
장외 = 기관끼리 1:1 협상      →  소액 사모 회사채, 복잡한 구조도 처리 가능
```

**③ ✅ 조건을 통제하면 차이가 거의 사라집니다**

📊 같은 대분류·등급·잔존만기끼리 비교:

| 조건 | 장내 YTM | 장외 YTM | 차이 |
| :--- | ---: | ---: | ---: |
| 특수채 AAA 1년미만 | 2.794 | 2.819 | **+0.025** |
| 회사채 AAA 1-3년 | 3.349 | 3.417 | **+0.068** |
| 회사채 AA- 1-3년 | 3.435 | 3.563 | +0.128 |
| 회사채 AA+ 3-5년 | 3.685 | 3.917 | +0.232 |
| 회사채 AA0 1-3년 | 3.399 | 3.319 | **−0.080** |
| 회사채 AAA 5년+ | 4.031 | 3.178 | **−0.853** |

> 🔑 **원시 차이 2.9%p 가 통제하면 0.03~0.2%p 로 줄어듭니다.**
> ***"장외라서 수익률이 높다"* 가 아니라 *"장외에 수익률 높은 채권이 몰려 있다"* 입니다.**
> 🔸 시장 자체의 효과가 있더라도 미미하며, 있다면 **소량·비유동 채권이라 조금 더 얹어줘야 팔리는 정도**로 보입니다.

> 🔴 **그래서 `PD_EXG_MKT` 를 단순 그룹 변수로 쓰면 안 됩니다.**
> *"시장별 평균 수익률"* 같은 집계는 시장 차이가 아니라 **구성 차이**를 재는 **거짓 상관**입니다.
> 비교하려면 **대분류·등급·잔존만기를 반드시 통제**해야 합니다.

**④ 📊 장외는 사실상 "정보가 없는 쪽"입니다**

| | 장내 (24,749) | 장외 (17,645) |
| :--- | ---: | ---: |
| YTM(`APPLIED_YIELD`) 있음 | 24,263 | 7,560 |
| 등급 있음 | 21,801 | 2,949 |
| **매수정보(`BUY_YIELD`) 있음** | **867** | **14** |

> 📖 즉 *"미래에셋이 지금 개인에게 팔고 있는 채권"* 881건은 **실질적으로 장내 867건**입니다. 🔸

> ⚠️ **장외의 83%가 등급 없음은 *"우량채가 없다"* 가 아니라 *"평가를 안 받았다"* 입니다** — §5.4의 무등급 논리가 여기에도 적용됩니다.

> ⚠️ 📊 **`개인투자용국채` 49건은 전부 `장외` 입니다.** 개인 전용 상품인데 거래소를 안 거칩니다
> (정부가 개인에게 직접 판매하는 구조로 보임 🔸). ***"개인이 살 수 있는 채권 = 장내"* 라는 단순 대응이 깨지는 지점입니다.**

> 🔑 **§6.4와 강하게 얽혀 있습니다.** 장외의 **65.4%가 특수구조**라, *"추천 질의에서 특수구조 제외"* 정책을 걸면
> **장외가 대부분 사라집니다.** 두 필터가 사실상 같은 것을 거르므로 **중복해서 걸지 말고 하나로 정리**해야 합니다.

## 7. 만기와 듀레이션 — 금리 위험의 크기

### 7.1 듀레이션이란

📖 **듀레이션(Duration)** 은 *"금리가 1%p 움직이면 이 채권 가격이 몇 % 움직이나"* 를 나타내는 숫자입니다.

```
듀레이션 3   →  금리 1%p 상승 시 가격 약 3% 하락
듀레이션 18  →  금리 1%p 상승 시 가격 약 18% 하락  ← 훨씬 위험
```

📊 앞서 본 국고채(만기 25년)의 `DUR`은 **18.507**입니다. 금리가 1%p만 올라도 가격이 18.5% 빠집니다.

📖 원래 뜻은 *"투자금을 회수하는 데 걸리는 평균 기간"* 인데, 실무에서는 **금리 민감도 지표**로 씁니다.

**📖 왜 만기가 길면 더 크게 떨어지나 — 듀레이션의 정체**

§4.2에서 *"금리 오르면 가격 내린다"* 는 봤습니다. 여기서 한 걸음 더 나갑니다.

> 🔑 **금리가 오르면 내 채권은 "남들보다 덜 주는 채권"이 됩니다.**
> **그 손해를 몇 년 동안 참아야 하느냐 — 그게 하락폭을 결정합니다.**

**표면금리 3% · 액면 10,000원**짜리 채권 셋을 놓습니다. **만기만 다릅니다.** 시장금리도 3%라 셋 다 정확히 10,000원입니다. 여기서 **시장금리가 4%로 오르면** — 새 채권은 매년 400원을 주는데 내 것은 여전히 300원입니다.

| | 매년 덜 받는 돈 | **몇 번 반복되나** | 가격 | **하락률** |
| :--- | ---: | ---: | ---: | ---: |
| **1년물** | 100원 | **1번** | 9,904원 | **−1.0%** |
| **5년물** | 100원 | **5번** | 9,555원 | **−4.5%** |
| **20년물** | 100원 | **20번** | 8,641원 | **−13.6%** |

> 🔑 **똑같이 1%p 올랐는데 손실이 14배 차이 납니다. 다른 건 만기뿐입니다.**
> 그리고 **맨 오른쪽 열의 숫자(1.0 / 4.5 / 13.6)가 곧 듀레이션**입니다.

📖 이유는 두 가지입니다.

**① 손해가 반복되는 횟수**

```
1년물  :  100원 덜 받고 → 끝. 1년 뒤 원금 받아 4%짜리로 갈아탐
20년물 :  100원 → 또 100원 → 또 100원 → … 20번 반복
```

**② 원금이 늦게 올수록 그 가치가 더 깎임** (금리 4% 기준)

```
1년 뒤  10,000원  →  지금 가치 9,615원   (할인 1번)
20년 뒤 10,000원  →  지금 가치 4,564원   (할인 20번)
```

📖 **예금으로 바꿔 보면** (§1.2의 비교를 다시 쓰면):

> 3% 정기예금에 넣었는데 다음 날 옆 은행이 4%를 내놨습니다.
> **1년 만기**면 1년만 참으면 됩니다. **20년 만기**면 20년을 3%에 묶여 있어야 합니다.
> 이 계약을 남에게 넘긴다면? **20년짜리 "억울한 계약"일수록 훨씬 많이 깎아줘야 사갑니다.**

📊 그래서 앞의 국고채는 — **25년간 낮은 이자에 묶이는 계약**이라 금리가 1%p만 올라도:

```
7,252원  →  약 5,910원   (−18.5%)   →  액면 10,000원당 1,342원 증발
```

> 🔑 **듀레이션은 "이 채권이 나를 얼마나 오래 묶어두느냐"를 숫자 하나로 나타낸 것**입니다.
> 오래 묶일수록 금리가 변할 때 크게 흔들립니다.

**🔑 "위험"이 두 종류라는 것을 먼저 구분해야 합니다**

| | **부도 위험** (신용위험) | **가격 변동 위험** (금리위험) |
| :--- | :--- | :--- |
| 무엇 | 발행사가 안 갚을 위험 | 금리가 변해 값이 출렁일 위험 |
| 어디서 다루나 | §5 신용등급 | **§7 듀레이션** |
| **국고채는?** | **0에 가까움** (§5.4에서 등급을 안 매기는 이유) | **최고 수준 (18.5)** |

> 📖 ***"국고채는 안전하다"* 와 *"듀레이션 18은 위험하다"* 는 둘 다 참입니다.** 서로 다른 위험을 말합니다.

**📖 만기까지 보유하면 이 위험은 실현되지 않습니다**

```
내일 금리가 1%p 오른다  →  가격 18.5% 하락  →  7,252원 → 약 5,910원
                                    ↓
                          팔지 않으면 무슨 일이 일어나나?
                                    ↓
       매년 187.5원 이자 + 2051년 원금 10,000원   ← 하나도 안 변함
       내가 실제로 버는 것 = 여전히 연 3.602%
```

📖 **가격은 *"지금 팔면 받을 돈"* 이지 *"만기에 받을 돈"* 이 아닙니다.** 만기에 받을 돈은 §2.2대로 발행 때 확정됐고 시장이 뭘 하든 안 바뀝니다.

| | 무엇 | 언제 |
| :--- | :--- | :--- |
| **평가손** | 장부상 숫자만 내려감 | 가격이 떨어진 순간 |
| **실현손** | 실제로 돈을 잃음 | **팔았을 때만** |

📊 앞의 국고채로 정리하면:

| | 무슨 일이 일어나나 |
| :--- | :--- |
| **지금 판다** | 5,910원밖에 못 받음 → **1,342원 손실 확정** |
| **만기까지 들고 간다** | 매년 187.5원 + 2051년 10,000원 → **손실 없음.** 처음 약속대로 연 3.602% |

> 🔑 **듀레이션은 "중도에 팔 때의 위험"이지 "떼일 위험"이 아닙니다.**

> ⚠️ **단, "완전히 무해"는 아닙니다.** 금리가 4.6%로 올랐는데 3.602%에 25년 묶여 있으면 **기회비용**이 생깁니다.
> **팔면 손실 확정, 안 팔면 낮은 수익률에 묶임** — 어느 쪽이든 대가가 있습니다.
> 만기 전에 돈이 필요해지면 결국 팔아야 하고, 그때 평가손이 실현손이 됩니다.

📖 그래서 **누구에게 중요한지가 갈립니다:**

| | 듀레이션 |
| :--- | :--- |
| 만기까지 확실히 보유할 개인 | **덜 중요** — 어차피 산 시점 YTM 확정 |
| 중도 매도 가능성이 있는 사람 | **매우 중요** |
| **채권형 펀드** | **결정적** — 매일 기준가를 매기므로 평가손이 그대로 수익률에 찍힘 |

### 7.2 왜 만기보다 듀레이션을 보나

📖 만기가 같아도 표면금리가 다르면 위험이 다릅니다.

```
만기 10년, 표면금리 5%  →  이자를 많이 받으니 원금 회수가 빠름  → 듀레이션 낮음
만기 10년, 표면금리 0%  →  만기에 한 번에 받음               → 듀레이션 ≈ 10 (최대)
```

> 🔑 **듀레이션 = 채권의 실질 위험도.**
> *"금리 오를 것 같으니 안전한 채권"* → 듀레이션 낮은 것.
> *"금리 내릴 것 같으니 수익 큰 채권"* → 듀레이션 높은 것.
> 실무에서 가장 많이 쓰는 개념입니다.

📖 **볼록성(Convexity, `COV`)** 은 듀레이션의 보정값입니다. 금리 변동이 클 때 듀레이션만으로는 오차가 생기는데 그걸 잡아줍니다. 📖 일반 사용자 질의에는 거의 안 쓰입니다.

### 7.3 🔴 안전한 채권일수록 듀레이션이 높습니다 — 두 위험이 상충합니다

📊 **§6.2의 안전도 순서와 듀레이션이 정확히 반대입니다.**

| 대분류 | 📖 안전도 (§6.2) | **DUR 평균** | 잔존 평균 |
| :--- | :--- | ---: | ---: |
| **국공채** | **최고** | **4.52** | 4.83년 |
| 특수채 | 높음 | 4.01 | 5.42년 |
| **회사채** | **낮음** | **2.05** | 2.64년 |

📊 신용등급별로도 같습니다:

```
AAA 3.55  >  AA0 2.11  >  AA+ 1.94  >  A+ 1.59  >  A0 1.50  >  AA- 1.43
```

📖 **이유는 간단합니다 — 정부·공기업은 장기로 빌릴 수 있지만, 신용이 약한 회사는 장기로 못 빌립니다.** 아무도 20년씩 돈을 안 빌려주니 단기 위주로 발행할 수밖에 없습니다.

> 🔴 ***"안전한 채권 추천"* → 국공채 → 듀레이션이 높은 것들 → 금리가 오르면 큰 손실.**
> **§5 기준으로 안전한 것을 골랐는데 §7 기준으로는 위험한 것을 고른 셈**이 됩니다.
> **두 위험을 함께 밝히지 않으면 오답이 됩니다.**

📊 실제로 **대한민국이 발행한 채권 중 118건이 `DUR` 15 이상**입니다.

## 10. 이 데이터가 답할 수 없는 것 — 도메인상 당연한 것들

📖 *"왜 이게 없지?"* 를 미리 알아두면 `확인할 수 없음` 응답을 자신 있게 낼 수 있습니다.

| 없는 것 | 📖 왜 없나 |
| :--- | :--- |
| **이자 지급 주기** | 3개월인지 6개월인지. 발행조건서(투자설명서) 영역 |
| **이자 지급일 / 다음 이표일** | 마스터에 미수록. 경과이자를 직접 계산할 수 없음 |
| **액면가** | 관행상 10,000원 고정이라 컬럼으로 두지 않음 |
| **최소 매수 단위** | 증권사·상품별로 달라 마스터에 없음 |
| **이표채/할인채/복리채 구분** | 별도 컬럼 없음. 표면금리 0 여부와 종목명으로 추정해야 함 (§3) |
| **고정금리/변동금리 구분** | 별도 컬럼 없음. 종목명의 `변` 표기 4종을 파싱해야 함 — 643건 (§3.4) |
| **FRN의 연동 기준금리·가산금리** | *"CD금리 + 1.5%"* 의 기준과 가산폭. 일부 종목명에 `KOFR` 만 노출 |
| **FRN 표면금리의 기준 시점** | 언제 갱신된 값인지 컬럼 없음. 오래된 FRN은 갱신 정지 의심 🔸 (§3.4) |
| **담보 유무 / 후순위 여부** | 별도 컬럼 없음. 종목명 `(후)` 등으로만 (§8.4) |
| **콜/풋 옵션 조건** | 행사일·행사가 미수록. 이름의 `(콜)` 만 |
| **발행사의 재무정보** | 매출·부채비율 등. 별도 기업 데이터 영역 |
| **가격 시계열** | 매일의 가격 이력. 마스터는 **한 시점 스냅샷** |
| **거래량 / 체결 내역** | 시장 데이터 영역 |
| **신용등급 변동 이력** | 현재 등급과 평가일만. 과거 등급 추이 없음 |
| **발행 목적 / 자금 사용처** | 증권신고서 영역 |
| **국채의 신용등급** | 📖 **원래 안 매깁니다** (§5.4). 결측이지만 정상 |

> 🔑 **마스터 데이터는 "채권의 신분증"입니다.**
> 발행 조건과 현재 평가값은 있지만, **매일 변하는 시계열**이나 **투자설명서에 적히는 상세 조건**은 없습니다.

### 10.1 도메인상 "정답이 하나가 아닌" 것들 — 데이터를 다 채워도 남습니다

📖 위 표가 **데이터에 없어서** 못 답하는 것이라면, 아래는 **데이터가 완벽해도** 못 정하는 것입니다. **사람이 무엇을 원하는지에 따라 답이 달라지기 때문**입니다.

| 물음 | 왜 하나로 못 정하나 |
| :--- | :--- |
| **"이 채권 위험해?"** | 📖 위험이 두 종류입니다 (§7.1). 국고채는 **부도위험 최저 · 금리위험 최고** — 어느 쪽을 묻는지에 따라 답이 정반대 |
| **"안전한 채권 추천"** | 📖 부도위험 기준이면 **국공채**(`DUR` 평균 4.52), 금리위험 기준이면 **단기 회사채**(`DUR` 0.49). §7.3의 역설 |
| **"수익률 높은 채권"** | 📖 세전/세후, 개인/법인에 따라 다름 (§4.4). 그리고 §5.3대로 **높은 수익률 = 높은 위험** |
| **"이 채권의 등급은?"** | 📊 평가사 의견이 갈린 258건에서 최저/다수결 중 무엇을 택할지 (§5.5) |
| **답변의 모수** | 📊 *"시장 전체"* 냐 *"지금 살 수 있는 것"* 이냐에 따라 **16,349건 vs 58~325건** |

📖 여기에 더해 **같은 단어가 여러 뜻인 것**도 되물어야 합니다 — *"수익률"* 은 표면금리/YTM/세후/예금환산 네 갈래(§4.3·§4.4), *"위험"* 은 두 갈래(§7.1), *"싸다"* 는 가격이 낮다는 뜻과 수익률이 높다는 뜻이 **정반대**입니다(§4.2).

> 🔑 **이런 물음은 "확인할 수 없습니다"가 아니라 "무엇을 기준으로 볼지"를 되물어야 하는 것입니다.**
> **되묻는 것은 답변 실패가 아니라 유효한 답변이며, 근거 없이 하나를 골라 단정하는 것보다 낫습니다.**
> 📖 특히 **보유 기간**이 결정적입니다 — §7.1대로 **만기까지 보유하면 듀레이션은 실현되지 않고,
> 중도 매도 가능성이 있으면 듀레이션이 결정적**이 됩니다. **같은 채권의 위험도가 뒤집힙니다.**
>
> **→ 역질문 설계와 기본값은 `docs/eda/domestic_bonds_notes.md` §I 참조.**
