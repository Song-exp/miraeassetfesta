## 🔴 예시가 그대로 드러낸 것 4가지

### ① `PD_RISK_GCD` 는 숫자가 낮을수록 위험합니다 — 직관과 반대

국고채가 `6`, 코코본드가 `2`, 전환사채가 `1` 인 게 이상해서 전수 확인했습니다.

```sql
SELECT PD_RISK_GCD, COUNT(*), ROUND(AVG(SRFC_IRT),2),
       ROUND(100.0*SUM(CASE WHEN CRD_GRD IS NULL THEN 1 ELSE 0 END)/COUNT(*),1)
FROM domestic_bonds GROUP BY 1 ORDER BY 1;
```

| 위험등급 | 건수 | 평균 표면금리 | 무등급률 | 대표 |
| ---: | ---: | ---: | ---: | :--- |
| 0 | 58 | 3.55% | 81.0% | 🔸 미분류로 보임 |
| **1** | **15,950** | **4.77%** | **91.9%** | 회사채·전환사채 |
| 2 | 62 | 3.73% | 1.6% | |
| 3 | 282 | 5.29% | 1.1% | |
| 4 | 1,938 | 4.46% | 0.1% | |
| 5 | 13,696 | 3.47% | 0.0% | |
| **6** | **10,408** | **2.83%** | 28.1% | **국공채 2,137건 전량** |

- **국공채 2,137건이 100% 등급 `6`**
- 등급 `1` 은 표면금리가 가장 높고(4.77%) 무등급 비율이 91.9%
- 코코본드 96건은 `1`(42) · `2`(34) · `3`(20) 에만 분포

📖 한국 표준투자권유준칙의 **1등급(초고위험) ~ 6등급(초저위험)** 체계와 방향이 일치합니다.
🔸 원본 정의서가 없어 확정은 못 했으나, 위 4개 지표가 전부 같은 방향을 가리킵니다.

> 🔴 ***"위험등급 낮은 채권 추천"* 을 그대로 필터로 걸면 가장 위험한 채권이 나옵니다.**
> 📌 `domestic_bonds.md` §9.5 · 노트 §C.4 에 방향 표기 **미반영 — 추가 필요**

### ② `AA0` vs `AA` 가 한 행 안에서 동시에 보입니다

②번 채권: `CRD_GRD = 'AA0'` · `PD_EVCO_CRD_GRD = 'AA, AA, AA'`.
**같은 등급인데 표기가 갈립니다.** 두 컬럼을 비교·병합하기 전에 `0` 접미사 정규화가 필수입니다. → §D.5

### ③ 만기가 끝나면 수익률 8개가 통째로 `None` 이 됩니다

③④번이 그 예입니다. 이건 결측이 아니라 **"만기 종료" 상태의 신호**입니다.
`REMAINING_DAYS=0` · `DUR=0` · `COV=0` · `NDY_*=0` 이 함께 움직이고, `EVAL_PRICE` 만 마지막 값이 남습니다.

> 🔴 이 상태를 구분하지 않으면 *"평균 수익률"* 에 만기 종료분이 섞이고,
> 반대로 지워버리면 발행사 2,291곳(28.6%)이 통째로 사라집니다. → §D.1

### ④ 패딩이 실물로 확인됩니다

## 부록: 재현 방법

```python
import sqlite3
conn = sqlite3.connect("file:data/financial_products.db?mode=ro", uri=True)  # 읽기 전용
conn.row_factory = sqlite3.Row
row = conn.execute("SELECT * FROM domestic_bonds WHERE TRIM(PD_NO)='KR103502GB33'").fetchone()
for c in row.keys():
    print(f"{c:<24} | {row[c]!r}")   # !r 로 출력해야 패딩·None 이 보입니다
```
