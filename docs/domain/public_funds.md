## 1. 공모펀드란

📖 **펀드(집합투자기구)** 는 여러 투자자의 돈을 모아 운용사가 굴리고 결과를 투자자에게 돌려주는 상품입니다.
**공모(公募)** 는 불특정 다수에게 판매하는 것, **사모(私募)** 는 49인 이하 등 제한된 대상에게만 파는 것입니다.

📖 ETF·펀드·채권의 관계를 한 줄로:

| | 무엇 | 거래 방식 |
| :--- | :--- | :--- |
| **공모펀드** | 운용사가 굴리는 집합투자기구 | 판매사(증권사·은행)에서 **설정/환매** |
| **ETF** | 거래소에 상장된 펀드 | 주식처럼 **장중 매매** |
| **채권** | 발행자에 대한 채권(債權) 증서 | 개별 종목 매매 |

> 📊 **ETF도 법적으로는 펀드입니다.** 그래서 이 테이블에 상장지수투자신탁이 섞여 있습니다.
> `itm_nm LIKE '%상장지수%'` 인 종목이 존재하며, 국내ETF마스터와 **중복 수록**됩니다.
> → 상품군 교차 질의 시 같은 상품이 두 번 세어질 수 있습니다.

📖 **자본시장법상 펀드는 5종**으로 나뉩니다. 주최 측이 제시한 `axis_fundType` 이 정확히 이 분류입니다 (§4).

| 법적 분류 | 무엇에 투자하나 |
| :--- | :--- |
| **증권펀드** (SecuritiesFund) | 주식·채권 등 증권 |
| **부동산펀드** (RealEstateFund) | 부동산·부동산 관련 권리 |
| **특별자산펀드** (SpecialAssetsFund) | 증권·부동산 외 (원자재·선박·인프라 등) |
| **혼합자산펀드** (MixedAssetsFund) | 위 셋에 제한 없이 |
| **단기금융펀드 / MMF** (MoneyMarketFund) | 단기 채권·CP 등. 원금 안정성 중시 |

## 2. 이 데이터셋의 구조 ★가장 중요★

**이 절을 모르면 거의 모든 집계 질의가 틀립니다.**

### 2.1 행 하나 = (종목 × 속성태그)

📊 `public_funds` 95,619행은 **펀드 95,619개가 아닙니다.**

```sql
SELECT COUNT(*), COUNT(DISTINCT itm_no) FROM public_funds;
-- ▶ 95,619 행 / 11,139 종목  (평균 8.6배)
```

같은 종목이 **`prfd_attr_cd`(펀드별속성코드) 하나당 한 행씩** 반복됩니다.
종목당 태그 수는 **4~16개**이고, 이름·수익률·순자산 등 나머지 컬럼 값은 **모든 행에서 동일**합니다.

즉 이 테이블은 **종목-속성 롱포맷(long format)** 입니다.

```sql
-- 한 종목의 태그 확인
SELECT trim(prfd_attr_cd) FROM public_funds WHERE itm_no = 'KR5153450780';
```

### 2.2 `prfd_attr_cd` 태그의 종류 (228종)

📊 태그는 두 형태가 섞여 있습니다:

| 형태 | 예 | 의미 |
| :--- | :--- | :--- |
| `<문자><3자리숫자>` | `C103` `D102` `M111` `V101` | ❓ 속성 코드 — 의미 미해독 |
| **3자리 국가코드** | `CHN` `USA` `IND` `JPN` `VNM` `BRA` `RUS` … | **투자 국가** |

📊 국가 태그는 **1,550개 종목(13.9%)** 이 보유하며, 한 종목이 최대 3개까지 가집니다.

```
CHN 646 · USA 386 · IND 142 · JPN 134 · VNM 131 · BRA 66 · RUS 53 · HKG 30
KOR 23 · DEU 18 · IDN 13 · TWN 7 · MYS 6 · AUS 6 · FRA 3 · GBR 3 · ESP 3
```

> 🔵 **이게 중요한 이유:** `fd_ivst_rgn_desc`(투자지역)는 `아시아`·`글로벌` 수준 7종뿐인데,
> **여기에 국가 단위 축이 숨어 있습니다.** *"중국에 투자하는 펀드"* 질의는
> `fd_ivst_rgn_desc` 로는 못 잡고 `prfd_attr_cd = 'CHN'` 으로 잡아야 합니다.
>
> ⚠️ 단 커버리지가 13.9%라, 국가 태그가 없다고 해서 그 나라에 투자 안 하는 건 아닙니다.
> 답변 시 모수를 밝혀야 합니다.

📊 오염값: `'해외'` 1건 (한글이 태그 자리에 들어감).

### 2.3 3단 계층

📊 식별자를 정리하면 이런 계층이 나옵니다:

```
mtco_itm_no  (운용사종목번호)   4,660  ← 모펀드 / 운용 단위
   └ itm_no · std_itm_no        11,139  ← 클래스 단위 (실제 판매 단위)
        └ prfd_attr_cd            228종  ← 속성 태그 → 95,619 행
```

📊 검증 — `삼성MMF법인제1호`의 4개 클래스가 같은 `mtco_itm_no` 를 공유합니다:

```sql
SELECT trim(itm_nm), itm_no, mtco_itm_no FROM public_funds
WHERE itm_nm LIKE '삼성MMF법인%제1호%' GROUP BY itm_no;
-- ▶ C 클래스 / Cp 클래스 / Ce / Cpe(퇴직연금)  →  mtco_itm_no 전부 '0123604'
```

📊 **같은 `mtco_itm_no` 그룹의 88%(2,847/3,236)에서 순자산이 완전히 동일**합니다.
→ `fd_nast_suma` 는 **클래스별이 아니라 모펀드 합계**입니다 (§6.2).

## 3. 펀드 클래스 체계

📖 **같은 펀드라도 판매 경로·수수료 구조에 따라 여러 "클래스(종류)"로 나뉩니다.**
운용 내용은 동일하고 **투자자가 부담하는 비용만 다릅니다.**

📖 표준 클래스 기호:

| 기호 | 의미 | 특징 |
| :---: | :--- | :--- |
| **A** | 선취판매수수료 | 가입 시 수수료를 떼고 연 보수는 낮음 → **장기 투자 유리** |
| **B** | 후취판매수수료 | 환매 시 수수료 |
| **C** | 수수료 없음, 보수만 | 선취 없이 연 보수가 높음 → **단기 투자 유리** |
| **e** | 온라인 전용 | 같은 클래스보다 보수 저렴 |
| **S** | 펀드슈퍼마켓 전용 | 온라인 판매 채널 한정 |
| **P** | 연금 (Pension) | 연금저축·퇴직연금 계좌용 |
| **I** | 기관 전용 (Institutional) | |
| **F** | 법인·기관 전용 | |
| **W** | 랩(Wrap) 전용 | |

📖 조합해서 씁니다: `C-e` = 온라인 전용 C클래스, `C-P2` = 연금용 C클래스 2종,
`Cpe` = 연금 + 온라인.

📊 실제 데이터의 클래스 표기 (종목명 말미에서 추출):

```
C 620 · A 610 · Ce 287 · C-e 280 · C-Pe 256 · C-P 216 · C1 210 · Ae 207
A-e 207 · C2 202 · C3 195 · C4 191 · C-P2e 189 · C-P2 154 · C-I 111 · C-F 84 …
```

📊 **클래스 표기가 있는 종목은 4,878 / 11,139 (43.8%)** 입니다. 나머지는 클래스 구분이 없는 단일 펀드이거나 표기 방식이 달라 자동 추출이 안 된 경우입니다.

> ⚠️ **이 데이터셋에는 보수(fee) 컬럼이 자체가 없습니다.**
> 클래스의 핵심이 비용 차이인데 그 비용을 알 수 없습니다.
> *"어떤 클래스가 더 싼가"* 류 질의는 **반드시 "데이터 미제공"** 으로 답해야 합니다.

순자산이 완전히 같은 종목 그룹이 **1,592개** 존재합니다.

```sql
-- ❌ 상위 5개가 같은 펀드의 클래스로 채워짐
SELECT trim(itm_nm), fd_nast_suma FROM public_funds
GROUP BY itm_no ORDER BY fd_nast_suma DESC LIMIT 5;
-- ▶ 2~5위가 전부 '삼성MMF법인 제1호' 의 서로 다른 클래스 (각 12.44조원)

-- ✅ 모펀드 단위로 묶어야 함
SELECT trim(itm_nm), MAX(fd_nast_suma) AS aum FROM public_funds
WHERE fd_nast_suma IS NOT NULL
GROUP BY mtco_itm_no ORDER BY aum DESC LIMIT 5;
```

📊 단위는 **원(KRW)** 으로 보입니다 — 최대값 28,359,162,282,520 = 28.36조원
(삼성KODEX200, 실제 규모와 부합). 결측 13.1%.

## 7. 이 상품군 고유 함정 요약

전 상품군 공통 함정은 `docs/EDA_GUIDE.md` §8 을 보세요. 아래는 **펀드 전용**입니다.

| # | 함정 | 영향 |
| :-: | :--- | :--- |
| 1 | **행 = 종목 × 속성태그** (8.6배) | 집계 질의가 8.6배 과대 |
| 2 | **순자산이 모펀드 합계** | Top-N 에 같은 펀드가 반복 |
| 3 | **`rptt_ksd_itm_no` 더미값** 2,501행 | 무관한 펀드가 한 그룹으로 묶임 |
| 4 | **보수 컬럼 자체 없음** | 보수 질의는 전부 "데이터 미제공" |
| 5 | **사모 102행 혼입** | "공모펀드마스터"인데 사모가 섞임 |
| 6 | **상장지수(ETF) 혼입** | 국내ETF마스터와 중복 계상 위험 |
| 7 | 위험등급 결측 19.3% + 라벨 표기 흔들림 (`높은 위험`/`높은위험`) | 등급 필터 모수 축소 |
| 8 | 센티넬 `해당없음` — `prvo_fd_desc` 95,451건, `pers_corp_desc` 73,054건 | 결측률 오판 |
| 9 | 오염 레코드 — `zrin_fd_ivst_risk_gcd=20054.0`, `exchdg_yn='00080008'`, `thco_sale_yn='KRZ50226929C'` | 화이트리스트 오염 |
| 10 | `itm_nm` 패딩 6건, `prfd_attr_cd` 패딩 1,670건 | 정확일치 실패 |

> 🔴 **9번의 세 레코드는 같은 행일 가능성이 큽니다** — 컬럼이 한 칸씩 밀린 사례.

| **모자형(母子型)** | 자펀드가 모펀드에 투자하는 구조. 종목명의 `자` (예: `증권자투자신탁`) |
