## 1. 펀드란 무엇인가

### 1.1 한 문장

📖 **펀드(집합투자기구)** 는 *"여러 사람의 돈을 한 통에 모아, 전문가가 대신 굴리고, 결과를 지분대로 나눠 갖는 그릇"* 입니다.

핵심은 **"그릇"** 이라는 점입니다. 펀드는 회사도 아니고 상품도 아니고, **돈을 담아 굴리기 위해 법적으로 만들어낸 통**입니다. 그래서:

- 펀드 자체는 사람을 고용하지 않습니다 → **운용은 운용사가 대신** 합니다
- 펀드 자체는 금고가 없습니다 → **자산은 수탁사가 따로 보관**합니다
- 펀드 자체는 창구가 없습니다 → **판매는 판매사가** 합니다

**이 "역할 분리"가 이 데이터셋의 컬럼 구조를 그대로 결정합니다.** 아래 1.2가 핵심입니다.

### 1.2 돈과 역할의 흐름 ★

📖 펀드 하나에는 **최소 4~5개 기관**이 관여합니다. 서로 견제하도록 법이 강제한 구조입니다.

```
   투자자
     │  ① 돈을 넣는다 (설정) / 뺀다 (환매)
     ▼
 ┌─────────┐   판매사 (증권사·은행)          ← thco_sale_yn (우리 회사가 파는가)
 │ 판 매 사 │   고객을 만나고 계좌를 관리
 └────┬────┘
      │ ② 자금 전달
      ▼
 ╔═══════════════════╗
 ║   펀 드 (그릇)      ║  ← 이 테이블의 한 종목
 ╚═══════════════════╝
      ▲            ▲
      │            │
 ③ 운용 지시    ④ 자산 보관
      │            │
 ┌────┴────┐  ┌────┴────┐
 │ 운 용 사 │  │ 수 탁 사 │  (대부분 은행)
 └─────────┘  └─────────┘
 or_co_xtn_itt_cd  trusc_xtn_itt_cd

 그 외:
   · 사무관리회사 — 기준가 계산 (이 데이터엔 없음)
   · 평가회사     — 위험등급·성과 평가   ← zrin_* (제로인)
   · 금융투자협회 — 공시·표준분류         ← kofia_fd_ccd
   · 예탁결제원   — 증권 결제·번호 부여   ← ksd_itm_no
   · 금융감독원   — 등록·감독             ← fss_itm_no
```

> 📖 **왜 운용사와 수탁사를 나누나?**
> 운용사가 돈을 직접 들고 있으면 횡령할 수 있습니다. 그래서 **"지시하는 자"와 "보관하는 자"를
> 법으로 분리**합니다. 운용사가 망해도 펀드 자산은 수탁사에 그대로 있습니다.
> → 이래서 `or_co_xtn_itt_cd`(운용사)와 `trusc_xtn_itt_cd`(수탁사)가 **별도 컬럼**입니다.

📊 데이터로 확인되는 규모:

| 역할 | 컬럼 | 기관 수 |
| :--- | :--- | ---: |
| 운용사 | `or_co_xtn_itt_cd` | **55개** |
| 수탁사 | `trusc_xtn_itt_cd` | **17개** |

📊 기관코드는 **8자리 = 기관종별(4) + 기관번호(4)** 구조입니다:

```
or_co_xtn_itt_cd  = 0004 + 0010     ← 0004 / 0008 두 종별
trusc_xtn_itt_cd  = 0002 + 0054     ← 0002(93,152) / 0005(2,088) / 0016(313)
```

> ⚠️ **DB에는 선행 0이 손실된 채 들어 있습니다.** 원본 엑셀 `00040010`(문자열) →
> DB `40010.0`(실수). 앞 4자리 종별이 날아갔습니다. 원본 대조 시 주의하세요.

### 1.3 펀드의 "가격" — 기준가와 좌수

📖 주식은 1주에 얼마인지가 가격입니다. 펀드는 다릅니다.

- **좌(座)** — 펀드의 지분 단위. 주식의 "주"에 해당
- **기준가격(NAV)** — 1,000좌당 얼마인지. 보통 1,000원에서 시작
- **순자산** — 펀드가 굴리는 돈의 총액

```
순자산 = 기준가격 × 총 좌수 ÷ 1,000
```

📖 **기준가는 하루에 한 번만 정해집니다.** 장중 실시간 가격이 없습니다.
그래서 펀드는 "지금 얼마"라고 물을 수 없고, "어제 종가 기준 얼마"만 말할 수 있습니다.
ETF가 펀드인데도 장중 매매가 되는 건 **거래소에 상장**했기 때문입니다.

> ⚠️ **이 데이터에는 기준가도 좌수도 없습니다.** `fd_nast_suma`(순자산)만 있습니다.
> "이 펀드 기준가 얼마야?" 는 답할 수 없습니다.

### 1.4 펀드의 "거래" — 설정과 환매

📖 주식은 **다른 투자자와** 사고팝니다. 펀드는 **펀드 자체와** 거래합니다.

| 주식 | 펀드 | 뜻 |
| :--- | :--- | :--- |
| 매수 | **설정(設定)** | 돈을 넣으면 펀드가 좌를 새로 만들어 줌 → 펀드가 커짐 |
| 매도 | **환매(還買)** | 좌를 돌려주면 펀드가 돈을 내주고 좌를 소각 → 펀드가 작아짐 |

📖 그래서 **펀드는 거래할 때마다 크기가 변합니다.** 여기서 두 가지 분류가 나옵니다:

- **개방형 / 폐쇄형** — 언제든 환매할 수 있는가, 만기까지 묶이는가
- **추가형 / 단위형** — 나중에 돈을 더 넣을 수 있는가, 처음 모은 돈으로만 굴리는가

> 이 두 축이 주최 측 `axis_redemptionType` · `axis_issuanceType` 입니다.

📖 환매에는 **시차**가 있습니다. 오늘 신청해도 며칠 뒤 기준가로 정산되고 돈은 더 나중에 들어옵니다
(주식형은 통상 T+3~4영업일). 이 데이터엔 환매 조건 컬럼이 없습니다.

## 2. 펀드는 어떻게 나뉘는가

📖 펀드 분류는 **질문 5가지**로 정리됩니다. 이 데이터의 분류 컬럼들이 각각 여기에 대응합니다.

### 2.1 무엇에 투자하는가 — 법적 5분류

📖 자본시장법이 정한 분류입니다. **투자 대상의 비중**으로 갈립니다.

| 법적 종류 | 기준 | 데이터의 `or_attr_desc` |
| :--- | :--- | :--- |
| **증권펀드** | 증권(주식·채권)에 50% 초과 | 주식형 · 채권형 · 주식혼합 · 채권혼합 · 재간접 · `06`(파생형) |
| **부동산펀드** | 부동산에 50% 초과 | 임대형 · 대출형 |
| **특별자산펀드** | 증권·부동산 외 자산 (원자재·선박·항공기·인프라) | 특별자산 |
| **혼합자산펀드** | 위 셋 비중 제한 없이 자유롭게 | 혼합자산 |
| **단기금융(MMF)** | 단기 채권·CP 등만. 만기 제한 엄격 | MMF |

📖 세부 유형:

- **주식형** 주식 60% 이상 / **채권형** 채권 60% 이상
- **주식혼합** 주식 50~60% / **채권혼합** 주식 50% 미만
- **재간접(Fund of Funds)** — 개별 종목이 아니라 **다른 펀드를 사는 펀드**.
  해외 투자나 대체투자에 흔합니다. 📊 30,243행으로 두 번째로 많습니다
- **파생형** — 파생상품을 활용. 종목명에 `파생형`. 📊 `or_attr_desc = '06'`

> 📖 **MMF는 왜 따로 두나?** MMF는 사실상 "이자 붙는 현금" 역할을 합니다.
> 원금 손실을 극도로 피해야 해서 편입 자산의 만기·신용등급을 법으로 촘촘히 제한합니다.
> 법인의 여유자금 파킹에 대량으로 쓰이고, 그래서 **개별 펀드 규모가 압도적으로 큽니다.**

### 2.2 언제 사고팔 수 있는가

📖 §1.4의 개방형/폐쇄형 · 추가형/단위형. 대부분의 공모펀드는 **개방형 + 추가형**입니다.

### 2.3 누가 살 수 있는가

📖

| 축 | 뜻 | 컬럼 |
| :--- | :--- | :--- |
| **공모 / 사모** | 불특정 다수 대상 / 49인 이하 등 제한 | `prvo_pbff_desc` |
| **개인 / 법인** | 개인 전용, 법인 전용 펀드가 따로 있음 | `pers_corp_desc` |
| **전문투자자 제한** | 일반 투자자에게 못 파는 고위험 상품 | `pfiv_sale_cntl_tcd` |
| **판매 중단 여부** | 신규 가입을 막았는가 | `sale_yn` (`판매중`/`판매완료`) |
| **우리 회사 취급** | 미래에셋증권에서 파는가 | `thco_sale_yn` |

> 📖 **`판매완료`는 "청산"이 아닙니다.** 신규 가입만 막고 기존 투자자는 그대로 있습니다.
> "지금 살 수 있는 펀드"를 물으면 `sale_yn = '판매중'` 으로 걸러야 합니다.

### 2.4 어디에 투자하는가

📖

| 컬럼 | 뜻 |
| :--- | :--- |
| `ovrs_fd_desc` | 국내 / 해외 / 국내외혼합 |
| `fd_ivst_rgn_desc` | 지역 — 국내·글로벌·아시아·유럽·남미북미·이머징브릭스·중동아프리카 |
| `fd_estb_ctry_cd` | **펀드가 설립된 나라** (투자처가 아님). 📊 `410`=한국(ISO 3166), `000`=미지정 |
| `curr_cd` | 펀드 기준 통화 |
| `exchdg_yn` | **환헤지 여부** |

> 📖 **환헤지(換hedge)가 왜 중요한가.** 해외에 투자하면 수익이 두 갈래로 생깁니다 —
> **자산 자체의 수익** + **환율 변동**. 미국 주식이 10% 올라도 원/달러가 10% 떨어지면 수익은 0입니다.
> 환헤지는 이 환율 부분을 제거해 자산 수익만 남깁니다.
> 종목명 표기: **`(H)` = 헤지** / **`(UH)` = 언헤지**. 같은 펀드가 H형·UH형으로 나뉘어 팔립니다.

### 2.5 위험이 얼마나 큰가

📖 `zrin_fd_ivst_risk_gcd` — **제로인(Zeroin)** 이라는 국내 펀드평가사가 매긴 등급입니다.

```
1 매우 높은 위험  ←→  6 매우 낮은 위험
```

> ⚠️ **숫자가 작을수록 위험이 큽니다.** 직관과 반대입니다.
>
> 📖 그리고 이건 **제3자 평가사의 등급**입니다. ETF·채권 테이블의 위험등급과 **산출 주체와 기준이
> 다릅니다.** 상품군을 넘나들며 "위험등급 3등급인 상품" 을 물으면 서로 다른 잣대를 섞는 셈이라,
> 답변에 근거를 밝히는 게 안전합니다.

## 3. 왜 한 펀드가 여러 줄로 나타나는가

이 데이터를 이해하는 데 가장 중요한 도메인 지식입니다.

### 3.1 클래스 — 같은 펀드, 다른 비용

📖 **같은 펀드인데 판매 경로와 수수료 구조만 다른 여러 버전**이 존재합니다.
운용 내용·편입 자산·수익률이 **완전히 동일**하고, **투자자가 내는 비용만** 다릅니다.

왜 나누나? 판매 채널이 다양하고 투자 기간도 제각각이기 때문입니다.
장기 투자자에게 유리한 구조와 단기 투자자에게 유리한 구조를 하나로 만들 수 없어서, **같은 펀드를
여러 "클래스(종류)"로 찍어냅니다.**

📖 클래스 기호:

| 기호 | 뜻 | 누구에게 유리한가 |
| :---: | :--- | :--- |
| **A** | 가입할 때 수수료를 떼고(선취), 연 보수는 낮음 | **장기** — 오래 들고 있을수록 유리 |
| **B** | 환매할 때 수수료(후취) | 중장기 |
| **C** | 선취 수수료 없이 연 보수가 높음 | **단기** — 짧게 들고 나올 때 유리 |
| **e** | 온라인 전용 (창구를 안 거쳐 보수가 쌈) | 온라인 가입자 |
| **S** | 펀드슈퍼마켓 전용 | |
| **P** | 연금 계좌 전용 (Pension) | 연금저축·퇴직연금 |
| **I / F** | 기관·법인 전용 | |
| **W** | 랩(Wrap) 계좌 전용 | |

조합해서 씁니다: **`C-e`** = 온라인 전용 C클래스, **`C-P2`** = 연금용 C클래스,
**`Cpe`** = 연금 + 온라인.

📊 실제 데이터의 클래스 표기:
```
C 620 · A 610 · Ce 287 · C-e 280 · C-Pe 256 · C-P 216 · C1 210 · Ae 207 · A-e 207 · C2 202 …
```

> 🔑 **여기서 데이터의 중요한 성질이 나옵니다.**
> 클래스가 다르면 **종목번호는 다르지만 자산은 같은 통**입니다.
> 그래서 **순자산·수익률이 클래스마다 동일하게 기록**됩니다.
> 이건 데이터 오류가 아니라 **펀드가 원래 그렇게 생긴 것**입니다.
>
> 📊 `삼성MMF법인제1호`의 C / Cp / Ce / Cpe 네 클래스 → 순자산이 전부 12.44조원으로 동일.

> ⚠️ **그런데 이 데이터엔 보수(fee) 컬럼이 없습니다.**
> 클래스의 존재 이유가 비용 차이인데, 정작 그 비용을 알 수 없습니다.
> → "어떤 클래스가 싼가" 류 질의는 **데이터 미제공**으로 답해야 합니다.

### 3.2 모자형(母子型) — 자펀드와 모펀드

📖 운용 효율을 위해 **여러 자(子)펀드가 돈을 모아 하나의 모(母)펀드에 넣고, 실제 운용은 모펀드에서만**
하는 구조입니다. 종목명의 **`자`** 가 이걸 뜻합니다.

```
미래에셋코어테크증권자투자신탁(주식) 종류A
                    ↑
              모자형의 자펀드
```

📖 재간접(Fund of Funds)과 헷갈리기 쉬운데 다릅니다:
- **모자형** — 같은 운용사 내부에서 운용을 한 곳으로 모으는 **구조적 장치**
- **재간접** — 외부의 다른 펀드를 **투자 대상으로 사는 것**

### 3.3 종목명은 구조화된 정보다 ★

📖 펀드 이름은 아무렇게나 짓지 않습니다. **정해진 순서로 정보가 박혀 있습니다.**

```
미래에셋   코어테크   증권   자   투자신탁   (주식)   종류A
  │          │        │     │      │         │        │

```

```

             └─ 상장지수 = ETF

                      └─ 신종MMF = MMF 유형

한화2.2배레버리지인덱스증권투자신탁(주식-파생재간접형)종류A
        └─ 레버리지        └─ 파생 + 재간접
```

> 🔑 **종목명 파싱만으로 상당한 분류가 가능합니다.**
> `상장지수` → ETF, `자` → 모자형, `(H)`/`(UH)` → 환헤지, `종류X` → 클래스,
> `파생` → 파생형, `레버리지`/`인버스` → 배수형.
> 별도 컬럼이 없는 속성도 이름에는 들어 있습니다.

## 5. 이 데이터가 답할 수 없는 것 — 도메인상 당연한 것들

📖 "왜 이게 없지?" 를 미리 알아두면 `확인할 수 없음` 응답을 자신 있게 낼 수 있습니다.

| 없는 것 | 왜 없나 |
| :--- | :--- |
| **보수·수수료** | 클래스별·판매사별로 달라 마스터 한 줄에 담기 어려움. 투자설명서 영역 |
| **보유 종목(포트폴리오)** | 분기 단위로 공시되는 별도 자료. 마스터는 상품 속성만 담음 |
| **기준가·좌수** | 매일 바뀌는 시계열. 마스터는 스냅샷 |
| **설정일·만기일** | 마스터에 미수록 |
| **환매 조건(수수료·소요일)** | 투자설명서 영역 |
| **운용사 이름** | 코드만 수록 (§4.3) |
| **운용역·운용 전략 서술** | 미수록 |

> 🔑 **마스터 데이터는 "상품의 신분증"입니다.** 신분증에 오늘 기분은 안 적혀 있듯,
> 매일 변하는 값이나 문서로 관리되는 상세 조건은 여기 없습니다.
