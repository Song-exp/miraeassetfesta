## A. 데이터 구조 — 행 하나가 무엇인가

### A.1 `PD_NO` 가 PK입니다 ✅

```sql
SELECT COUNT(*), COUNT(DISTINCT TRIM(PD_NO)) FROM domestic_bonds;
-- ▶ 42,394 / 42,394
```

**행 하나 = 채권 한 종목.** 공모펀드처럼 클래스별로 쪼개진 구조가 **아닙니다.**
전부 12자리 ISIN 코드이고 42,393건이 `KR` 로 시작합니다 (1건은 `XS3`).

> 다른 3개 테이블도 PK 중복이 없습니다. 행 중복 이슈는 공모펀드에만 있습니다.

### A.2 종목코드 앞 3자리가 대분류와 대응합니다

### A.3 3단 분류 계층 — 🔴 **[정정] 16종·39종이고, 트리가 아닙니다**

```
STD_PD_MCLS_NM (6종) → STD_PD_SCLS_NM (16종) → BD_KND (39종)
     대분류                   소분류                채권종류
```

```sql

 WHERE STD_PD_SCLS_NM IS NOT NULL AND TRIM(STD_PD_SCLS_NM)<>'';   -- ▶ 16  (결측 13건)
SELECT COUNT(DISTINCT TRIM(BD_KND)) FROM domestic_bonds
```

### B.1 🔑 결측 해석 — 두 가지가 특히 중요합니다

**① 신용등급 41.6% 결측은 "모름"이 아니라 "무등급"입니다.**

국채·지방채는 원래 신용등급을 매기지 않습니다. 주최 측 축도 `NotRated` 로 따로 두고 있고, 샘플 100건 중 **49건**이 여기 해당합니다.

> **답변 정책:** *"확인할 수 없습니다"* ❌ → *"국채라 신용등급이 부여되지 않습니다"* ✅

> 🔴 **단, `CRD_GRD` 결측 = 무등급이 아닙니다.** 그중 **1,600건은 `PD_EVCO_CRD_GRD` 에 값이 있습니다.**
> 두 컬럼을 병합하면 모수가 **24,750 → 26,350** 으로 늘고, **진짜 무등급은 16,044건**입니다. → §D.5

**② 수익률 97.9% 결측은 "데이터 부실"이 아니라 "지금 안 팔고 있어서"입니다.**

```sql
SELECT TRIM(PD_EXG_MKT), COUNT(*), SUM(CASE WHEN BUY_YIELD IS NOT NULL THEN 1 ELSE 0 END)
FROM domestic_bonds GROUP BY 1;
-- ▶ 장내 24,749건 중 867건 / 장외 17,645건 중 14건
```

발행조건은 채권이 존재하면 있지만, 매수수익률은 **증권사가 지금 호가를 내고 있어야** 생깁니다. 🔸 *"미래에셋이 현재 개인에게 파는 채권"* 이 881건이라는 뜻으로 읽힙니다 — **실질적으로 장내 867건** (§D.12).

> 🔴 **정보 밀도가 시장별로 극단적으로 비대칭입니다** — 등급 있음: 장내 21,801 / **장외 2,949(16.7%)**.
> **장외의 등급 결측 83.3%는 "우량채 부재"가 아니라 "미평가"** 입니다. → §D.12

**컬럼은 세 층위로 갈립니다** — 값이 "언제 생기는가"가 다릅니다.

| 층위 | 컬럼 | 값 있는 행 | 언제 생기나 |
| :--- | :--- | ---: | :--- |
| ① **발행 조건** | `SRFC_IRT` `MAT_DT` | **42,392 (100%)** | 채권이 **존재하면** 반드시 |
| ② **평가 정보** | `EVAL_PRICE` `APPLIED_YIELD` | 31,823 (75.1%) | **평가사가 값을 매기면** |
| ③ **매수 정보** | `BUY_YIELD` 계열 7종 | **881 (2.1%)** | **증권사가 "지금 팝니다" 라고 내놓아야** |

```
평가O 매수X  :  30,942건   ← "값어치는 아는데 지금 파는 물건이 아님"
평가O 매수O  :     881건
평가X 매수O  :       0건   ← 완벽한 포함관계
```

**→ `BUY_YIELD` 결측은 *"값을 모른다"* 가 아니라 *"지금 매물이 아니다"* 입니다.**

> 🔴 **881건도 최종 답이 아닙니다.**
>
> | | 건수 | 비율 |
> | :--- | ---: | ---: |
> | `BUY_YIELD` 있음 | 881 | 2.1% |
> | └ 매수가능수량 > 0 | 325 | 0.8% |
> | └ **수량 > 0 이면서 만기도 안 지난 것** | **254** | **0.6%** |
>
> 📊 881건 중 **277건이 이미 만기 도래분**(§D.1)이고, 556건은 **호가만 있고 수량이 0**입니다.

> 🔴 **답변 정책:** *"수익률 높은 채권 추천"* 의 실질 모수는 **42,394건이 아니라 881건(2.1%)**,
> **실제로 오늘 살 수 있는 것은 254건(0.6%)**. **모수를 반드시 밝혀야 합니다.**

### B.2 🔑 결측을 한 가지로 처리하면 안 됩니다 — 7가지 유형

**이 도메인에서 "값이 비어 있다"는 최소 7가지 다른 뜻입니다.** 일괄 `dropna()` 하거나 일괄 `"확인 불가"` 로 답하면 전부 틀립니다.

| # | 유형 | 뜻 | 대표 사례 | 처리 |
| :-: | :--- | :--- | :--- | :--- |
| 1 | **구조적 부재** | 값이 **존재할 수 없음** | 국채의 `CRD_GRD` (§B.1) · 외화채권 6건의 소분류 (§A.3) | *"원래 부여되지 않습니다"* 로 **답변** |
| 2 | **상태 표현** | 결측 **자체가 정보** | `BUY_YIELD` 41,513건 = **"지금 판매 중 아님"** | *"현재 판매 중이 아닙니다"* 로 **답변** |
| 3 | **미산출** | 계산 대상이 아님 | `DUR` 13,376 · `REMAINING_DAYS` 10,645 (만기 도래분) | 모수에서 제외 + 사유 명시 |
| 4 | **복구 가능** | 다른 컬럼에 값이 있음 | `CRD_GRD` 결측 중 **1,600건이 `PD_EVCO`에 존재** (§D.5) | **병합 후 판단** |
| 5 | 🔴 **센티넬 위장** | `NULL` 이 아닌 값으로 결측 표현 | `AVG_ANNUAL_TAX_YIELD` 전량 `0` · `DUR=99` · `MAT_DT=99991231` · `DIRTY=0` | **`IS NULL` 로 안 잡힘** — 값 분포로 탐지 |
| 6 | 🔴 **복사 위장** | 다른 컬럼 값을 그대로 채움 | `DIRTY` 27,430건이 `EVAL_PRICE` 복사로 추정 (§D.10) | **탐지 가장 어려움** — 컬럼 간 동일성 검사 |
| 7 | ⚠️ **정상값 오해** | 비어 보이지만 **진짜 값** | `SRFC_IRT=0` 2,758건 = 할인채·CB (§D.11) | **결측 처리 금지** |

> 🔑 **판정 순서:** ⑦ 정상값인가 → ⑤⑥ 위장인가 → ④ 복구 가능한가 → ①②③ 어떤 부재인가
> **`IS NULL` 만으로 결측을 세면 ⑤⑥⑦을 통째로 놓칩니다.**

> 🔴 **`empty_column` 류 탐지기는 `NULL` 기준이라 ⑤⑥을 못 잡습니다** (§D.3에서 이미 확인).
> **→ 값 분포 기반 탐지기가 별도로 필요합니다** — §D.14.

### D.5 🔴 신용등급 `AA0` 표기 + 두 컬럼의 규칙 불일치 — **[갱신] 유도 규칙·병합 모수 확인**

```sql
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD) = 'AA';   -- ▶ 0    (!!)
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD) = 'AA0';  -- ▶ 1,713
```

**같은 테이블 안에서 두 컬럼의 표기 규칙이 다릅니다:**

| 컬럼 | 형태 | 예시 |
| :--- | :--- | :--- |
| `CRD_GRD` | 단일 등급, **중간값에 `0`** | `AA0` `A0` `BBB0` |
| `PD_EVCO_CRD_GRD` | **콤마 결합**, `0` 없음 | `'AAA, AAA, AAA'` `'AA, AA'` |

`PD_EVCO_CRD_GRD` 상위값 / 콤마 원소 개수(= 평가사 수):
```
'AAA, AAA, AAA'  6,427건   ← 3사 모두 AAA        3곳 평가 : 14,776
'AA-, AA-, AA-'  4,118건                        2곳 평가 :  7,829
'AAA, AAA'       4,065건   ← 2사만 평가          1곳 평가 :  2,361
'AA, AA'           732건   ← 🔴 AA0이 아니라 AA
```

> ⚠️ **자리와 평가사의 대응은 알 수 없습니다.** 첫 번째가 한신평인지 NICE인지 데이터에 없어 **평가사별 비교 불가**. 알 수 있는 것은 *"몇 곳이 봤고 갈렸나"* 까지.

**🔴 표기 규칙이 완벽하게 갈립니다**

```sql
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD)='AA';   -- ▶ 0
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD)='AA0';  -- ▶ 1,713
```

| 등급 | `CRD_GRD` | `PD_EVCO` 원소 |
| :--- | ---: | ---: |
| `AA0` / `AA` | **1,713** / 0 | 0 / **1,652** |

### D.10 🔴 [신규] `DIRTY` 컬럼 신뢰도 — 94.5%가 미산출 의심 + 이상값 4종

**§E.1 에서 "더티프라이스로 확정"했으나, 재조사 결과 컬럼 자체의 신뢰도가 낮습니다.**

```sql

SELECT COUNT(*) FROM domestic_bonds WHERE EVAL_PRICE = DIRTY;                            -- ▶ 27,430 (94.5%)
SELECT COUNT(*) FROM domestic_bonds WHERE DIRTY < EVAL_PRICE;                            -- ▶ 21
SELECT COUNT(*) FROM domestic_bonds WHERE DIRTY = 0 AND EVAL_PRICE > 0;                  -- ▶ 8
```

**🔴 ① 27,430건 동일 — "이표 직후"로 설명 불가**

§E.1 은 이를 *"이표 지급 직후라 경과이자 0"* 으로 해석했으나 **성립하지 않습니다.** 이 데이터는 한 시점 스냅샷이고 채권마다 이표일이 제각각인데 **94.5%가 같은 날 이표 직후**일 확률은 사실상 없습니다.

```sql
-- 동일 그룹의 표면금리 0 비율

 WHERE EVAL_PRICE=DIRTY;        -- ▶ 27,430 / 1,083  (3.9%)  ← 대부분 이표채
```

**→ `DIRTY` 미산출 시 `EVAL_PRICE` 를 그대로 복사한 것으로 추정** 🔸. **경과이자 = `DIRTY − EVAL_PRICE` 역산이 94.5%에서 0으로 나오며, 이는 "경과이자 없음"이 아닙니다.**

> 온톨로지에서 등급은 값만이 아니라 **as-of(평가 시점) 속성이 붙은 개체**로 설계.
> §I.3(B) "등급" 다의어(어느 평가사·최저·다수결)에 **"언제 평가"** 차원이 하나 더 필요합니다.

**② 🔴 등급일만 있고 등급값이 없는 2,819건 — §B.2 에 없는 "이력 흔적형" 결측**

```sql
SELECT COUNT(*) FROM domestic_bonds
 WHERE CRD_GRD_DT IS NOT NULL AND CRD_GRD IS NULL;      -- ▶ 2,819
-- 그중 PD_EVCO_CRD_GRD 로 구제되는 건 111건뿐 — 2,708건은 날짜 흔적만 남음
```

과거에 평가받은 흔적(날짜)만 있고 값이 사라진 상태입니다. 등급 취소·만료·수집 누락 중 무엇인지 미확정 🔸. **§B.2 결측 7유형 어디에도 안 들어가는 8번째 유형 후보**이고, §D.5 병합(+1,600건)으로도 안 잡힙니다.

**③ 🔴 `DUR = 0` 과 `DUR = NULL` 은 다른 뜻입니다 — 잔존 > 0 인데 듀레이션 0 인 500건**

| 분해 | 건수 | 판정 |
| :--- | ---: | :--- |
| `DUR=0` & 만기 도래 | 7,768 | 미산출을 0으로 — 무해 |
| **`DUR=0` & 잔존 > 0** | **500** | 🔴 **신종자본·영구채류** |

```sql
-- SK텔레콤 신종자본증권 2-2(사모/콜/후)   잔존 20,089일   DUR 0.0   COV 0.0
```

영구채는 실제로는 듀레이션이 **가장 긴** 축인데 0으로 기재되어 있어, §D.13 의 *"중도매도 → 듀레이션 1순위"* 정렬에서 **가장 위험한 채권이 가장 안전해 보이는 역전**이 생깁니다. `COV=0` 8,326건도 대부분 `DUR=0` 과 동행(8,268건)합니다. → §H-9c ⓒ · §H-10 ⓒ(영구채 450건)와 묶어서 처리.

**④ 🟡 "외화채권" 이중 장부 — 대분류 6건 vs 통화 표시 21건** *(2026-08-18 감사 정정 반영: ≠KRW 22건 중 1건은 오염값 '000')*

```sql
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CURR_CD) <> 'KRW';             -- ▶ 22 (오염값 '000' 1건 포함 — 실제 외화 21)
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(STD_PD_MCLS_NM) LIKE '외화%';   -- ▶ 6
-- 한화솔루션 1 USD(사모) · 현대캐피탈2091 (USD) · 링스켑코리아1-1(사모/콜) EUR  → 대분류 '회사채'
```

USD/JPY/EUR 표시 **15건이 그냥 `회사채`로 분류**되어 있습니다(사모·Conduit·은행채 위주). *"외화 채권 보여줘"* 를 대분류로 grounding 하면 6건, 통화로 하면 21건 — **`CURR_CD` 기준(오염 '000' 제외)이 정답**입니다. `graph` §5.2(코드가 분류를 보완)와 같은 패턴의 통화 판.

**⑤ 🟡 `ISU_DT = 0` 336건 — "발행조건 100%" 서술의 예외**

회사채 311 · 국공채 21 · 특수채 4. §B.1 층위 ①("채권이 존재하면 반드시")의 예외이자 §D.7 오염값 표 누락분입니다. §D.8 쿼리가 `ISU_DT > 0` 조건으로 암묵적으로 피해갔을 뿐 명시가 없었습니다. *"2020년에 발행된 채권"* 류 질의의 모수에서 **336건이 조용히 빠짐**을 명시해야 합니다.

**⑥ 🟢 `PD_STD_INFO_UPDATE` 결측 10,571건 = 전부 만기 도래분 (완벽 상관)**

```sql
SELECT SUM(REMAINING_DAYS > 0) FROM domestic_bonds
 WHERE PD_STD_INFO_UPDATE IS NULL;                      -- ▶ 0  (잔존 있는 결측이 없음)
```

**"갱신이 멈춤 = 죽은 종목"** 이라는 깨끗한 신호입니다. §D.1 4상태 플래그의 보조 판별자, §D.8 "행별 기준시점 근사 규칙"의 방증으로 활용 가능.

**검토 후 제외 판정** (신규 아님):

| 후보 | 판정 |
| :--- | :--- |
| 이름 3벌 (`PD_ABRV_NM` · 영문 2종) | 패딩+축약뿐 고유 정보 없음. 결측 26~72건. §D.4 `TRIM()` 범위로 충분 |
| `PD_RISK_GCD` 0등급 58건 · 2등급 62건 | §C.4 · §H-3 기존 안건 범위 |
| 세금수익률 5종 상호 관계 | §D.9 · §H-9 ⓐ~ⓓ 범위 내 (`CORP_PRETAX ≠ BUY_YIELD` 전 행 포함) |

## I. 역질문 설계 — 사람의 선택이 개입해야 정해지는 것들 💡 제안

> **상태: 아이디어 / 워크샵 안건.** 아직 구현·합의 전입니다.

### I.1 문제 — "데이터에 없음"과 "사람이 정해야 함"은 다릅니다

§10(`domain` 문서)이 정리한 *"답할 수 없는 것"* 은 **데이터에 없어서** 못 답하는 것입니다. 그런데 조사를 진행하며 **데이터가 완벽해도 못 정하는** 항목이 따로 쌓였습니다.

가장 뚜렷한 예가 **듀레이션**입니다 (§D.13):

```
만기까지 보유한다  →  가격이 18.5% 빠져도 받을 돈은 불변. 듀레이션은 무의미
중도에 팔 수 있다  →  듀레이션이 손익을 결정하는 핵심 지표
```

**같은 채권의 위험도가 사용자의 보유 의도에 따라 뒤집힙니다.** 이건 데이터를 더 모아도 해결되지 않습니다.

### I.2 ✅ 역질문은 "답변 실패"가 아니라 유효한 답변입니다

> 🔑 **평가 기준상 역질문은 결과를 내지 않아도 "답을 한 것"으로 간주되며,
> 근거 없이 지어낸 답(할루시네이션)보다 높게 평가됩니다.** *(팀 확인 사항)*

📖 **이건 설계 방향을 바꿉니다.** 애매한 질의에 **그럴듯한 단일 답을 만들어내는 것이 가장 나쁜 선택**이고, 되묻는 것은 **안전판이자 가점 요소**입니다.

**→ 그래도 3단 기준은 유지합니다.** 다만 이유가 다릅니다 — 채점 불이익이 아니라 **모든 질의에 되물으면 도구로서 쓸모가 없어지기 때문**입니다.

```
① 데이터로 결정 가능        →  그냥 답한다
② 합리적 기본값이 있음       →  기본값으로 답하고 가정을 명시한다
③ 분기 결과가 갈림 / 용어 다의 →  역질문한다        ← 애매하면 여기로 보낸다
```

> 🔑 **③으로 보낼지 애매하면 ③을 택합니다.** 잘못된 단정보다 되묻는 편이 낫습니다.
> ②를 쓸 때도 **가정을 반드시 문장으로 밝혀야** 같은 효과를 냅니다 — 밝히지 않은 기본값은 사실상 단정입니다.

### I.3 ③ 역질문 대상 — 두 갈래

**(A) 사용자의 선택이 있어야 정해지는 것**

| # | 역질문 | 분기별 답 | 근거 |
| :-: | :--- | :--- | :--- |
| 1 | **"만기까지 보유하실 건가요, 중간에 파실 수도 있나요?"** | 만기보유 → 듀레이션 제외하고 신용위험만 / 중도매도 → **듀레이션이 1순위 지표** | §D.13 |
| 2 | **"안전을 어떤 뜻으로 보시나요 — 떼일 위험, 가격 변동?"** | 부도위험 → **국공채**(`DUR` 4.52) / 금리위험 → **단기 회사채**(`DUR` 0.49) | §D.13 |
| 3 | **"시장 전체를 보실 건가요, 지금 살 수 있는 것만 보실 건가요?"** | 전체 → **16,349건** / 매수가능 → **58~325건** | §B.1 · §D.13 |

**1·2번은 답이 정반대로 갈립니다** — §D.13의 *"안전할수록 듀레이션이 높다"* 역설 때문입니다. 3번은 모수가 **50배 이상** 차이 납니다.

**(B) 🔴 질의 용어 자체가 다의적인 것 — 이 도메인의 핵심 위험**

📖 채권 용어는 **같은 단어가 여러 뜻**입니다. 임의로 하나를 골라 답하면 **틀린 답이 그럴듯하게 나갑니다.**

| 사용자가 쓴 말 | 가능한 뜻 | 고르면 달라지는 것 | 근거 |
| :--- | :--- | :--- | :--- |
| **"수익률"** | 표면금리 / **YTM** / 세후 / 예금환산 | 같은 채권이 1.875% ~ 4.2% | §D.9 · `domain` §4.3 |
| **"위험"** | 부도위험 / 금리위험 | **국공채가 최저 또는 최고** | §D.13 |
| **"등급"** | `CRD_GRD` / 평가사별 / 최저 / 다수결 | 258건에서 갈림 | §D.5 |
| **"만기"** | 만기일 / 잔존만기 / 듀레이션 | 영구채 450건이 57년으로 잡힘 | §D.11 · §D.13 |
| **"싸다"** | 가격 낮음 / 수익률 높음 | **정반대** (§4.2 가격↔수익률 역관계) | `domain` §4.2 |

> 🔴 ***"수익률 높은 채권"* 은 이 데이터에서 가장 위험한 질의입니다.**
> 표면금리로 답하면 **몇 년 전 발행 시점의 약속**을 알려주는 꼴이고(§4.3),
> YTM으로 답하면 **모수가 881건**이며(§B.1), 세전/세후가 또 갈립니다(§D.9).
> **되묻지 않고 하나를 고르면 그 답은 확인 불가능한 단정이 됩니다.**

**역질문 3원칙**

1. **선택지를 2~3개로 닫아서 제시** — 열린 질문이면 사용자가 답을 못 합니다
2. **각 선택지가 답을 어떻게 바꾸는지 함께 제시** — *"국공채가 나옵니다 / 단기 회사채가 나옵니다"*
3. **기본값을 하나 추천** — 사용자가 답을 안 해도 진행 가능해야 합니다

### I.4 ② 기본값 + 명시 대상 — 되묻지 않습니다

| 항목 | **기본값** | 명시 문구 | 근거 |
| :--- | :--- | :--- | :--- |
| 특수구조 채권 | **제외** | *"전환사채·영구채 등 15,306건 제외"* | §D.11 |
| 만기 도래분 | 🔴 **질의 유형에 따라 다름** — 매수·추천은 제외, **조회·설명·이력은 포함** | *"만기 종료된 상품입니다"* 라벨 부착 | §D.1 |
| 세금 기준 | **개인 세후** | *"개인 기준 세후입니다"* | §D.9 |
| 평가사 의견 갈림 | **보수적으로 최저등급** | *"평가사 간 이견이 있어 낮은 쪽 표기"* (258건) | §D.5 |
| 장내/장외 | **통제 후 비교** | 🔴 그룹 변수로 쓰지 않음 | §D.12 |
| 신용등급 결측 | **`PD_EVCO` 로 보강 후 판단** | *"국채라 등급이 부여되지 않습니다"* | §D.5 · §B.1 |

> 🔑 **②는 "조용히 필터링"이 아닙니다.** 기본값을 적용하되 **무엇을 걸렀는지 반드시 문장으로 밝혀야** 합니다. 안 밝히면 *"전체를 본 답"* 으로 오독됩니다.

### I.5 미결 — 워크샵에서 정할 것

1. ✅ **역질문이 채점상 유효한가** — **유효하며 할루시네이션보다 높게 평가됨** (§I.2). *"되물으면 불리하다"* 는 당초 우려는 **기각**
2. 🟡 **(B) 용어 다의성 5종의 역질문 문구 확정** — 특히 *"수익률"* 은 4갈래라 선택지를 2~3개로 줄이는 설계 필요
3. 🟡 기본값 6종의 타당성 합의 — **밝히지 않은 기본값은 단정과 같다**는 원칙 적용
4. 🟡 역질문 후 사용자가 답하지 않았을 때의 폴백 동작 (권장 기본값으로 진행 + 가정 명시)

## J. 실행 계획 📋 회의용

> **채권을 몰라도 읽을 수 있게 썼습니다.** 자세한 근거가 궁금하면 각 항목의 §번호를 찾아보세요.

### J.1 세 줄 요약

```
1.  데이터에 채권이 42,394개 있는데,
    지금 실제로 살 수 있는 건 254개(0.6%)입니다.

2.  나머지는 "쓸모없는 데이터"가 아니라 용도가 다릅니다.
    (이미 만기가 끝난 것 / 지금은 안 파는 것 / 성격이 특이한 것)
    그런데 어느 게 어느 쪽인지 표시가 없습니다.

3.  구분 없이 그냥 쓰면 에러가 안 납니다. 그냥 조용히 틀립니다.
    ← 이게 제일 위험합니다.
```

📖 **왜 "조용히 틀리는" 게 문제인가**

숫자가 안 나오면 우리가 알아챕니다. 그런데 **그럴듯한 숫자가 나오면 검수도 통과합니다.**

> 예) 채권 평균 만기위험도를 계산했더니 **2.0** 이 나왔습니다. 그럴듯하죠.
> 그런데 이미 끝난 채권을 빼고 다시 계산하면 **3.1** 입니다. **55% 틀렸는데 아무도 모릅니다.**

---

### J.2 발견한 문제 — 5가지로 묶으면

**① 이미 끝난 상품이 38% 섞여 있습니다** (16,180개) — §D.1

만기가 지나 사라진 채권인데 데이터에 그대로 남아 있습니다. **지우면 안 됩니다** — 발행한 회사 8,015곳 중 **2,291곳(28.6%)이 여기에만** 있어서, 지우면 *"○○회사 채권 알려줘"* 에 답을 못 합니다. **구분만 하면 됩니다.**

**② 일반 채권이 아닌 게 36% 섞여 있습니다** (15,306개) — §D.11

- 주식으로 바뀌는 채권 (2,337개)
- 만기가 아예 없는 채권 (450개)
- **회사가 부실해지면 원금이 사라지는 채권** (96개)
- 회사가 망하면 맨 뒤에서 받는 채권 (1,210개)

*"안전한 채권 추천"* 에 이런 게 섞이면 **심각한 사고**입니다.

**③ 빈칸이 다 같은 빈칸이 아닙니다** — §B.2

| 빈칸의 뜻 | 예 |
| :--- | :--- |
| 원래 없는 값 | 국채는 신용등급을 **안 매깁니다.** "모름"이 아님 |
| **"지금 안 팔아요"** | 판매 정보가 없는 건 값을 몰라서가 아님 |
| 다른 칸에 있음 | 등급이 비어 보여도 옆 칸에 **1,600개** 들어 있음 |
| **빈칸인 척하는 값** | `0`, `99`, `9999-12-31` 로 채워놓은 것 |

**→ 빈칸을 한꺼번에 지우면 답할 수 있는 것까지 버립니다.**

**④ 글자에 공백이 껴 있어 검색이 조용히 실패합니다** — §D.4

```
"일반회사채" 로 검색  →     188개   ❌
공백을 떼고 검색      →  13,998개   ✅   (74배 차이)
```

에러가 안 나고 **"결과 없음"** 이 나옵니다. 사용자는 그게 진짜 없는 줄 압니다.

**⑤ 그대로 믿으면 안 되는 숫자 칸이 있습니다** — §D.10 · §D.13 · §D.14

| 칸 | 문제 |
| :--- | :--- |
| 실제 결제금액 | **94.5%가 계산이 안 된 채** 다른 칸 값을 복사해둠 |
| 다음날 가격 | 8,503개가 **0원**으로 되어 있음 (오늘 1만원인데 내일 0원?) |
| 위험도 지표 | **1,035개가 계산상 불가능한 값** |

### J.3 그래서 뭘 만들어야 하나 — **"데이터에 라벨 붙이기"**

📖 원본 데이터에는 위 구분이 **하나도 표시돼 있지 않습니다.** 그래서 **우리가 라벨 칸을 새로 만들어 붙이고, 모든 작업을 거기서 시작**해야 합니다. 이게 안 되면 아래 모든 게 막힙니다.

**라벨 ① — "이 채권 지금 어떤 상태야?"** (4가지 중 하나)

| 상태 | 개수 | 추천에 쓸까 | 설명·조회에 쓸까 |
| :--- | ---: | :-: | :-: |
| **지금 살 수 있음** | **254** | ✅ | ✅ |
| 살아있지만 지금 안 팜 | 25,641 | ❌ | ✅ |
| **이미 만기 끝남 (옛날 자료)** | 16,180 | ❌ | ✅ |
| 만기일이 안 적혀 있음 | 319 | ❌ | ⚠️ |

**라벨 ② — "성격이 특이한 채권인가?"** (해당되면 표시, 중복 가능)

| 라벨 | 뜻 | 개수 |
| :--- | :--- | ---: |
| 조기상환 가능 | 회사가 만기 전에 갚아버릴 수 있음 | 12,119 |
| 사모 | 소수에게만 판 것, 개인은 접근 어려움 | 10,067 |
| 주식 전환 | 주식으로 바꿀 수 있음 | 2,337 |
| 후순위 | 회사 망하면 맨 뒤에서 받음 | 1,210 |
| 금리 변동 | 이자율이 계속 바뀜 | 643 |
| 만기 없음 | 영원히 안 갚아도 됨 | 450 |
| 주식 교환 | 다른 회사 주식으로 바꿀 수 있음 | 391 |
| 이자 분리 | 이자를 떼어 판 것, 사실상 무이자 | 221 |
| 🔴 **원금 소각** | 회사 부실해지면 원금이 사라짐 | 96 |

> 🔴 **하나만 고르는 분류가 아닙니다.** 만기 없는 채권 296개 중 **295개가 조기상환 가능이고 250개가 후순위**입니다. 한 채권에 여러 라벨이 동시에 붙습니다. → **각각 O/X 칸으로** 만들어야 합니다.

**라벨 ③ — "값 정리하기"**

| 만들 것 | 이유 |
| :--- | :--- |
| **공백 없앤 문자열** (모든 글자 칸) | 안 하면 검색이 74배 틀림 |
| **정리된 신용등급** | 표기가 두 가지(`AA` vs `AA0`)라 맞춰야 함. 합치면 **1,600개를 더 건짐** |
| **평가사끼리 의견 갈림 표시** | 258개. 보수적으로 볼 대상 |
| **만기까지 남은 날짜 다시 계산** | 원본과 **3,296개가 서로 안 맞음** |

### J.5 온톨로지 만들 때 조심할 것 — 4가지

**① 계층으로 만들면 안 되는 게 있습니다**

데이터에 분류가 3단계(대분류 → 중분류 → 세부종류)로 되어 있는데, **깔끔한 나무 구조가 아닙니다.** 가지가 서로 얽혀 있어요.

```
"일반사채" 라는 중분류  →  회사채에도 있고(30,116)  특수채에도 있습니다(842)
```

**→ 대분류만 그대로 쓰고, 중분류·세부종류로 상위를 역추적하면 안 됩니다.** (842개가 틀립니다) → §A.3

**② 값 목록(선택지)을 자동으로 뽑으면 안 됩니다**

| 하면 안 되는 것 | 결과 |
| :--- | :--- |
| 있는 값 그대로 목록화 | 39종이 **51종으로** 등록됨 (공백 때문) |
| 빈칸을 하나의 값으로 셈 | 없는 종류가 하나 더 생김 |
| 이상한 값도 목록에 포함 | *"`000` 이라는 통화가 있다"* 고 시스템이 믿음 |

**③ 조건(제약)을 잘못 걸면 데이터가 잘려나갑니다**

- 위험등급을 `1~5` 로 제한 → **10,408개(24.6%)가 차단됩니다.** 실제 값은 `0~6`
- 신용등급 목록에 `AA` 를 넣으면 → **0개가 매칭됩니다.** 실제 값은 `AA0`

**④ 라벨은 "종류"가 아니라 "O/X"로**

만기 없는 채권이면서 동시에 후순위이면서 조기상환 가능한 채권이 있습니다. **하나만 고르게 만들면 표현이 안 됩니다.** → §J.3 라벨 ②

### J.6 실제 질문이 들어오면 — 이렇게 동작합니다

📖 **공통 원칙 하나:** *"몇 개 중에서 고른 건지"* 를 항상 밝힙니다. 4만 개 중에서 고른 것처럼 말하면 안 됩니다.

**🔴 조심해야 할 4개**

**① *"안전한 채권 추천해줘"*** — 답이 **정반대로 갈립니다**

```
되묻기      "안전을 어떤 뜻으로 보시나요?"
             (a) 회사가 망할 위험이 낮은 것
             (b) 가격이 덜 출렁이는 것

(a) 라면 →  국채·공기업 채권          ← 그런데 이건 (b) 기준으로는 위험한 편
(b) 라면 →  만기가 1년 안 남은 것      ← 이건 (a) 기준으로는 안전하지 않을 수 있음

공통      원금 소각·만기 없음·주식 전환 채권은 무조건 빼기
끝에      "지금 살 수 있는 254개 중에서 골랐습니다"
```

> 🔴 **되묻지 않고 하나를 고르면 절반의 사용자에게 틀린 답이 나갑니다.**

**② *"AA등급 이상 안전한 채권"*** — 가장 조용한 오답

```
그냥 등급으로 거르면  →  원금 소각 채권 96개가 전부 통과합니다
                        (등급이 AA0·AA+·AA- 로 높기 때문)
올바른 동작          →  등급과 상관없이 이 96개를 따로 뺀다
                     +  "AA등급이지만 원금이 사라질 수 있는 상품은 제외했습니다"
```

**③ *"○○회사 채권 뭐 있어?"*** — 옛날 자료를 지웠다면 답 못 함

```
발행사 8,015곳 중 2,291곳(28.6%)은 이미 만기 끝난 채권만 갖고 있습니다.

❌ 지웠다면   "해당 회사 채권이 없습니다"        ← 거짓말
✅ 올바르게   목록을 보여주되 각각 "만기 종료(2025-03-15)" 표시
              + "지금 판매 중인 건 없습니다"
```

**④ *"이 채권 이자 언제 나와?"*** — 없는 걸 없다고 말하기

```
❌ 지어내기   "3개월마다 나옵니다"        ← 데이터에 그 정보가 아예 없음
❌ 뭉개기     "확인할 수 없습니다"
✅ 올바르게   "이자 지급 날짜는 이 데이터에 없습니다. 투자설명서를 보셔야 합니다.
              대신 이자율은 연 3.5% 입니다."
```

> 🔑 **"왜 없는지"까지 말하면 그것도 정보가 됩니다.**

**나머지 자주 나올 질문들**

| 질문 | 어떻게 처리 |
| :--- | :--- |
| *"수익률 높은 채권"* | 되묻기 — *"세금 떼기 전 기준인가요, 실제 받는 돈 기준인가요?"* |
| *"싼 채권 알려줘"* | 되묻기 — **"싸다"가 두 가지 뜻**입니다 (가격이 낮다 / 수익률이 높다). 둘은 정반대 |
| *"평균 이자율은?"* | *"만기 끝난 것 제외 25,895개 기준"* 이라고 밝히기. 안 빼면 틀림 |
| *"2020년에 나온 채권은?"* | **옛날 자료가 꼭 필요합니다.** 2020년 발행분의 62%가 이미 만기 |
| *"장외가 수익률 높아?"* | 🔴 **겉으로는 2배 높지만 거짓입니다.** 조건을 맞춰 비교하면 거의 같음 |
| *"이 국채 신용등급은?"* | *"국채는 신용등급을 매기지 않습니다"* — 빈칸이지만 정상 |
| *"듀레이션이 뭐야"* | 데이터 안 봐도 됨. 설명만 |
