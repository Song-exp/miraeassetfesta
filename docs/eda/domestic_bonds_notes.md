### B.1 🔑 결측 해석 — 두 가지가 특히 중요합니다

**① 신용등급 41.6% 결측은 "모름"이 아니라 "무등급"입니다.**

국채·지방채는 원래 신용등급을 매기지 않습니다. 주최 측 축도 `NotRated` 로 따로 두고 있고, 샘플 100건 중 **49건**이 여기 해당합니다.

> **답변 정책:** *"확인할 수 없습니다"* ❌ → *"국채라 신용등급이 부여되지 않습니다"* ✅

**② 수익률 97.9% 결측은 "데이터 부실"이 아니라 "지금 안 팔고 있어서"입니다.**

```sql
SELECT TRIM(PD_EXG_MKT), COUNT(*), SUM(CASE WHEN BUY_YIELD IS NOT NULL THEN 1 ELSE 0 END)
FROM domestic_bonds GROUP BY 1;
-- ▶ 장내 24,749건 중 867건 / 장외 17,645건 중 14건
```

발행조건은 채권이 존재하면 있지만, 매수수익률은 **증권사가 지금 호가를 내고 있어야** 생깁니다. 🔸 *"미래에셋이 현재 개인에게 파는 채권"* 이 881건이라는 뜻으로 읽힙니다.

> 🔴 **답변 정책:** *"수익률 높은 채권 추천"* 의 실질 모수는 **42,394건이 아니라 881건(2.1%)**.
> **모수를 반드시 밝혀야 합니다.**

### D.3 🔴 [신규] `AVG_ANNUAL_TAX_YIELD` 전량 `0`


### D.5 🔴 신용등급 `AA0` 표기 + 두 컬럼의 규칙 불일치

```sql
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD) = 'AA';   -- ▶ 0    (!!)
SELECT COUNT(*) FROM domestic_bonds WHERE TRIM(CRD_GRD) = 'AA0';  -- ▶ 1,713
```

**같은 테이블 안에서 두 컬럼의 표기 규칙이 다릅니다:**

| 컬럼 | 형태 | 예시 |
| :--- | :--- | :--- |
| `CRD_GRD` | 단일 등급, **중간값에 `0`** | `AA0` `A0` `BBB0` |
| `PD_EVCO_CRD_GRD` | **콤마 결합**, `0` 없음 | `'AAA, AAA, AAA'` `'AA, AA'` |

`PD_EVCO_CRD_GRD` 상위값:
```
'AAA, AAA, AAA'  6,427건   ← 3사 모두 AAA
'AA-, AA-, AA-'  4,118건
'AAA, AAA'       4,065건   ← 2사만 평가
'AA, AA'           732건   ← 🔴 AA0이 아니라 AA
```

> `'A-, CCC, CCC'` 처럼 **평가사마다 등급이 갈리는** 케이스가 실재합니다.
> **"이 채권의 등급"을 무엇으로 볼지 도메인 판단 필요** (최저? 다수결? 전부 표기?). 워크샵 안건.

### E.1 ✅ `DIRTY` = 더티프라이스 (확정)

```sql
SELECT COUNT(*) FROM domestic_bonds WHERE EVAL_PRICE <> DIRTY;   -- ▶ 1,588
```

29,018건 중 27,430건은 동일, **1,588건(5.5%)에서 다르고 항상 `DIRTY`가 큽니다** (예: 10,340 → 10,510).
경과이자가 붙은 만큼 크므로 더티프라이스 해석과 일치. 같은 27,430건은 이표 직후로 경과이자 0.

### E.2 ✅ `AVG_ANNUAL_TAX_YIELD` = 사용 불가 (확정)

§D.3 참조. 881건 전량 `0`.

### E.3 🔸 `NDY_` = 익일 — 정합적이나 미확정

```sql
-- DUR vs NDY_DUR (둘 다 non-null 29,018건)
-- ▶ 같음 8,832 / NDY 더 작음 13,818 / NDY 더 큼 6,368
```

대체로 작아지는 것은 하루 경과 시 듀레이션 감소와 일치. 커지는 6,368건도 **이표 지급일 통과 시 듀레이션이 튀는 현상**으로 설명 가능. `APPLIED_YIELD`와 `NDY_APPLIED_YIELD`는 대부분 동일 (수익률 동일, 시점만 이동).

> **원본 정의가 없어 확정 못 함.** 다른 평가 기준일일 가능성 잔존. 워크샵 안건.
