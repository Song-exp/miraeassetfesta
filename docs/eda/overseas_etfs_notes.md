## A. 데이터 구조

### A.1 식별자 — 국내와 다른 코드 체계

| 컬럼 | distinct | 판정 |
| :--- | ---: | :--- |
| `pd_itm_no` | 5,646 | ✅ **PK** — 단, 한국식 표준코드가 아니라 **티커** (`EES`, `CHGX.O`, `JQUA.K`) |
| `pd_itm_no_ma` | 5,646 | `pd_itm_no` 와 동일값 (국내는 달랐음) |
| `pd_isin_cd` | 5,587 | ISIN 국제표준코드 (`US9219378356`) — 결측 0.2% |
| `pd_lipper_id` | 5,588 | Lipper(글로벌 펀드평가사) ID |
| `pd_us_cik` | 374 | 미국 SEC 등록번호 (운용사 단위, 중복 많음) |

> ✅ PK 중복 없음. 행 하나 = ETF 하나. **국내ETF보다 식별자가 풍부** (ISIN·Lipper·CIK).

### A.2 ETN 혼입 — 국내보다 경미

```sql
SELECT pd_grp_no, COUNT(*) FROM overseas_etfs GROUP BY 1;   -- ▶ ETF 5,587 / ETN 59
SELECT COUNT(*) FROM overseas_etfs WHERE cu_etn_yn='Y';     -- ▶ 59
```
ETN 59건(1.0%)으로 국내(30.7%)보다 훨씬 적음. 구분 컬럼이 **2개**:
- `pd_grp_no` = `'ETF'`/`'ETN'` (국내와 동일)
- `cu_etn_yn` = `'Y'` 59건 (결측 99% = ETF는 빈칸)

추가: `cu_inverse_short_yn='Y'` 인 **인버스/숏 상품 171건** (레버리지 판별용).

### A.3 접두사 = 갱신주기 (국내와 동일)

`pd_`/`cu_`/`du_`/`wu_`/`ru_` 체계 동일. 단 **국내와 달리 `ru_`(실시간)가 채워져 있음**:
`ru_mkt_price` 결측 0.2% — 종가(`du_clpr`)로 백필된 것으로 보임 (국내는 100% 결측).

## B. axis_* — ⚠️ 해외ETF는 정답축 미제공

> 🔴 **국내ETF와 결정적 차이: 해외ETF schema `Sheet2_Sample` 에 `axis_*` 컬럼이 없습니다.**
> 주최 측이 해외ETF에는 분류축 정답을 제시하지 않았음 (국내ETF 7축·채권 8축·펀드 6축과 대조).

의미:
- 해외ETF는 **채점할 정답이 없음** → 분류축을 우리가 자체 설계해야 함
- 국내ETF에서 검증한 축 규칙(strategy·leverage 등)을 **동일 원리로 적용은 가능**하나 정확도 측정 불가
- 온톨로지 설계 시 **국내ETF 축을 기준으로 삼고 해외ETF를 정렬**하는 방향 → 워크샵 안건

## C. 컬럼 실측값 — 국내와 비대칭

### C.1 🔴 국내에 있던 핵심 컬럼이 해외엔 없음

| 컬럼 | 국내ETF | 해외ETF |
| :--- | :---: | :---: |
| `pd_risk_nm`/`pd_risk_cd` (위험등급) | ✅ 있음 | 🔴 **없음** |
| `du_er_1y` (1년수익률) | ✅ 있음 | 🔴 **없음** |
| `du_er_ytd`/`_1m`/`_3m`/`_6m` (기간수익률) | ✅ 있음 | 🔴 **없음** |

> 🔴 **결정적:** *"위험등급 낮은 해외 ETF"*, *"1년 수익률 높은 해외 ETF"* 는 **답할 수 없음.**
> 해외ETF는 위험등급도, 기간수익률(1일 제외)도 데이터에 없음. → 대량 "데이터 미제공" 발생.

### C.2 ✅ 국내보다 나은 것 — 총보수가 깨끗

| 컬럼 | 상태 |
| :--- | :--- |
| `cu_charge_rt` (총보수) | ✅ **결측 0%** (국내는 유효 67건뿐). 중앙값 0.49%, max 2.50% |
| `du_last_aum` (AUM) | ✅ 결측 3.3% (국내 16.2%). 단위는 USD |

> 총보수 0값 363건은 대부분 **레버리지/인버스 상품**(ProShares Ultra 등) + ETN 51건.
> 진짜 0인지 미입력인지는 국내와 달리 소수라 개별 확인 필요. **국내만큼 심각하지 않음.**

## D. 함정

| # | 함정 | 영향 |
| :-: | :--- | :--- |
| 1 | **위험등급·기간수익률 컬럼 부재** | 해당 질의 전부 "데이터 미제공" |
| 2 | **기초지수 센티넬 문자열** | 결측률 0.1%로 보이나 실제 52% (D.2) |
| 3 | **자산군·지역 영문** | 국내(한글)와 표기 불일치 → 교차질의 매핑 필요 |
| 4 | **미국 74.3% 편중** | "해외 ETF" ≈ 대부분 미국 |
| 5 | **du_er_1d 전부 0** | 수익률 질의 불가 |
| 6 | **상장시장에 숫자코드 혼입** | `101`·`102` 31건 (거래소 코드 미해독) |

### D.2 기초지수 센티넬 — IS NULL 로는 안 잡힘

```sql
SELECT COUNT(*) FROM overseas_etfs WHERE cu_base_index LIKE '%not provided%';   -- ▶ 1,984
SELECT COUNT(*) FROM overseas_etfs WHERE cu_base_index LIKE '%not available%';  -- ▶ 721
```
`Index is not provided by Management Company` 1,984 + `Index is not available on Lipper Database` 721
→ **실질 지수명 수록 약 2,941건 (52.1%).** distinct 1,733종으로 보이지만 절반이 센티넬.

### D.3 자산군·지역 국내 vs 해외 언어 불일치

| 축 | 국내ETF | 해외ETF |
| :--- | :--- | :--- |
| 자산군 | 주식·채권·원자재… (한글 8종) | Equity·Bond·Alternatives·Commodity… (영문 6종) |
| 지역 | 국내·미국·글로벌… (11종) | United States of America·Global·China… (**59종**, 국가 단위) |

> 🔴 *"미국 투자 ETF"* 질의: 국내는 `wu_inv_rgn='미국'`, 해외는 `wu_inv_rgn='United States of America'`.
> **교차질의 시 언어·입도 매핑 필수** → 워크샵 안건(F). `Alternatives`(대체투자)는 국내에 없는 자산군.

## F. 미해결 & 🔴 워크샵 안건

### F.1 워크샵에 가져갈 안건

| # | 안건 | 배경 | 관련 |
| :-: | :--- | :--- | :--- |
| 1 | **국내ETF ↔ 해외ETF 통합 방식** | 컬럼 구성·언어·보유 정보가 크게 다름. 하나의 ETF 클래스로? 분리? | §C.1, Q2 |
| 2 | **자산군·지역 언어 정규화** | 한글(국내) ↔ 영문(해외). `주식`↔`Equity`, `미국`↔`United States` | §D.3, Q5 |
| 3 | **해외ETF 분류축 자체 설계** | axis 정답 미제공. 국내 축을 이식할지 | §B |
| 4 | **위험등급·수익률 부재 대응** | 해외ETF는 위험등급/기간수익률 없음. "미제공" vs 외부보완 | §C.1 |
| 5 | **지역 계층 설계** | 59종 국가 → 대륙/글로벌 계층 (일본⊂아시아⊂글로벌) | §D.3, Q7 |
| 6 | **기초지수 독립개체 + 센티넬 처리** | 52%만 유효. 국내ETF와 같은 지수 추종 비교 가능성 | §D.2 |
| 7 | **구성종목 외부보완** (국내와 공통) | 배점 큰 교차질의. 미국 ETF는 SEC 공시(CIK 활용 가능) | Q9 |

> 📌 질문 5·9·11 답은 워크샵 전 T0 공유 (EDA_GUIDE §3).
