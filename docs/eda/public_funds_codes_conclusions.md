## 0. 근거 등급 — 판정마다 이 등급을 붙입니다

규칙의 강도는 근거 등급이 아니라 **"그 규칙이 만드는 문장이 틀릴 수 있는가"** 로 잽니다.
등급은 **말할 수 있는 범위**를 정합니다.

| 등급 | 뜻 | 답변에서 할 수 있는 것 |
| :-: | :--- | :--- |
| **A** | 도메인 법·구조 근거 + 데이터 정합 | **이유를 말해도 된다** |
| **B** | 독립 지표 여러 개가 일치 | **조건부로 말해도 된다** |
| **C** | 관측만. 인과 아님 | **사실만 병렬 서술. 이유 금지** |

> C급도 규칙으로 쓸 수 있습니다. C급 근거는 *"어느 컬럼을 읽어올 가치가 있는지"* 를
> 알려주고, 답변의 진실성은 **읽어온 값**이 보증합니다.

## 2. 🔴 `mtco_itm_no` 는 모펀드가 아닙니다 【A】

**이 항목은 2026-08-17 에 뒤집힌 것입니다.** 이전 문서들이 `mtco` 를 "모펀드"라고 부릅니다.

| 검사 | `mtco` = 모자형 모펀드라면 | 실측 |
| :--- | :--- | :--- |
| 모투자신탁·모투자회사 표기 | 있어야 함 | **0건** |
| 묶음 하나에 서로 다른 자펀드 여럿 | 그래야 함 | 2,798개 중 **203개(7.3%)** |
| 묶음 내 이름 동질성 | 낮아야 함 | 공통 접두 90%+ 가 **89.1%** |

→ `mtco_itm_no` 는 **클래스를 걷어낸 "펀드" 단위**(운용사 내부 관리 단위)입니다.

**용어 규칙**: `mtco` 단위는 **"펀드"** 로 부릅니다. **"모펀드"는 모자형의 모펀드에만** 쓰고,
이 테이블에는 없습니다. 실무에서 종류형(클래스)의 상위를 관행적으로 "모펀드"라 부르는 것과
자본시장법의 모자형 모펀드가 **다른 개체**인데, 이전 문서가 둘을 섞었습니다.

### 2.1 펀드의 진짜 키는 합성키 【A】

```
mtco 단독 distinct 4,573   vs   (or_co, mtco) 합성 4,643
65종의 mtco 값이 최대 3개 운용사에 걸침  →  단독 조인 시 남의 운용사 펀드와 뭉침
   예: mtco '0002221' 을 00040035 와 00080052 가 함께 사용
```

🔴 **`GROUP BY mtco_itm_no` 는 틀린 집계입니다.** 순자산·Top-N 이 어긋납니다.

### 2.2 자/일반 판정은 3분류 【B】

`mtco` 묶음은 자펀드일 수도 일반펀드일 수도 있으므로, **단위 이름을 "자펀드"로 해도 틀립니다.**
자/일반은 **그 펀드에 붙는 속성**입니다.

```
종목 기준   자펀드 7,196 (64.6%) · 일반 3,363 (30.4%) · 판정불가 510 (4.6%)
묶음 기준   자펀드 2,793 · 일반 1,421 · 판정불가 408 · 혼재 21
```

⚠️ **2분류로 밀면 안 됩니다.** 판정불가 510종목 중 60건이 `M109`(자펀드 신호)를 보유합니다.

### 2.3 클래스 다중성과 자/일반은 직교 【A】

| | 1클래스 | 2클래스+ |
| :--- | ---: | ---: |
| 자펀드 | 1,680 | 1,113 |
| 일반 | 948 | 473 |

세로(모→자)는 운용 구조, 가로(펀드→클래스)는 판매 구조입니다. *"다클래스 = 자펀드"* 가설은
정확도 52.6% < 기준선 60.0% 으로 이미 기각됐습니다.

## 3. 포함관계 — 3층 계층 【A】

```
[기관]   운용사 67개 (or_co_xtn_itt_cd)      수탁사 18개 (trusc_xtn_itt_cd)
          8자리 = 종별(4) + 번호(4)            8자리 = 종별(4) + 번호(4)
   │ 1:N
   ▼
[펀드]   (or_co, mtco) 합성키  4,643개
         예탁원 대표 묶음 rptt 2,624개   ← 경계가 다름 (§3.2)
   │ 1:N   평균 2.38 클래스 · 1클래스뿐 2,989개(64.4%) · 최대 20
   ▼
[클래스] itm_no  11,139개   ★ 속성 44컬럼이 붙는 주 노드
```

### 3.1 도메인 불변식: 펀드당 수탁사 1개 【A】

자본시장법의 운용/보관 분리가 데이터에서 성립합니다. **위반은 사실상 0건**입니다.

⚠️ **표면상 위반 9건(0.19%)은 데이터 오류가 아니라 키 오염이었습니다.**
9건 전부에서 수탁사가 갈리는 선이 **종목명이 서로 다른 펀드로 갈리는 선과 정확히 일치**했습니다:

```
02M7500   삼성가치인덱스(수탁 …020)  │  삼성밸류코어(수탁 …032)
00AG530   브이아이코리아통일르네상스 11종(032) │ 브이아이일본고배당포커스 1종(004)
02M4900   삼성중소형FOCUS 13종(003)  │  삼성알파클럽코리아롱숏 7종(081)
0230221   미래에셋국공채MMF 7종(081) │  미래에셋국공채**법인**MMF 1종(050004)
```

→ **이 불변식은 데이터 검증기가 아니라 키 품질 검사기로 씁니다.**
수탁사가 갈리는 묶음 = 키가 틀린 묶음.

### 3.2 두 기관의 "펀드" 경계가 다릅니다 【A】

```
예탁원 대표 묶음 2,610개  vs  운용사 펀드 묶음 4,225개  (양쪽 유효 10,612종목)
두 묶음이 완전히 같은 종목 68.0% · 예탁원 1묶음에 운용사 펀드 2개+ 인 경우 560개
```

어느 쪽이 틀린 게 아니라 **묶는 기준이 다른 것**입니다.

### 3.3 모펀드는 이 테이블에 없습니다 【A】

```
자투자신탁 7,191 + 자투자회사 29 = 7,220종목 (64.8%)
모투자신탁 0 · 모투자회사 0 · 모증권투자 0
```

도메인상 타당합니다 — 모펀드의 집합투자증권은 **자펀드만 취득 가능**해 투자자에게 팔 수 없고,
이 테이블은 판매 상품 마스터입니다.

→ 🔴 **자펀드의 실제 편입자산은 이 테이블 밖에 있습니다. 포트폴리오 질의는 구조적으로 답 불가.**
→ Holdings 를 외부에서 수집할 때 **모펀드 단위로** 구해야 합니다 (`docs/DATA_NEEDS.md` §2).

## 6. 결측 판정

### 6.1 값과 결측의 경계 — 더미가 대부분입니다 【A】

**`NULL` 만 결측으로 보면 틀립니다.**

```
fss_itm_no    결측 3,025 중 3,022 (99.9%)가 '000000000000'
kofia_fd_ccd  결측 2,891 중 2,879 (99.6%)가 '0'×20
rptt          결측  487 중  478 (98.2%)가 'KR0000000000' 류
mtco          결측   62 중   61 이 0패딩·반복문자
```

**작업 정의 (`eff_empty`)** — NULL · 공백 · `(KR)?0+` · `(.)\1+`

🔴 정규화 없이 조인하면 `'000000000000'` 하나에 **3,022종목이 뭉치고**,
Agent 가 *"등록번호는 000000000000입니다"* 라고 답합니다. **환각 감점에 정면으로 걸립니다.**

> ⚠️ **`eff_empty` 정의를 임의로 바꾸지 마세요.** 이 문서의 거의 모든 수치가 여기 의존합니다.
> 제외하지 않는 것: 비영숫자 오염(`'"0466580'`)·길이 이탈 — 복구 가능한 정보라서 따로 셉니다.

### 6.2 코드별 결측과 판매상태 【C】

| 코드 | 실질빈값 | 판매중에서 | 판매완료에서 | `missing_reason` |
| :--- | ---: | ---: | ---: | :--- |
| `itm_no` | 0 | 0 | 0 | — |
| `or_co` · `trusc` · `std` | 각 9 | **0** | 8 | `unresolved` |
| `ksd_itm_no` | 48 | **0** | 47 | `unresolved` |
| `rptt_ksd_itm_no` | 487 | **0** | 486 | `unresolved` |
| `mtco_itm_no` | 62 | 10 | 51 | `missing` |
| `fss_itm_no` | 3,025 | **1,139** | 1,885 | `unresolved` |
| `kofia_fd_ccd` | 2,891 | **1,004** | 1,886 | `unresolved` |

**앞 5종은 판매중 8,445종목에서 결측이 0건**입니다. 그러나 **단방향입니다**:

```
번호 없음 → 판매완료          100% 성립
판매완료 → 번호 없음          ❌  판매완료 2,693 중 2,207종목은 번호 보유
조건을 "판매완료 AND 평가데이터 전무" 로 좁혀도 1,638종목 중 442건만 빔
```

→ 🔴 **판매완료는 결측의 필요조건이지 원인이 아닙니다.**
답변에서 *"판매완료라서 없다"* 는 **거짓**입니다. `sale_yn` 을 직접 읽어 **두 사실을 병렬**로 씁니다:

```
✅ "이 상품은 판매완료(신규 가입 중단) 상태이며, 해당 번호는 조회되지 않습니다."
❌ "판매완료 상품이라 번호가 없습니다."
```

⚠️ **`판매완료` 는 청산이 아닙니다**(도메인 §2.3). 답변에서 "청산"·"종료"로 쓰지 마세요.

### 6.3 `fss` · `kofia` 판매중 결측 — 원인 미확정 【C】

사실상 **한 현상**입니다 (판매중 `fss` 결측 1,139 중 994가 `kofia` 도 결측).

```
기각된 가설    역외펀드 0.0% · 상장지수 0.0% · 설립국가/통화 전원 000/KRW 로 구분 안 됨
관측된 편향    자펀드 17.9% vs 일반 1.7%  ·  종목번호 끝=M 36.7% vs 숫자 9.8%
              운용사별 0~47% (자펀드만 놓고 봐도 0~53.6% 유지)  ·  펀드 단위로 함께 빔 77.4%
결정적 사실    이 종목들은 예탁원 대표번호를 100% 보유  →  '미등록 펀드' 가 아니다
```

위험등급 100% · 순자산 92.9% · 당사판매 100% 인 **정상 판매 상품**입니다.
운용사별 부여·수집 관행 차이가 유력하나 **미확정**. 확정에는 금감원 등록 원부 대조가 필요합니다.

### 6.4 수익률 결측 — 우측결측 패턴 【B+】

```
전부 보유      5,482 (49.2%)
접미결측       1,994 (17.9%)   ← 앞쪽 연속 + 뒤쪽 전부 없음 (순수 우측결측)
구멍 있음        127 ( 1.1%)   ← 우측결측 아님. 별도 분류
전무           3,536 (31.7%)
```

기간 순서는 `1주 → 1개월 → 3개월 → 6개월 → **1년 → 18개월** → 2년 → 3년 → 5년` 입니다.

**근거**: 끊김이 기간 순서를 정확히 따르고, 순수 우측결측 대 구멍이 **94.0% : 6.0%** 입니다
(무작위 적재 누락이면 구멍이 더 많아야 함). 형제 클래스 대조가 이를 강화합니다:

```
형제가 더 긴 이력 보유   653종목 (32.7%)  → 펀드는 오래됨, 이 클래스만 신설
묶음 내 자기가 최장    1,341종목 (67.3%)  → 펀드 자체가 신생 후보
실물: _Ce(온라인) · C-Pe · Cpe(퇴직연금) = 나중에 생긴 판매 채널 클래스 → 구조가 설명됨
```

🔴 **답변은 주체를 클래스로 둡니다.**

```
✅ "해당 종목(클래스)의 운용 이력이 짧아 N년 수익률이 아직 산출되지 않았습니다"
❌ "설정 후 기간이 짧아 ..."   ← 32.7% 에서 거짓 (펀드는 오래됨)
```

⚠️ **무효화된 근거**: 이전에 근거로 적혀 있던 *"위험등급·순자산 보유율 100%"* 는 **판별력이 0**입니다
— 전부보유 그룹도 100%입니다. 이 지표는 "전무 그룹과 다르다"만 말합니다.

### 6.5 답변 계층 3단

| 층 | 상황 | 처리 |
| :-: | :--- | :--- |
| **0** | 더미값 | **값이 아니라 결측으로 정규화** (조회 계층. 프롬프트에 원값이 닿지 않게) |
| **1** | 원인 명확 | `sale_yn` 등 조건을 직접 읽어 **병렬 서술** |
| **2** | 원인 미확정 | "마스터 데이터에 제공되지 않아 확인할 수 없습니다" |

2층에서도 **대체 식별자는 제시할 수 있습니다** — `fss` 가 없어도 `ksd_itm_no` 는 100% 있습니다.

## 8. 온톨로지 / KG / 가드레일 분담

가르는 질문은 하나입니다 — **"데이터가 0건이어도 참인가?"**

| 계층 | 담는 것 | 이 문서의 어느 항목 |

| **온톨로지 (`.ttl`)** | 클래스·속성·관계·제약 | 카디널리티(§3.1 수탁사 1개, 필수/선택) · §3.3 "없음" 선언 · §4 별칭 속성 |

| **가드레일 (`yaml`)** | 값이 없을 때 어떻게 답하는가 | §6.2~6.5 전부 |
