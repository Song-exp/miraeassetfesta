## A. 데이터 구조 — 행 하나가 무엇인가

### A.1 3단 계층

```
mtco_itm_no (운용사종목번호)   4,660  ← 운용 단위 = 모펀드
   └ itm_no (종목번호)        11,139  ← 클래스 = 판매 단위
        └ prfd_attr_cd          228종  ← 속성 태그 → 95,619 행
```

**행 = (클래스 × 속성태그)** 이고, 종목당 태그가 4~16개라 평균 8.6배로 부풀어 있습니다.
이름·수익률·순자산 등 나머지 컬럼은 모든 행에서 동일합니다.

```sql
SELECT COUNT(*), COUNT(DISTINCT itm_no) FROM public_funds;
-- ▶ 95,619 / 11,139
```

계층 검증 — `삼성MMF법인제1호` 4개 클래스가 같은 `mtco_itm_no` 공유:

```sql
SELECT trim(itm_nm), itm_no, mtco_itm_no FROM public_funds
WHERE itm_nm LIKE '삼성MMF법인%제1호%' GROUP BY itm_no;
-- ▶ C / Cp / Ce / Cpe  →  mtco_itm_no 전부 '0123604'
```

### D.11 🆕 종목약어명은 유일하지 않습니다

`codebook('itm_no')` 결과 — **약어명 13종이 서로 다른 종목번호 여럿에 대응**합니다.

### D.9 `해당없음` 을 결측으로 본 것은 오판 — 정정

처음에 `prvo_fd_desc='해당없음'` 95,451건과 `pers_corp_desc='해당없음'` 73,054건을
센티넬(위장 결측)로 분류했습니다. **틀렸습니다.**

```sql
SELECT trim(prvo_fd_desc), trim(prvo_pbff_desc), COUNT(*)
FROM public_funds GROUP BY 1,2;
-- ▶ ('해당없음','공모') 95,451 / ('일반사모(2015년전)','사모') 102   ← 1:1 완전 대응
```

`'해당없음'` 은 **"공모라서 사모 세부구분이 없다"는 정보**입니다.
`pers_corp_desc='해당없음'` 도 "개인/법인 전용이 아닌 일반 펀드"라는 정보입니다.

이 오판으로 결측률이 **99.9% / 76.5%** 로 부풀려져 있었습니다. 실제는 각각 **0.1%** 입니다.

→ `ontology/enums/public_funds.yaml` 에 `not_applicable` 로 선언 완료.
→ 프로파일러의 `SENTINEL_PATTERNS` 도 `not_provided` / `not_applicable` 두 갈래로 분리했습니다.

**교훈:** `Not Provided`(제공 안 됨 = 결측)와 `Not Applicable`(해당 없음 = 정보)은 다릅니다.
한국 금융 데이터의 `해당없음` 은 대개 후자입니다.

## E-2. ✅ 해결 — 수익률은 **누적**입니다

연환산이 아니라 **누적 수익률**로 확정했습니다.

| 근거 | 내용 |
| :-- | :--- |
| ① MMF 복리 대조 | `1년 2.76% → 3년 10.50% → 5년 16.07%`. `(1.03)^5 = 15.9%` 와 일치. 연환산이면 3년도 3%대여야 함 |
| ② 유형별 패턴 | `5년 < 3년` 이 76%인데 **MMF만 98%가 `5년 > 3년`**. 손실 없는 상품만 계속 상승 = 누적의 특징 |
| ③ 시장 정합 | 기준일 기준 5년 전(2021-07) ~ 3년 전(2023-07) 하락 구간이 반영됨 |

```
유형        5년>3년 비율
MMF          98%   📈 손실 없음 → 계속 상승
채권형        46%
주식형        15%   📉 중간 구간 손실
혼합자산        9%
```

> ⚠️ **답변 시 "누적" 명시 필수.** *"3년 수익률 10.5%"* 를 연 10.5%로 읽으면 3배 오해입니다.

## E-3. ✅ 해결 — 수익률 결측은 **세 가지**입니다

**`설정일` 컬럼이 없습니다.** 그래서 펀드 나이를 알 방법이 중첩 패턴밖에 없습니다 —
*짧은 기간부터 차례로 채워졌는가?* 11,139종목을 전수 분류했습니다.

| 패턴 | 예 | 종목 | 비율 | 판정 |
| :--- | :--- | ---: | ---: | :--- |
| 완전 | `OOOOOOOOO` | 5,482 | 49.2% | — |
| **접미결측** | `OOOOO····` | 1,994 | 17.9% | **`not_applicable`** — 아직 그 기간이 안 됨 |
| **전무** | `·········` | 3,536 | 31.7% | **`missing`** — 🔴 신생이 아님 |
| **구멍** | `OOOO·OOOO` | **127** | **1.1%** | 데이터 오류 후보 |

**98.9%가 운용기간·미평가로 설명됩니다.** 이전 note 의 *"중첩 위반 수천 건"* 은
**행 기준 오독**이었습니다 (95,619행 기준). 종목 기준으로는 127개뿐입니다.

접미결측이 끊기는 지점이 기간 순서를 정확히 따릅니다:
`1주까지 21 · 3개월까지 132 · 6개월까지 295 · 18개월까지 511 · 3년까지 539`

### 🔴 '전무' 3,536종목은 신생 펀드가 아닙니다

패턴별로 **다른 컬럼**의 값 보유율을 대조하면 갈립니다:

| 패턴 | 위험등급 | 순자산 | 판매중 |
| :--- | ---: | ---: | ---: |
| 완전 · 접미결측 · 구멍 | **100%** | 100% | 98~99% |
| **전무** | **27.3%** | 47.7% | **26.2%** |

신생 펀드라면 위험등급과 순자산은 있어야 합니다. 전무 그룹만 **평가 데이터가 통째로 없고
74%가 판매완료**입니다. 운용유형 분포는 완전 그룹과 유사해 상품 성격 차이도 아닙니다.

→ **평가사(제로인)가 평가하지 않은, 대개 판매 종료된 펀드.** 위험등급 결측 덩어리와 같은 원인입니다.

### 답변 정책

| 패턴 | 응답 |
| :--- | :--- |
| 접미결측 | *"설정 후 기간이 짧아 N년 수익률이 아직 산출되지 않았습니다"* |
