## 심사관 지시 (qa-judge)

1. 위 8문항은 **판정 보류**. `보류(gold 결함)` 로 표시하고 ✅/✅값/🟡/❌ 어느 쪽으로도 세지 않는다.
   집계 표에 "판정 대상 N문항(보류 8 제외)" 로 분모를 명시한다.
2. **gold 파일을 고치지 마라.** 새 결함을 찾으면 이 문서에 항목만 추가한다.
3. 이 문항들에서 관찰한 **서버 측 결함은 정상적으로 §③ 에 올린다** — gold 가 못 쓴다고 서버 결함까지 덮지 않는다
   (예: `FND-008` 의 "서버가 해외채권형을 뺀다" 는 gold 와 무관하게 유효한 결함).
4. 🔴 **gold 수정을 제안할 때 "서버 답과 일치" 를 근거로 쓰지 마라.** 근거는 질문 문언 · 도메인 정본 · DB 실측 셋뿐이다.
