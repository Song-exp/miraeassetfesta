## 0. 이 트랙의 역할

층은 넷이고, **어느 층에 넣느냐가 성패를 갈랐다**(§3).

### 2.2 부재 선언 — 1건

`OFFICIAL-002`❌ 는 "세부 전략은 확인할 수 없습니다" 라고 부인해 놓고 바로 앞줄에서

보고서는 `absent_properties` 한 줄 추가를 제안했다. **그대로 넣으면 안 됐다** — 게이트는
질문 단위 전부-아니면-전무다(`gate.check` ①-0 즉시 return). 이 질문은 "**구조와** 투자전략"
복합이라 통째로 걸면 답할 수 있는 구조·보수·환매(`ext_fund_page` 실재)까지 죽는다.

→ `vocab` 을 **앵커 부정선행**으로 좁혀 순수 전략 질의만 걸고, 복합 질문은 `answer_rules` 가 잡게 했다.

```yaml
vocab: ["^(?!.*(?:구조|보수|수수료|환매|설정일|클래스|모펀드|수익률|순자산)).*(?:투자[ ]?전략|운용[ ]?전략|…)"]
```

채권 규칙은 그대로 발동한다. → 재현 시 **131펀드/187클래스** = gold.

> 부류: 여러 도메인이 같은 컬럼명을 쓰면 컬럼 단위 가드는 반드시 테이블로 한정한다.
> 실측 — 펀드가 다른 마스터와 공유하는 컬럼명은 `curr_cd` **하나뿐**이고 그게 터진 자리였다.

`pfiv` 항목이 *"전문투자자 조건은 `han_clas_policies LIKE '%전문투자자%'` 로 푼다"* 고
지시하고 있었는데, **그게 `DOM-12` 의 오답(27건)을 만든 경로다.** 게이트만 넣으면 두 층이
