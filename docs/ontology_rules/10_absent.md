# 규칙 10. 부재 선언 — 컬럼이 없다는 사실도 지식이다

> 값이 비어 있는 것과 **컬럼이 아예 없는 것**은 다르다. 후자는 HCX 호출 없이 즉시 기각한다.

> 🔴 생성물입니다. 서술·체크리스트는 `scripts/_ontology_rules_data.py`,
> 목록·수치는 `scripts/gen_ontology_rules_doc.py` 가 yaml·DB 에서 매번 새로 뽑습니다.

## 1. 데이터가 이랬다

- 해외ETF 에는 **기간 수익률 컬럼 자체가 없다.** 1일수익률 하나뿐.
- 해외ETF 에 위험등급 컬럼이 없고, 채권에 기초지수 컬럼이 없다.
- 이걸 모르면 플래너가 없는 컬럼으로 SQL 을 만들어 실행 오류를 낸다.

## 2. 그래서 이렇게 정했다

- `absent_in` 으로 **컬럼 부재를 선언**하고 `.ttl` 에 속성 부재로 기록.
- `build_ontology.py` **V6 검증** — 부재 선언했는데 실제로 컬럼이 있으면 빌드를 거부.
- 게이트가 이 선언을 보고 **HCX 호출 0회로 기각**한다.
- 주최 확정(OQ-2, 8/26): 해외ETF 1년 수익률 질의는 출제되지 않으며 교차 TOP-N 에서 **제외해도 무방**.

## 3. 전수 인벤토리 — 이 규칙이 실제로 어디에 선언돼 있나

#### (1) `absent_in` — 개체별 부재 선언 전수

> 컬럼이 **비어 있는 것**이 아니라 **아예 없는 것**. 게이트가 이걸 보고 HCX 호출 0회로 기각한다.

| 개체 | 부재 도메인 | 사유 |
| :-- | :-- | :-- |
| `AssetClass` | 채권 | 자산군 컬럼 없음 — 상품 자체가 채권. 클래스 계층(DomesticBond ⊂ Bond)으로 처리 |
| `CreditGrade` | 국내ETF | 신용등급 컬럼 없음 — ETF 는 발행사 신용등급을 갖지 않음. 위험등급(RiskGrade)과 별개 축 |
| `CreditGrade` | 해외ETF | 신용등급 컬럼 없음 |
| `CreditGrade` | 펀드 | 신용등급 컬럼 없음 — 채권형 펀드도 등급은 구성종목 단위(미수록) |
| `Index` | 채권 | 기초지수 컬럼 없음 — 채권은 지수 추종 상품이 아님. '지수 추종 채권' 질의는 기각 |
| `Region` | 채권 | 투자지역 컬럼 없음 — pd_ctry_cd(발행국)는 2차 21,881/21,882 행이 KR(XS 1행)인 사실상 상수 (1차 42,393/42,394 · enums 판정: kg_entity null) |
| `RiskGrade` | 해외ETF | 위험등급 컬럼 자체 없음 → '위험등급 낮은 해외ETF' 질의는 HCX 호출 0회로 기각 |

— 총 **7건**

#### (2) 실측 — 선언과 실제 스키마가 맞는가 (`build_ontology.py` V6 이 검사하는 것)

| 확인 | 실제컬럼 |
| :-- | --: |
| 해외ETF 수익률 컬럼 | du_er_1d |
| 국내ETF 수익률 컬럼 | du_er_1d, du_er_1m, du_er_1y, du_er_3m, du_er_6m, du_er_ytd |
| 해외ETF 위험등급 컬럼 | (없음 — 선언과 일치) |
| 채권 기초지수 컬럼 | (없음 — 선언과 일치) |

## 4. 근거 (라이브 DB 실측)

**해외ETF 의 수익률 컬럼은 하나뿐 — 국내ETF 와 대조**

| 테이블 | 수익률컬럼 |
| :-- | --: |
| 해외ETF | du_er_1d |
| 국내ETF | du_er_1d, du_er_1m, du_er_1y, du_er_3m, du_er_6m, du_er_ytd |

## 5. 안 지키면

없는 컬럼으로 SQL 을 만들면 실행 오류 → 무응답. 부재를 선언해 두면 **‘미수록’ 이라고 정확히 답한다.**

## 6. 검토 체크리스트

> 전수조사에서 나온 규칙이므로 **규칙 단위로 판정**한다. 각 항목에 결론과 근거를 적고,
> 판정이 바뀌면 `ontology/enums/*.yaml` 또는 `ontology/shared/*.yaml` 을 고친 뒤 재생성한다.

| # | 검토 항목 | 판정 | 근거·조치 |
| :-: | :-- | :-- | :-- |
| 1 | 부재 선언이 **개체 5종에만** 있다. 컬럼 수준 부재(해외ETF 기간수익률)는 어디에 선언돼 있는가 — `_absent_columns` 가 도메인 yaml 에 없다. |  |  |
| 2 | 게이트가 실제로 부재 선언을 읽어 기각하는가 — `tests/` 에 회귀 테스트가 있는가. |  |  |
| 3 | 부재인데 선언되지 않은 축이 더 있는가 — 도메인 × 축 교차표(`graph_sources_review` §0)와 대조. |  |  |
| 4 | ‘없음’ 을 답하는 문구가 `not_applicable` 과 구분되는가 — 컬럼 부재 vs 값 부재. |  |  |
| 5 | OQ-2 답변 반영으로 해외ETF 관련 부재 선언 문구를 갱신했는가. |  |  |
