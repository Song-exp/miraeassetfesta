## 🔴 반드시 지켜야 할 주최 지침 (8/24~25 Q&A)

> *"데이터 수집 방법 / 데이터 수집 및 적재 Flow / 데이터 활용 로직 등을 **보고서에 기재**.
> Repo에 데이터 저장만 하는 경우, 해당 데이터가 검색에서는 나오겠으나 **정성평가는 받지 못함**
> (담당자가 모든 소스코드 자체를 분석하지는 않으므로)"*

→ 우리가 모은 외부 데이터(구성종목 98만 행·코드북 9종·설명서 8,443건)는 **보고서에 안 쓰면 점수로 안 잡힌다.**

> *"결측치를 채우는 부분은 **Knowledge 구축 시 중요한 작업**으로, 진행하셨다면 보고서에 기재
> (어떻게 파악했는지, 어떤 식으로 채워서 결측률을 줄였는지, 그 외 적용·고민한 내용)"*

→ 결측 판정(`missing_reason`·`zero_is_value`·센티넬 분해)이 **정성평가 대상**. ETF 트랙 근거는 [`ontology_engineering_etf.md`](ontology_engineering_etf.md) §2.

> *"원천 데이터가 틀린 경우 답변에 문제를 초래하므로, **데이터의 신뢰성/무결성 관리 역시 과제의 일부**"*

→ 검증 게이트(V1~V7)·교차검증 사례를 서술 근거로 쓸 것.
