## 0. 한 줄 요약

🔴 **주최에 "이 코드·기호가 무슨 뜻이냐" · "판정 기준이 뭐냐" 를 묻는 경로가 닫혔다.**

## 1. 🔴 코드·기호 정의 — 답변 거부 (오늘 15:02)

우리 팀 서현이 국내채권 종목명 부기 기호 `(녹)/(사)/(지)` · `(강제)/(중)/(신)` 의 정의를 물었다.

> **주최 답변** — *"[공지사항] 말씀드렸다시피, **코드 및 기호등의 정의에 대해서는 말씀드리지 않는 것으로** 확인드렸습니다.
> 이 부분 **직접 확인 및 판단**하셔서 구분하시면 됩니다."*

8/24 공지 §0-B(*"코드 값 테이블을 드릴 수는 없을 것으로 보입니다 … 이 부분에 대한 질문은 없을 예정"*)의 연장이다.
그때는 **"코드를 묻는 질의가 안 나온다"** 는 뜻으로 읽었는데, 이번 답으로 **"우리가 물어도 안 알려준다"** 까지 확정됐다.

### 우리에게 미치는 영향

| 대기 중이던 문의 | 처리 |
| :-- | :-- |
| 채권 `(사)`·`(강제)`·`(중)`·`(신)` 정의 (회의 안건 4-3) | 🔴 **문의 종결** — 이미 `bd_ofr_tcd` 컬럼으로 공모/사모를 판정하도록 규칙화돼 있어 오답은 막힌다 |
| ETF `axis_assetType`·`axis_underlyingScope` 기준 3건 ([`axis_mismatch.md`](eda/domestic_etfs_axis_mismatch.md) §4) | 🔴 **철회** — 아래 §1-1 |
| ETF `pd_sect_cd` 5개 값의 뜻 | 🔴 문의 불가. 리드 확답(§5)대로 **섹터 컬럼을 안 쓰고** 지수명·상품명·구성종목 3축으로 우회한다 |
| ETF `cu_strtegy = 'C'` 422건의 뜻 | 🔴 문의 불가. **데이터로 이미 풀었다** — 422건 전건이 `pd_grp_no='ETN'` 이라 ETN 표기임을 확인(2026-08-31). 운용전략으로 말하지 않도록 `answer_rules` 에 기입 완료 |

### 1-1. `axis_mismatch.md` §4 주최 문의 3건 — 철회 확정

원래 방침은 *"컬럼을 정본으로 두고 주최에 문의"* 였다. **문의 경로가 닫혔으므로 앞부분만 남는다.**

- 실측상 **컬럼 매핑이 이미 92%** 로 가장 높고, 상품명 키워드로 바꿔도 92% 그대로다(§3).
- 남은 오분류는 **1건**(`TIGER 우선주`, KR7261140008)뿐이고 종목코드 예외로 처리했다(`query_rules.자산군오분류_제외`).
- → **컬럼을 정본으로 확정.** 문의 항목 3건은 §4 에 철회 표시.

> 📌 같은 유형이 또 나오면 **문자열 규칙을 새로 만들지 말고 종목코드를 추가**한다(서현 지적 반영분 유지).

## 2. 🔴 "판정 기준을 알려달라" 도 거부 (오늘 15:16)

타팀이 공모펀드 `sale_yn`(판매중/판매완료) 기준을 물었다.

> **주최 답변** — *"스키마 파일을 확인해보시면 되며, **Data Engineering 으로 충분히 확인**하실 수 있는 부분입니다. …
> 기준에 대한 명확한 컬럼이 있음에도, **정답 기준을 알려달라는 것은 이해가 되지 않습니다.**"*

톤이 세다. **명확한 컬럼이 있는 사안은 묻지 않는 것이 맞다**는 신호로 읽는다.

| 우리 상태 | 확인 |
| :-- | :-- |
| ETF `구매가능` = `pd_lste_dt = 99991231 AND pd_sale_yn = 1` | ✅ 컬럼 기반. 문의 없이 우리가 정했다 |
| 채권 판매가능 = 만기 경과 여부 | ✅ 컬럼 기반 |
| 펀드 `sale_yn` | 🟡 **펀드 담당 확인 필요** — 우리는 `sale_yn='판매중'` 을 기본 모수로 쓰고 있다(gold SQL 다수). 주최 답변이 그 방향을 지지한다 |

> 🔴 **앞으로 주최 문의는 "데이터로 판단 불가능한 것" 에만 보낸다.** 컬럼이 있는 사안은 보내면 역효과다.

## 3. 🟡 결측치를 채우면 정량평가에서 틀리나 — **미답변** (오늘 16:50)

타팀 질문. **우리에게 직접 걸린다.**

> *"팀마다 결측값은 임의로 채워질 수 있어 채점은 **결측값이 채워지지 않은 기존 엑셀파일을 기준**으로 할 것으로 예상됩니다.
> 만약 임의로 채워진 결측값으로 인해 정답과 달라진다면, 당연히 틀린 것으로 되겠지요?"*

8/26 주최 답변은 *"제공된 데이터가 아예 없을 때 결측값만 채우는 경우 … 결측값을 확인해서 정량평가를 하지 않을 것이기에 영향이 없을 것"* 이었으나,
**"채운 값이 답에 섞여 나오면 어떻게 되는가"** 는 아직 답이 없다.

### 우리 노출도

| 보강분 | 마스터 값을 덮나 | 위험 |
| :-- | :-- | :-- |
| `ext_etf_holdings` 국내 구성종목 75,859 | ❌ 마스터에 없는 축(구성종목) | 🟢 낮음 — 주최가 *"구성종목-상품"* 을 직접 고민 질의로 지목했다 |
| `ext_ovs_etf_holdings` 해외 906,848 | ❌ 동일 | 🟢 낮음 |
| `ext_fund_page` 10,565 | ❌ 웹 사실 | 🟢 낮음 |
| 국내ETF 총보수 외부 보완 | ⚠️ **마스터 컬럼을 덮는다** | 🔴 **미착수 상태 — 착수 전에 이 답변을 봐야 한다** |

**→ 조치: 총보수 외부 보완(A-4)은 이 답변 나오기 전까지 착수하지 않는다.**
리드 확답(§6)도 *"운용사 공시 수집은 후속 검토"* 로 보류였으므로 방침이 일치한다.
지금 규칙은 **채우지 않고 "수록되어 있지 않습니다" 로 답하는 것** 이고, 그게 8/24 공지 §0-C 와 정확히 맞다.
