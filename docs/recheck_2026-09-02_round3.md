- `_FALSE_HEDGE`·`strip_disclaimer` 는 HCX 경로가 사라지면 자연 소멸 — 확장하지 않는다(중복 방지).

**우선순위**: A(오거절 2 · 개별 조회 부류 전체) → B(운용사 집계 3 · 자릿수) → C(국가 목록 4) → D(T11) → E → F → G → H. A~D 는 서로 독립이라 병렬 가능; C-2/C-3 은 A-1 의 `_has_name_filter` 재사용과 같은 함수를 건드리므로 한 커밋으로.
