## 2. 🔴 공식 예시 #5 에코프로 — 정답을 찾고도 답변 거부

서버 실질의: SQL 은 조인·정렬 다 맞아 **1행 = KODEX 200**(㉡ 검증 때 확정한 그 정답)을 찾았는데,
SELECT 가 `pd_nm, cu_lev_fector` 뿐이라 답변기가 **"위험요인 정보가 없어 답변할 수 없습니다"** 로 통째 거부. 이름조차 안 밝힘.

- `query_rules.위험요인질의` 신설 — 위험 서술 재료 컬럼 명시(`pd_risk_nm`·`cu_lev_fector`·`du_vlty_1y`·자산군·이름). 1차 SQL 이 지어낸 `cu_risk_factor` 는 없다고 못박음
- `answer_rules` — **조회 1행 이상이면 "정보가 없다" 금지.** 상품명 밝히고 가진 컬럼으로 답하고, 빠진 항목만 "수록되지 않았습니다"
- 부수 확인: 환각 컬럼을 리드의 유사컬럼 힌트 + 내 수식자 소유 검사가 **협업으로 기각** — 가드 두 겹이 실전에서 함께 돈다
