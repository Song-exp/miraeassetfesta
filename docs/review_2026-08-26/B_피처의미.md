# B. 피처 의미

> 컬럼 하나하나가 정말 그 뜻인가 — 판정이 없는 것, 물려받은 것, 단위가 없는 것.

| | |
| :-- | :-- |
| **왜 보나** | 판정이 없는 컬럼은 **질의에 쓰면 안 되는** 상태다. 단위가 없으면 비교·정렬 답변을 만들 수 없다. |
| **어떻게** | 주최 한글명과 실측 값 분포를 보고 결측 사유·답변 정책을 정한다. |
| **담당** | 도메인 담당 4인 분담 |

> `판정` 칸에 **✅ 이상없음 · ⚠️ 확인필요 · ❌ 고쳐야함** 중 하나를, `근거·조치` 칸에 판단 근거와 고칠 곳(`ontology/enums/*.yaml` 등)을 적습니다.
