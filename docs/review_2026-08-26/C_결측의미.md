> 비어 있음이 무슨 뜻인가 — 답변 문장이 여기서 갈린다.

| | |
| :-- | :-- |
| **왜 보나** | `not_applicable` 을 “모릅니다” 로 답하면 오답이다. 분해가 없으면 문장을 고를 수 없다. |
| **어떻게** | 값별 분포를 보고 어느 값이 어떤 뜻인지 가른다. |
| **담당** | 채권 C-4-01 → **seohyun** · 국내ETF C-1-01~35·C-3-01 + 해외ETF C-1-36~53 → **Leebyungchul** · 펀드 C-1-54~62·C-2-01~09·C-3-02~10·C-4-02~06 → **song** |
| **방법** | [`에이전트검토_프롬프트.md`](에이전트검토_프롬프트.md) 의 지시서를 LLM 에 넣고 카테고리 단위로 보고받아 승인 → 기입 |

> `판정` 칸에 **✅ 이상없음 · ⚠️ 확인필요 · ❌ 고쳐야함** 중 하나를, `근거·조치` 칸에 판단 근거와 고칠 곳(`ontology/enums/*.yaml` 등)을 적습니다.
