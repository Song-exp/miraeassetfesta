## 채우는 법

> 🤖 **에이전트와 함께 채우는 방법·담당별 항목 범위·프롬프트는 [`에이전트검토_프롬프트.md`](에이전트검토_프롬프트.md)** — 지시서를 LLM 에 넣고 카테고리 단위로 보고받아 승인하는 방식.
> 📘 **판정 기준·채운 예시는 [`작성법.md`](작성법.md)** — 판정 세 글자의 기준, 채운 예시 4종, 고칠 yaml 위치 대응표, 반영 한 바퀴, 진행 관리 명령.


| 칸 | 적을 것 |
| :-- | :-- |
| `판정` | **✅ 이상없음** · **⚠️ 확인필요** · **❌ 고쳐야함** |
| `근거·조치` | 그렇게 본 근거와, 고칠 파일·위치 |

판정이 바뀌면 **원본을 고칩니다** — `ontology/enums/*.yaml`(컬럼 판정·질의 규칙) 또는 `ontology/shared/*.yaml`(개체·계층·부재). yaml 은 `loader.planner_context()` 를 통해 **플래너 프롬프트로 그대로 전달**되므로 판정을 고치면 답변 동작이 바뀝니다.
