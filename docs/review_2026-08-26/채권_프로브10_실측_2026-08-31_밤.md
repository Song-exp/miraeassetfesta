## 2. 문항별 진단 (SQL 경로 기준)

### Q2 한전 만기 최장 — 가드 성공 + 답변층 단위 환각
- SQL: `ORDER BY mat_dt DE…` — **ensure_maturity_sort 가드 정상 작동**(dur→mat_dt). 종목·만기일 정답.
- ❌ 답변 문장이 remaining_days **9,375(일)** 를 **"약 93.75년"** 으로 환산(÷100 환각). 실제 25.7년.
- 수정: `pipeline._cell` 이 잔존일수 칸을 **`9375일(약 25.7년)`** 로 렌더 — 답변기가 환산할 여지 제거. answer_rules 에 "그 표기 그대로 인용, 임의 환산 금지" 명시.

### Q5 가장 안전한 회사채 — 규칙 절반 학습(16 단독은 따르고 폴백은 놓침)
- SQL: `pd_risk_gcd = '16'` + 회사채 → 회사채 대분류는 6등급 0행(실측) → 0행.
- 원인: 위험등급방향의 "가장 안전한 = 16 단독" 은 이번엔 HCX 가 따랐는데, **"6등급 없는 종류면 IN ('15','16') 폴백 + 명시" 뒷조항을 미적용**.
- 수정: `ensure_top_safety` 에 역방향 완화 — 6등급 없는 종류(회사채·카드·캐피탈·보험·증권·일반은행채) 지목 + `='16'` 이면 `IN ('15','16')` 으로 완화. 기대 결과: SC은행 AAA 5등급 3종 + answer_rules 의 "6등급엔 회사채 없음 · 더 안전한 6등급 안내" 문구.

### Q8 국고채 몇 종목 — 조건 날조(발행사) + STRIPS 누락
- SQL: `TRIM(pd_pbcm) = '한국은행' AND TRIM(bd_knd) = '국고채권'` → 0행 "미수록".
- 원인 ①: **국고채권 발행사는 전부 '대한민국'(356행 실측)** — 한국은행은 통안채 발행사. 질문에 없는 발행사 조건을 HCX 가 날조.
- 원인 ②(잠재): 날조가 없었어도 `bd_knd='국고채권'` 단독은 **274종목** — STRIPS(종류 결측) 21종목이 빠져 정답 295(gold BND-D-029)와 어긋남.
- 수정: `ensure_ktb_kind` 확장 — (a) 질문에 없는 `pd_pbcm =` 등호 절 제거(질문이 발행사를 명시하면 유지) (b) bd_knd 단독을 확정식(STRIPS 분기 포함)으로 확장. 옛 "국고채권 있으면 불개입" 단정 폐기(테스트 갱신).

### Q9 A등급 이상 표면금리 top5 — 불완전 IN 목록 (가장 큰 수치 오답)
- SQL: `TRIM(crd_grd) IN ('AA-', 'AA0'…` (잘림) — 'A등급 이상' = 7종(AAA·AA+·AA0·AA-·A+·A0·A-)이어야 하는데 목록 불완전.
- 실측: 같은 모수(회사채·이표채·고위험제외)의 진짜 상위는 **우리금융캐피탈458 7.5% · 엠캐피탈355 7.5% · 한국토지신탁44-2 7.402%** — 서버 1위(SC은행 5.2%)보다 위에 **209종목** 실존.
- 기존 `expand_grade_comparison` 은 단일 리터럴(`crd_grd='A-'`)만 교정하고 IN 이 있으면 불개입 — 그 사각을 찔림.
- 수정: 질문에 등급+이상/이하 1개 + SQL 에 crd_grd IN 1개면 목록을 서열 확장식과 대조해 다르면 통째 교체. 옛 "IN 있으면 불개입" 테스트 폐기·갱신.
- 🔍 미해결 관찰: 응답 30.5초(15초 목표 초과, 60초 감점 한도 안) — 재생성 경로가 돌았을 가능성. 서버 think_trace 확인 필요.

### Q10 보험사 안전한 채권 — 방향 정답, 노출 문제만
- 0행 판정 자체는 정답(보험회사채 99행 전부 1등급 실측). SQL 도 서술형 매핑(보험사가 발행한→보험회사채) 정상.
- 🟡 개선 여지: 이상적 답은 "수록된 보험사 채권은 전부 1등급(매우높은위험)이라 안전한 것이 없다" — 현재는 사유 없는 "확인되지 않습니다". (판단 대기 — §4-4)

### 공통: "조건별 단독 조회: …" 노출 (Q5·Q10)
- 0행 진단(guard.diagnose_zero_rows)의 개발자용 텍스트가 **사용자 답변에 그대로 이어 붙고 있었음** (`pipeline` 0행 경로의 `answer += diag.text()`).
- 수정(팀 지적 반영): 진단은 **think_trace 전용**으로 이동 — 채점자용 근거는 trace 에 그대로 남고, 사용자 답변은 "조건에 해당하는 상품이 데이터에서 확인되지 않습니다." 한 문장.
