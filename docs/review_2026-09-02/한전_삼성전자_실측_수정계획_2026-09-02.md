## 2. 과정 결함 (전부 실측, 답이 맞았던 건 우연이거나 데이터 형편이 좋았던 것)

### A. 값 사전 검사(R-4)가 TRIM 감싼 컬럼에서 죽어 있음 — 🔴 최우선
- `guard._EQ` 는 `identifier = '리터럴'` 만 잡는다. `TRIM(pd_pbcm) = '삼성전자'` 는 `)` 때문에 미매치.
- `ensure_trimmed_compare`(pipeline 2834행, check_values 보다 **앞**)가 pd_pbcm·bd_knd 등호를 전부 TRIM 으로 바꾼다 → 발행사·종류 리터럴 검사는 사실상 0건.
- 실측: `pd_pbcm='삼성전자'` → 위반 검출 / `TRIM(pd_pbcm)='삼성전자'` → `[]` / `TRIM(crd_grd)='AAAA'` → `[]` / `TRIM(pd_pbcm)='한국전력공사'`(주 누락) → `[]`.
- 위험: HCX 가 '한국전력공사' 로 쓰면 0행 → "확인되지 않습니다" **오거절**. 검사가 살아 있으면 힌트 `'한국전력공사(주)'` 로 재생성된다.
- 안전성: kg_alias 의 pd_pbcm 값 1,818 = DB distinct 1,818 (100%), crd_grd 15/15 → TRIM 허용해도 정상 값 오기각 없음.

### B. COUNT = 0 결과가 HCX 로 넘어감 (비결정)
- 삼성전자 SQL 은 HCX 가 스스로 COUNT 로 냈다(`_COUNT_Q` 는 '있어?' 를 안 잡음). 결과 1행 값 0 → `n == 0` 조기반환을 타지 않고 compose 로 감.
- `ensure_positive_count_answered` 는 값 0 불개입, `_count_answer` 는 펀드 2열만. 이번엔 HCX 가 맞게 썼지만 "0종목입니다" / 날조 사이를 오갈 수 있다.

### C. 랭킹 제외에 만기 경과가 없음
- `_rank_exclusions` 4절(수익률>0·1등급·C0·사모)에 `mat_dt >= 20260822` 없음. 구매가능 규칙(만기 경과 제외)과 불일치.
- 실측: **'한전 채권 수익률 낮은 순'** → 1063(만기 2026-08-20 경과) 이 1·2위. 전체 만기 경과 49행, 최대 5.699%.

### D. 채권 목록 중복행(장내/장외) dedupe 없음
- 중복행 1,385 (1,078종목이 2~4행). 값은 같고 pd_exg_mkt 만 다름(applied_yield 상이 8종목).
- 실측: 발행사 **39곳**의 top5 에 같은 종목 2회 등장. 한전 낮은순 1063 ×2, 전체 낮은순 물가채 20-5 ×2.
- 펀드는 대표행 가드(GROUP BY 펀드키 + MAX/MIN)가 있고 채권은 없다 — 체계 비대칭.

### E. 상위 k 커버리지 미고지
- `_coverage_counts` 는 `n >= MAX_ROWS(30)` 에서만 발동. LIMIT 5 랭킹은 총량 재료가 없어 "전체 386종목 중 상위 5" 를 말할 수 없고, 답변 말미 "이외에도 다양한 만기와 수익률…" 은 근거 없는 채움말이 됐다.

### F. 채권 근거컬럼 미보강
- SELECT 가 pd_nm·applied_yield·crd_grd 만. 5.05%(만기 2052) 와 4.74%(만기 2038) 를 만기 없이 나열 — 정렬축 값은 있으나 판단 재료(mat_dt) 누락. 펀드 근거컬럼 가드의 채권판이 없다.

### G. 발행사 0건 되묻기 부재
- `_suggest_similar_products` 는 ETF `pd_abrv_nm` 만. 발행사 0건일 때 "삼성카드(323)·삼성증권(16) 채권을 말씀하신 건가요?" 역질문(정답형 ②) 재료를 버린다.

## 3. 수정 계획 (순서 = 우선순위, 전부 결정층·HCX 0회)

1. **guard.check_values TRIM/COALESCE 인식** — `_EQ`/`_IN` 을 `(?:COALESCE\()?(?:TRIM\()?\s*(tbl.)?col\s*\)?(?:,\s*''\s*\))?\s*=` 꼴로. `_value_hints` 에 어간 미포함 시 **앞 2글자 접두**(삼성→삼성카드…) fallback. 테스트: 위 4개 실측 케이스 + 정상 `TRIM(pd_pbcm)='한국전력공사(주)'` 통과.
2. **0-집계 결정층** — 단일행·단일 집계·값 0 이면 `n == 0` 경로와 같은 불가응답(HCX 미호출) + 발행사 유사후보 되묻기(7번과 함께). `ensure_positive_count_answered` 옆에 `ensure_zero_count_refused` 로 두고 compose **전**에 호출.
3. **`_rank_exclusions` 에 `mat_dt >= CUTOFF_INT` 추가** — 질문에 '만기 지난·경과·과거' 가 없을 때만. `ensure_maturity_sort` 가 이미 같은 절을 주입하므로 중복 주입 방지(`mat_dt\s*>=?\s*\d` 존재 검사 재사용).
4. **채권 대표행 가드** — domestic_bonds 단독 · 집계 없음 · 목록 SELECT 에 `GROUP BY pd_no` 주입, ORDER BY 컬럼은 MAX/MIN(DESC→MAX, ASC→MIN) 으로 감싸기. `_coverage_counts` 의 grouped 허용 목록에 `GROUP BY pd_no` 추가. 8종목의 상이 수익률은 대표행 규칙(정렬 방향 극값)으로 결정.
5. **랭킹 커버리지** — ORDER BY + 명시 LIMIT k < MAX_ROWS 인 채권 SQL 에도 `COUNT(DISTINCT pd_no)` 총량을 헤더에 굽는다: "(전체 386종목 중 상위 5)". `strip_false_hedge` 가 "이외에도…" 류를 커버리지 문장으로 치환하도록 규칙 확대.
6. **채권 근거컬럼 보강** — 정렬축이 applied_yield 면 SELECT 에 `mat_dt`(+`TRIM(crd_grd)` 없으면 추가) 주입. 펀드 `ensure_fund_evidence_columns` 와 동형.
7. **발행사 되묻기** — `_suggest_similar_products` 에 `TRIM(pd_pbcm)='X'` 분기: `TRIM(pd_pbcm) LIKE 'X[:2]%'` 발행사를 종목수 순 4개.
8. **회귀 고정** — `eval/questions_domestic_bonds.jsonl` 에 4문항: 한전 높은순(gold 5) · 한전 낮은순(1063 제외·중복 없음) · 삼성전자 발행(불가+역질문) · 한국전력공사(주 누락) 리터럴 재생성. `tests/test_guard_v2.py` 에 A·C·D 단위 테스트.

⚠ 체계 원칙(메모리 `detail-fixes-must-preserve-taxonomy`): 3·4 는 펀드 대표행·만기하한 가드와 **같은 문구·같은 CUTOFF 상수**를 써야 하고, 1 은 규칙 문서 R-4 절("값 사전이 완전한 컬럼에 한해")의 TRIM 예외 설명을 함께 고친다.
