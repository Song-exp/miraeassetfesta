### ③ 결론

**기준일 = 2026-07-11 확정.** 요청서가 상정한 세 갈래 중 **①주최 명시**다. 파일명 유래설(②)은 기각 — 파일명은 선언과 일치하는 방증일 뿐 출처가 아니다. 주최 확인 질문지(⑰)에서 기준일 항목을 뺄 수 있다.

**단, 2-24 증거는 반증이 아니라 다른 것을 재고 있었다.** 정리하면 두 날짜는 층위가 다르다:

- **2026-07-11 = 추출일** — 주최가 스냅샷을 뜬 날. 평가 기준 시점.
- **2026-02-24 = 채권 마스터의 내용 갱신 정지일** — 계산 컬럼(`REMAINING_DAYS`·`DUR` 등)이 이 시점에 굳어 있다.

둘의 차이 **137일**이 그대로 계산 컬럼의 지연으로 남는다.

**⚠️ 새로 확정된 함정 — `REMAINING_DAYS` 원값 사용 금지.**

7-11 기준으로 이미 만기가 지났는데 `REMAINING_DAYS > 0` 인 채권이 **3,296건**(`<` 경계 기준 · `<=` 기준 3,301건) 있다. 원값을 그대로 쓰면 이 3,296건이 "아직 살아있는 채권"으로 답변에 나간다. 매수 모수 254 는 `MAT_DT` 기준이라 무사했지만, "잔존만기 3년 이내" 류 질의는 전부 137일씩 밀린다.

대체 식을 만들어 검증했다. `MAT_DT` 가 REAL(`20260711.0`)이라 `julianday(MAT_DT)` 가 바로 안 먹혀 **CAST 2단계**가 필요하다:

```sql
CAST(julianday(substr(CAST(CAST(MAT_DT AS INTEGER) AS TEXT),1,4)||'-'||
substr(CAST(CAST(MAT_DT AS INTEGER) AS TEXT),5,2)||'-'||
substr(CAST(CAST(MAT_DT AS INTEGER) AS TEXT),7,2)) - julianday('2026-07-11') AS INTEGER)
```

검증: 이 식의 값이 `REMAINING_DAYS - 137` 과 정확히 일치하는 건 20,106건(84.0%, 역산 수렴분 전건). 이 식으로 잔존>0 은 **25,888건**.

## B2. 영구채 판정 건수(is_perpetual 450) 재확정 ✅ 확정 (08-21)

**쟁점** — 등재 건수 450 이 어떤 패턴으로도 재현되지 않았다(현행 `신종|영구` 473 · 도메인 문서 원패턴 467 · `신종자본` 단독 296). 어느 집합이 영구채인지 정하고 패턴·건수를 못박는 작업.

**왜 중요한가** — 영구채는 듀레이션이 0 으로 기재돼 있어 "금리위험 낮은 채권" 정렬에서 **가장 위험한 채권이 가장 안전해 보이는 역전**을 만든다. 집합 정의가 이 방어의 토대다.

### ① 검사 방법

요청서 §B2 는 "450 을 산출한 사람에게 먼저 물어보라"고 하지만 채권은 단독 담당이라 대상자가 없다. 대신 **레포에서 숫자를 역추적**했다 — `docs/` 전체에서 450 을 grep.

```
docs/eda/domestic_bonds_notes.md:788
| 신종자본 | `신종자본` 296 | + `(신종)` **450** | 1.5× |
```

이 표기를 그대로 코드로 옮겨 재현을 시도하고, 후보 4종의 차집합을 전 행 육안 판정했다.

```python
A = {n.strip() for n in names if re.search(r'신종|영구', n)}                 # 현행 yaml
B = {n.strip() for n in names if re.search(r'신종자본|[(/]신종[)/]', n)}     # 도메인 문서 해석
C = {n.strip() for n in names if '신종자본' in n}                            # 단독
D = {n.strip() for n in names if '신종자본' in n or '(신종)' in n}           # notes.md:788 재현 가설
```

오탐 잔여 점검은 `'신종'` 뒤에 오는 글자를 전수 조사했다.

```python
odd = set()
for n in names:
    for m in re.finditer(r'신종', n):
        nxt = n[m.end():m.end()+1]
        if nxt not in ('자', '(', ')', '/', ''):
            odd.add((nxt, n.strip()))
```

**(2) 그러나 450 은 오답 — 표기 변형 3종을 놓친다.**

## B5. 듀레이션 0 = "영구채 산출 불능" 판정 검증 ✅ 판정 교체 (08-21)

**쟁점** — 듀레이션이 0인데 잔존만기가 남은 채권 500건을 "영구채라 평가사가 산출을 못 한 표기"로 판정하고 `듀레이션정상` 규칙에서 제외해 왔다. 근거는 표본 예시(SK텔레콤 신종자본증권) + 도메인 논리뿐이고 500건 전수 확인이 없었다. **합격 기준: 패턴 부합 비율 ≥90%.**

### ① 검사 방법

요청서 §B5 의 지시대로 부합 비율을 재고, **미달이면 미부합 행의 유형을 규명**하는 데까지 갔다(B2 ⑥에서 미달이 예고돼 있었다).

```python
pool = [r for r in rows if r['DUR'] == 0 and r['REMAINING_DAYS'] and r['REMAINING_DAYS'] > 0]   # 500건
B5PAT = re.compile(r'신종자본|[(/]신종[)/]|영구|코코|조건부자본')   # 요청서 원안
miss  = [r for r in pool if not B5PAT.search(nm(r))]
```

미부합분에 대해 채권종류·잔존만기·동반 결측·장내외 구성을 교차 분해하고, 종목명 표본에서 공통 패턴을 찾았다. 가설이 나온 뒤에는 **역방향 검정**(그 속성을 가진 모집단이 실제로 DUR=0 이 되기 쉬운가)까지 돌렸다.

`듀레이션정상` 은 `DUR = 0` 만 막는다. 그런데 **듀레이션이 잔존만기와 전혀 안 맞는 채권이 1,101건 더** 있다.

### ⑤ 🔴 신규 발견 2 — `is_callable` 이 콜옵션 68행을 놓친다

## B4. "지금 살 수 있는 채권 254건" 해석 검증 ✅ 지지 + 정정 (08-21)

**쟁점** — 매수 정보 7컬럼이 42,394건 중 881건에만 있다(결측 97.9%). 이 결측을 "값을 모른다"가 아니라 "**미래에셋 진열대에 없다**"로 해석하고 추천 모수를 254 로 잡았다. 틀리면 "이 채권은 현재 판매 중이 아닙니다"라는 답변 전체가 오답이 되는, 채권 도메인에서 가장 위험한 단일 가정이다.

**⚠️ 범위 제약** — 요청서 최신본의 비수집 방침(2026-08-20): 254건(0.6%)이 적다고 타사 판매·호가 데이터를 수집해 메꾸지 말 것. 채권 시장은 기관 중심(관행 거래 단위 ~100억, 개인 비중 1~2%)이라 **이 비율 자체가 도메인과 정합**하다. B4 의 목적은 모수 확장이 아니라 해석 검증뿐.

### ① 검사 방법

두 가설을 경쟁시켰다.

- **가설 A (진열대)** — 결측이 구조적. 레코드 단위로 있거나 없거나, 대상이 리테일 성격을 띤다.
- **가설 B (수집 실패)** — 결측이 무작위. 컬럼별로 제각각 비고, 유형 편중이 없다.

구별 검정으로 **BUY 7컬럼의 결측 조합 분포**를 썼다. 수집 실패라면 조합이 흩어지고, 진열대라면 전부-있음/전부-없음 두 가지로 수렴한다.

```python
BUY7 = ["BUY_YIELD","CORP_PRETAX_YIELD","CORP_AFTER_TAX_YIELD","AFTER_TAX_YIELD",
        "PREF_TAX_YIELD","DEPO_EQUIV_YIELD_154","BUYABLE_QUANTITY"]
pat = collections.Counter(tuple(r[c] is not None for c in BUY7) for r in rows)
len(pat)      # 2^7 = 128 중 실제 등장 조합 수
```

이어서 254 의 성격을 전체와 대조했다 — 사모 비율, 특수구조 비율, 채권종류 분포, 거래 단위, 잔존만기.

### ② 결과

**(1) 🔬 결정적 — 결측이 완벽한 all-or-nothing.**

```
가능한 조합 128가지 중 실제 등장: 2가지
   41,513건   전 7컬럼 결측
      881건   전 7컬럼 존재
```

중간이 **하나도 없다**. 수집 실패라면 "3개만 있음", "5개만 있음" 같은 조합이 나와야 한다. **가설 B 기각.** 이 7컬럼은 레코드 단위로 통째로 채워지거나 통째로 빈다 — 진열 여부라는 단일 사실이 만드는 패턴이다.

**(2) 사모가 사라진다** — 사모는 개인에게 팔 수 없는 상품이다.

| 집단 | 사모 비율 |
| :--- | ---: |
| 전체 42,394 | **36.0%** |
| 매수정보 보유 881 | 0.1% |
| 추천 모수 254 | **0.4%** (1건) |

**(3) 특수구조도 사라진다.**

| | 콜 | 전환CB | 후순위 | 영구채 |
| :--- | ---: | ---: | ---: | ---: |
| 전체 | 28.6% | 5.5% | 2.9% | 1.1% |
| 254 | **1.2%** | **0.0%** | 1.6% | 0.8% |

**(4) 소매채권으로 편중된다.**

| 채권종류 | 254 중 | 전체 비중 | 배율 |
| :--- | ---: | ---: | ---: |
| 지역개발채 | 42.5% | 3.0% | 14× |
| 도시철도공채 | 24.0% | 0.6% | 42× |
| 국민주택1종 | 6.7% | 0.2% | 38× |
| 국고채권 | 7.1% | 0.7% | 10× |
| 일반회사채 | 7.1% | 33.0% | 0.2× |

상위 3종(**73.2%**)은 **첨가소화채권** — 부동산 등기·자동차 등록 시 의무 매입 후 즉시 되파는 채권으로, 증권사 소매채권 창구의 대표 상품이다. 반대로 기관용 대량 물건인 일반회사채는 33% → 7%로 줄었다.

종류별 매수가능 비율로 보면 더 뚜렷하다:
```
도시철도공채   61/   240 = 25.42%
국민주택1종    17/    74 = 22.97%
지역개발채    108/ 1,266 =  8.53%
국고채권       18/   298 =  6.04%
일반회사채     18/13,998 =  0.13%    ← 200배 차이
```

**(5) 잔존만기 중앙값 980일(2.7년)** — 개인 투자 기간대와 정합.

**(6) 🔴 반례 발견 — 개인투자용국채 49건이 목록에 없다.**

```
개인투자용국채 49건
   장외 49 / 장내 0
   BUY_YIELD 있음:  0건
   BUYABLE_QUANTITY > 0:  0건
```

이 상품은 **미래에셋 단독 판매대행**이다. "미래에셋이 파는 것 = 254"라면 반드시 들어 있어야 하는데 전건 결측이다.

원인은 상품 구조다 — 개인투자용국채는 **청약형(신규 발행)**이라 증권사 재고라는 개념이 없고, 유통시장도 없어 되팔 수도 없다. 즉 이 컬럼이 담는 것은 "미래에셋이 파는 전부"가 아니라 **소매채권 재고(2차 시장 매물)**다.

**(7) 부수 실측** — 254 중 장내 253 / 장외 1. 유일한 장외는 `LG전자 75(사모)`(AA0, 수량 68.6억)로, 254 중 유일한 사모이기도 하다.

### ④ 외부 대조에 대하여

요청서 §B4-2 는 미래에셋 앱/웹의 장외채권 판매 목록과 5종목을 대조하라고 지시한다. **미실시**로 남겼다. 이유:

- 합격 기준은 "사다리 재현 + 성격 부합/불일치 판정문"이고, 둘 다 내부 증거로 충족됐다. 외부 대조는 그 판정을 얻기 위한 수단이었다.
- (1)의 all-or-nothing 구조는 외부 대조보다 강한 증거다 — 재현 가능하고 표본 추출에 좌우되지 않는다.
- 지시가 지목한 "**장외**채권 판매 목록"과 실제 254(장내 253)는 대조 대상이 어긋난다. 대조하려면 **소매채권** 목록을 봐야 한다.

필요하면 미래에셋 소매채권 페이지로 5종목 대조를 추가할 수 있다 — 판정을 바꾸기보다 보강하는 성격이다.
