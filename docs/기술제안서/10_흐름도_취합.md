## §0. 취합 규칙 (네 절 공통)

- **7단 세로표** 고정: Route → Ground → Gate → Plan → 가드/검증 → 실행 → 조립. 오른쪽 열 = 읽는 온톨로지 요소(1 값 사전 · 2 규칙 문서 · 3 게이트).
- 표 아래 **think_trace 원문** 코드 블록(줄 번호 그대로, 긴 줄은 `…` 로 자르되 SQL 은 전문) + **응답 첫 3줄** + **시간·HCX 호출 수**.
- 캡션 한 줄: "규칙이 없을 때" 의 실측 오답(있으면 날짜).
- 조판 시 표는 그대로, 원문 블록은 회색 박스.
