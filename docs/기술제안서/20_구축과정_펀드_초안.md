## 1. 원본 데이터 EDA — 무엇을 읽었나
### 1.1 테이블 개요
- `public_funds` — **23,676행 × 75컬럼**, 기준일 2026-08-22 (v2_20260824). 소스 `prfd01n001_data.xlsx`.
- **행 = 클래스(판매 단위)** 다. `itm_no` 가 23,676 완전 유일이고 NULL 0.
- 1차 데이터는 행이 `(종목 × 속성태그)` 라 95,619행이었다 — 그냥 세면 **8.6배** 부풀었다. 2차에서 `prfd_attr_cd` 가 삭제되고 `prfd_attr_cds`(콤마 목록) 로 집약되어 행 폭발이 사라졌다. 그래서 1차의 "COUNT(*) 금지 · GROUP BY itm_no 선행" 규칙은 폐기됐다.
- 첫 발견의 뜻: "행 하나가 상품 하나가 아니다". 클래스를 걷어낸 **운용단위 펀드** 는 컬럼 하나로 안 나오고 복합키가 필요했다.

### 4.2 결함 → 선언 (06 §B.2 6건 압축)
**B.2-1. 행이 펀드가 아니라 클래스이고, 묶음 키로 보이는 `std_itm_no` 는 묶음 키가 아니다 → grain 선언 + 복합키 (2층)**
`std_itm_no` 는 18,948 중 18,909 가 `itm_no` 와 1:1. `row_grain` 을 "행 = 클래스" 로 선언하고 운용단위 키를 `(or_co_xtn_itt_cd, zero-pad 7자 mtco_itm_no)` 로 못 박았다(`query_rules.펀드단위`, 폴백 `itm_no`). 폴백 없이 세면 3,040 이 아니라 2,938 이 나온다. 순자산은 SUM 금지·MAX.

**B.2-2. 사모 8,960행 혼입 → 기본모수 `판매중 AND 공모` 강제 (2층)**
`query_rules.기본모수` — 집계·Top-N 은 WHERE 에 `sale_yn='판매중' AND prvo_pbff_desc='공모'`. 모수 8,969 를 답에 밝힌다. 2026-09-03 부터 enforce 슬롯이 빠진 조건을 주입한다(§4.3).

**B.2-3. 더미 키(`KR0000000000` 5,308 · fss 49.2%) → `dummy_as_missing` (2층)**
값을 고치지 않는다. 조인·개체 키에서 제외만 한다. 화이트리스트 밖 적용 금지 — 채권 `AAA` 8,722행이 죽는다.

**B.2-4. `prfd_attr_cds` 콤마 다중값 210종 15축 → `match_kind='token'` alias + 확정식 (1층·선언)**
`',' || prfd_attr_cds || ',' LIKE '%,C103,%'` 로 양끝 콤마 감싸기. 국가(ISO 3자)는 `Country` 17, 나머지는 `FundAttribute` 179 노드. 펀드유형은 개체가 아니라 `class_hierarchy` 하위클래스.

**B.2-5. 좌수·운용역·시계열 없음 → ABSENT 5건 (3층)**
`absent_properties` → ttl `# ABSENT:` + 게이트 정규식. KG-027(설정유형코드 `'10'` 을 "10좌" 로 6펀드 단언) 이후 도입. 기준가는 있으므로 '추이·변동' 에만 건다.

**B.2-6. 운용사·수탁사가 코드뿐, 약칭 라벨이 매칭 하한에 걸림 → 코드북 + `label_official` (1층)**
`asset_manager.csv` 275 · `trustee.csv` 18(50종 중). FND-034 "삼성자산운용 펀드" Ground 0 → 복구.

| 조립 | 구조(모/자·클래스 수·운용사·수탁사) + 페이지 항목 + **"투자전략 동향은 제공 데이터에 없음"** 명시 | "요청하신 내용은 제공된 데이터(기준일 2026-08-24)로 확인할 수 없습니다." (2.3초 · HCX 1회) | answer_rules |

- DB 에는 `itm_nm LIKE '%국민성장%'` 4행이 있다(10 §4.3). 실측 시점에는 `설명서항목` 규칙이 이 질의에 안 실려 `ext_fund_page` 이름이 프롬프트 어디에도 없었다 → 2026-09-03 트리거에 `구조·투자전략·전략·동향` 추가(§4.3). 수리 후 재실측 결과는 소스에 없음 `[리드 검토]`.
- 어느 쪽을 제안서에 실을지(실측 거절 그대로 vs 부분 답변으로 수리 후 재실측)는 10 §4.3 의 리드 판단 대기 `[리드 검토]`.
- 어느 경우든 "동향" 을 지어내지 않았다 — 모델은 복사만 한다. 값 접지는 그래프, 행 선택은 SQL.

### 6.2 집계 예 — "삼성자산운용 공모펀드 몇 개"
`펀드단위` enforce 슬롯이 작동하는 자리 (`docs/recheck_2026-09-03_round17.md` §2).
