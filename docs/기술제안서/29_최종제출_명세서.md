## 4. 옮기는 절차

경로가 깨질 일은 없다. 추출기가 `git ls-files` 의 **상대 경로 그대로** 복사하므로 폴더 구조가 원본과 같게 재현된다.

```bash
# 0) 무엇이 뽑히는지 먼저 본다 — 복사도 삭제도 하지 않는다
python scripts/make_submission.py --list

# 1) 제출 저장소를 빈 폴더에 새로 clone 한다
git clone https://github.com/miraeasset-aifestival-2026-product/fin-120.git ../fin-120

# 2) 그 안으로 추출한다 (원본은 그대로 둔다)
python scripts/make_submission.py --out ../fin-120

# 3) 옮긴 쪽에서 임포트가 되는지 본다 — 경로가 온전하다는 뜻이다
cd ../fin-120 && python -c "import src.runtime.pipeline; print('ok')"

# 4) 커밋하고 올린다
git add -A && git commit -m "제출: 트리플에이치 금융상품 Agent" && git push
```

🔴 **지금 작업 저장소에서 remote 만 바꾸지 않는다.** 오답기록과 라운드 로그까지 전부 따라간다.
🔴 README 가 없으면 추출기가 **경고만 내고 넘어간다.** 만든 뒤 다시 뽑아야 한다.
