> 규칙이 아니라 **코드 가드**로 넣었다. 📄 는 확률, 🔧 는 확정이다.

### 절반만 고친 가드가 왜 제일 무서운가

`ensure_etf_mgmt_canon()` 은 `SELECT` 절만 정본으로 고치고 `GROUP BY` 를 놓쳤다.
**SQLite 는 이런 문장을 오류 없이 실행한다.** 그래서 결과가 나오고, 그럴듯해 보이고, 조용히 틀린다.

| 미래에셋자산운용 | 188 | **230** |
| 한화자산운용 | 81 | **85** |

그룹 수 자체가 **84 vs 28** 이었다. **가드는 전부 고치거나 아예 안 넣는 편이 낫다.**

## 6. 기록 규칙 — 라운드가 끝나면

1. **§4 에 라운드 절을 추가**하고 문항별 표를 채운다 (지우지 않고 append)
2. 새 결함은 **§2 색인에 번호를 이어서** 추가한다
3. **§3 유형표의 건수와 재발표를 갱신**한다 — 같은 결함이 2회 이상이면 🔴 코드 가드 이관 후보
4. 조치가 📄 규칙이면 어느 yaml 인지, 🔧 코드면 어느 함수인지 **파일 단위로 적는다**
5. 정답표는 **로컬 DB 재현으로 먼저 계산**하고 나서 서버에 던진다 (서버 호출은 비용이다)
