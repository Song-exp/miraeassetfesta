# 채권 — 전수조사 직전 서버 점검 10문항 (2026-09-05)

목적: 전수조사에 들어가기 전에 **아직 한 번도 안 던져 본 부류**를 골라 약한 자리를 먼저 드러낸다.
선정 기준 — ① `채권_오답기록_2026-09-03.md` 총괄표 76건에 없는 축 ② 개별 사고가 아니라 **부류**로 재발할 자리
③ 채점이 가능한 자리(정답을 DB 로 실측해 적어 둠).

정답 키는 전부 `data/financial_products.db` 실측(2026-09-05). 서버 판정은 기준일 2026-08-24·구매가능 모수를 쓰므로
숫자가 몇 종목 다를 수 있다 — **모수를 밝혔는지**가 채점 대상이지 숫자 일치가 아니다.

읽는 법: **보려는 것** = 질문의 목적 · **정답 형태** = 이렇게 나오면 ✅ · **터지면** = 결함의 겉모습.

---

## 1. "한국전력공사 채권은 이자를 몇 개월마다 줘?"

- **보려는 것**: 데이터에 **없는 축(이자 지급 주기·지급일)** 을 있는 컬럼(`bd_intp_tcd` 이표/할인/복리/단리)으로 메꾸는가.
  `absent_properties` 에 선언된 건 등급이력·수익률이력·업종 셋뿐이고 **이 축은 선언이 없다**.
- **정답 형태**: "지급 주기는 수록되어 있지 않습니다" + 있는 것으로 대체(한전 채권 403행 전부 **이표채** = 만기 전 이자 지급 방식,
  표면금리 `srfc_irt`·만기일은 조회 가능) + 되묻기 대안.
- **터지면**: "이표채이므로 **3개월마다**(또는 6개월) 지급됩니다" — 채권 상식으로 지어낸다. 데이터에 없는 숫자가 답에 박힌다.
- **부류**: 미선언 부재 축. 같은 부류 형제 → "이자 지급일이 언제야", "다음 이자 언제 들어와".

## 2. "100만원으로 살 수 있는 채권 추천해줘"

- **보려는 것**: **최소 투자금액·매수 단위 축이 데이터에 없다**. `buyable_quantity` 는 이름이 "매수가능수량"이지만 값은 액면금액(원)이고
  주최 공지로 **사용 금지** 컬럼이다(yaml `answer_policy`).
- **정답 형태**: 최소 투자금액은 미수록임을 밝히고, 답할 수 있는 것으로 전환 — 판매 조건이 있는 **634행(장외 LOT)** 의
  매매단가(`trade_price` 5,570~10,759원 = 액면 10,000원 기준 단가)를 모수와 함께 안내.
- **터지면**: `buyable_quantity` 로 "100만원이면 N주" 를 계산하거나, "채권은 보통 최소 1,000만원부터" 같은 상식을 답한다.
- **부류**: 사용 금지 컬럼 + 없는 축. 형제 → "얼마부터 살 수 있어", "1억이면 몇 종목 살 수 있어".

## 3. "장내에서 실제 거래된 가격이 가장 비싼 채권 알려줘"

- **보려는 것**: `exg_close_price` 의 **0 = 거래 없음**(장내 17,746행 중 16,476행). 0값을 정렬 축으로 쓰면 순위가 통째로 무너지는
  ETF 총보수·추적오차와 **같은 부류**의 채권판. 기준일(`exg_close_price_base_dt`)도 종목마다 다르다.
- **정답 형태**: 유효 **1,270행 기준**임을 밝히고 상위 — 메리츠캐피탈 256-4 **10,135원(기준일 08-21)** · 에코프로26-1 10,119.5원(08-21) ·
  한국캐피탈542-1 10,100원(**08-14** — 기준일이 다르다). 0인 행은 "거래 없음" 으로.
- **터지면**: 0원짜리가 "가장 싼 채권" 으로 올라오거나, 모수(1,270)·기준일을 안 밝히고 전체 장내 순위인 양 말한다.
- **부류**: 위장 결측 정렬축. 형제 → "장내에서 제일 싸게 거래된 채권", "어제 종가 알려줘".

## 4. "장내 채권이랑 장외 채권 중에 어디가 수익률이 더 높아?"

- **보려는 것**: `query_rules.시장집계금지` — `pd_exg_mkt` 단독 group-by 금지(구성 효과). 실제로 평균을 내면
  **장외 8.59% vs 장내 4.13%** 라는 그럴듯한 숫자가 나오는데, 이건 시장의 차이가 아니라 **담긴 종목이 다르기 때문**이다
  (장내 = 등급 있는 우량채 위주, 장외 = 고수익 유동화·사모 포함).
- **정답 형태**: 두 시장을 그대로 비교하지 않는다 — 같은 종목이 양쪽에 실려 있고(1,077종목) 구성이 달라 평균 비교가 성립하지 않음을 밝힌 뒤,
  등급·종류를 맞춘 비교나 판매 조건(634행) 기준으로 전환.
- **터지면**: "장외가 4.5%p 높습니다" 로 단정한다. **숫자가 전부 실측값이라 환각 검사에 안 걸린다** — 가장 위험한 형태.
- **부류**: 금지된 집계 축. 형제 → "장외 채권이 더 위험해?", "시장별 평균 등급".

## 5. "엔에이치농협캐피탈269-1 신용등급이랑 평가단가 알려줘"

- **보려는 것**: **행 = 종목이 아니다**(`row_grain`). 이 종목은 장내·장외 두 행이고 값이 다르다 —
  장내 AA-·9,990.98원 / 장외 **등급 NULL**·10,000.12원. yaml 은 한 줄로 뭉개지 말고 **두 줄 병기**하라고 못 박았다(평가가 상이 8종목).
- **정답 형태**: 두 줄 병기 + 장외 가격에 "액면가 수준" 단서 + 장외 등급은 "미수록"(≠ 등급 없음/저품질).
- **터지면**: 한 줄만 답하거나(어느 행인지 안 밝힘), 장외 결측을 장내 값으로 채워 "AA-, 10,000원" 처럼 **섞은 한 줄**을 만든다.
- **부류**: 행 낟알·중복행. 형제 → "한국자산관리공사채권제163회 등급 알려줘"(같은 8종목 중 하나).

## 6. "종목명에 (사) 붙은 채권은 사모야? 몇 개나 돼?"

- **보려는 것**: `(사)` = **사회적채권(Social) ESG 라벨**이지 사모가 아니다. yaml 이 두 번(컬럼 trap · `공모사모판정`) 경고한 함정.
- **정답 형태**: 두 축을 분리해서 — 종목명 `(사)` 는 사회적채권 라벨 **약 1,974종목**(99.8%가 공모), 사모는 `bd_ofr_tcd` 기준
  **2,007종목**으로 서로 다른 축임을 밝힌다. (녹)=녹색·(지)=지속가능도 함께.
- **터지면**: "(사) = 사모, N종목" 이라고 답한다. 채권 도메인 지식이 없으면 채점자도 속는 오답이다.
- **부류**: 이름 표기 오독. 형제 → "사모채권 알려줘", "ESG 채권 몇 개야".

## 7. "단기 채권 위주로 추천해줘"

- **보려는 것**: `maturityClass` **경계값이 미확정(workshop)** 이다. 기본값(잔존 <1년 단기 / 1~5년 중기 / >5년 장기)을 쓰되
  **경계를 답변에 밝히는가**. 영구채(266행, `mat_dt` = 콜 개시일)를 어떻게 다루는가.
- **정답 형태**: "잔존만기 1년 미만 기준(해당 6,392종목)" 처럼 경계와 모수를 밝히고 목록 + 정렬 축 한 마디 + 고위험 제외 고지.
- **터지면**: 경계를 안 밝히거나 "3년 이내" 처럼 임의 경계를 쓴다. 듀레이션(`dur`)을 잔존만기로 바꿔치기한다(8/31 사고 부류의 재발).
- **부류**: 미확정 경계 + 되묻지 말고 기본값 밝히기. 형제 → "장기채 추천", "중기 회사채".

## 8. "금리가 오르면 어떤 채권이 유리해?" ← **게이트 오폭 검사**

- **보려는 것**: 최근 붙인 `hasYieldHistory` 게이트가 **정당한 개념 질문을 막지 않는가**(yaml 어휘가 `오르(?!면)` 으로 조건형을 비켜 가게 설계됨).
  거절 게이트를 여러 개 얹은 뒤라 반드시 한 번은 확인해야 하는 반대 방향 문항이다.
- **정답 형태**: 거절하지 않는다 — 금리 상승 국면엔 듀레이션이 짧은 채권·변동금리채(`bd_inrt_tcd`='변동금리' **830종목**)가 상대적으로 유리하다는
  개념 설명 + 데이터로 조회 가능한 조건(짧은 잔존·변동금리)으로 연결. 향후 금리 **전망**은 하지 않는다.
- **터지면**: "금리 변동 이력은 수록되어 있지 않습니다" 로 끊는다(오폭). 반대로 금리 전망을 예측한다.
- **부류**: 게이트 오폭. 형제 → "금리 내리면 장기채가 좋아?", "요즘 금리 어때"(이건 정당한 거절).

## 9. "물가연동국채 뭐 있어?"

- **보려는 것**: 컬럼이 없고 **종목명·소분류로만** 식별되는 소수 모수(소분류 '물가채' 6행 = 5종목). `구조표시` 규칙의 '물가연동' 열이 걸리는가.
- **정답 형태**: 5종목을 그대로 나열 + "소수(5종목)" 임을 밝힘 + 물가연동은 원금이 물가에 연동된다는 한 줄. 표면금리가 낮게 보이는 이유도 데이터 범위 안에서만.
- **터지면**: 0행 → "데이터에 없습니다"(실재하는데 없다고 답하는 사실 왜곡, 9/5 우주항공 사고와 같은 형태) 또는 이름에 '물가' 없는 종목까지 섞는다.
- **부류**: 소수 모수 + 이름 파싱 축. 형제 → "분리채권(STRIPS) 알려줘"(209종목, 21행은 `bd_knd` 결측).

## 10. "세금 떼고 나면 얼마나 남아? 수익률 높은 순으로 알려줘"

- **보려는 것**: `clarify.다의어.수익률` — 세후 수익률은 **투자 주체별로 컬럼이 다르다**(개인 `after_tax_yield` / 법인 `corp_after_tax_yield` /
  종합과세 `pref_tax_yield`), 그리고 이 13개 판매 컬럼은 **634행에만** 있다. 세율·산식 서술은 금지(검수 C).
- **정답 형태**: 개인 세후 기본값 + **"개인 기준(15.4%)" 명시** + "판매 조건이 수록된 634건 기준" 모수 + 법인·종합과세는 다른 값임을 한 줄 안내.
  값만 인용하고 세금 계산 산식은 쓰지 않는다.
- **터지면**: 세전 `applied_yield`(전 21,882행)로 답하면서 "세후" 라 말한다. 모수를 안 밝힌다. 세법·세율 계산을 지어낸다.
- **부류**: 다의어 + 좁은 모수. 형제 → "법인으로 사면 수익률 얼마야", "예금이랑 비교하면"(`depo_equiv_yield_154`).
