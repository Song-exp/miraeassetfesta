# 채권 파트 필요 파일 명세서 — yaml 부터 챗봇까지 (2026-09-04)

> **이 문서가 답하는 것** — 채권 도메인 하나를 처음부터 다시 만들어 **챗봇이 채권 질문에 답하기까지** 어떤 파일이 필요하고, 무엇을 손으로 쓰고, 무엇이 생성물이며, 어떤 순서로 돌리는가.
> **이 문서가 답하지 않는 것** — *왜 그렇게 판정했는가*(→ `18_구축과정_채권_초안.md`) · *원리*(→ `docs/HOW_IT_WORKS.md`) · *수치의 원천*(→ `docs/proposal/NUMBERS.md`) · *작업 연혁*(→ `docs/BONDS_MASTER.md`).

## 0. 읽는 법 — 범례

| 표기 | 뜻 | 다루는 법 |
| :-: | :-- | :-- |
| ✍️ | **손으로 쓴 원천** — 사람의 판단이 들어간 것 | 고칠 곳은 여기뿐이다 |
| ⚙️ | **생성물** — 스크립트가 만든다 | 손으로 고치면 다음 빌드에 사라진다 |
| 🔧 | **도구** — 실행되는 코드 | |
| 📄 | **문서** — 읽는 것 | 산출물이 아니라 근거 |
| 🔒 | **공용** — 채권 소유가 아님 | 리드·타 도메인과 함께 고친다 |

세 원칙이 이 목록 전체를 지배한다.

1. **판정은 yaml 에 적는다** — 코드에 도메인 상수를 적지 않는다.
2. **ttl 과 KG 는 손으로 쓰지 않는다** — `build_ontology.py` 의 출력이다.
3. **숫자는 한 곳에서만 가져온다** — `NUMBERS.md` · `채권_회신` 의 재실측 줄.

### 2.5 ⑤ 런타임 코드 — 8단계와 파일의 대응

| 단계 | 파일 | 채권이 여기서 쓰는 것 |
| :-: | :-- | :-- |
| ① Normalize | `src/runtime/pipeline.py` | 따옴표 · 공백 |
| ② Route | `src/runtime/router.py` | 머리명사 판정 + `kg_alias` raw + `synonyms` — "채권형 ETF" 를 채권으로 끌고 가지 않는다 |
| ③ Ground | `pipeline._ground` + `loader` | `kg_node` / `kg_alias` / `kg_closure` — `AA-` → `CG_AAm` → `crd_grd='AA-'`, 발행사 통칭, 등급 밴드 후손 전개 |
| ④ Gate | `src/runtime/gate.py` | `gate_constants`(외화채) · `absent_properties`(등급 이력 · 투자지역 · 기초지수) · 등급 표준표 4분기 · `range_by_table` 0~6 · `DATA_CUTOFF` = `BUYABLE_CUTOFF` = **2026-08-24** |
| ⑤ Plan 🤖 | `src/hcx/planner.py` · `client.py` · `loader.planner_context` | 근거문서 = KG 매핑 + `query_rules` + `clarify` + `_refusal` + 값 사전 + 스키마 (**18,101자**) |
| ⑥ Guard | `src/runtime/guard.py` + `pipeline.py` 결정층 함수 | SELECT 단일문 · 테이블 화이트리스트 · LIMIT · **WHERE 리터럴 ↔ 값 사전 대조** · 재생성 1회(예산 12초) |
| ⑦ Execute | `pipeline`(read-only 커넥션) | ≤ 30행 |
| ⑧ Answer | `planner.compose_answer` + `loader.answer_context` | `answer_rules` 21 · 목록 · 집계는 **기계 조립**(HCX 0회) |

`src/runtime/loader.py` 는 이 전부의 입구다 — enums/shared yaml + `kg_*` 테이블 + 등급 표준표를 **한 번 읽어 캐시**하고, `planner_context` / `answer_context` / `clarify_context` / `refusal_context` 를 조립한다. **규칙을 해석하지 않고 yaml 문자열을 그대로 싣는다** — 규칙의 원천은 yaml 이다.

채권 규칙이 지목하는 **결정층 함수(대표)**

| 함수 | 무엇을 고치나 |
| :-- | :-- |
| `expand_grade_comparison` | `crd_grd='AA-'` → `TRIM(crd_grd) IN ('AAA','AA+','AA0','AA-')` 서열 확장 |
| `ensure_reco_exclusions` | 고위험 제외를 `COALESCE` + AND 확정식으로 (= `NOT(a OR b)` 의 NULL 삼킴 방지) |
| `ensure_kind_filter` · `ensure_ktb_kind` · `normalize_mcls_values` | 종류 확정식 주입 — 통안'증권' · 국고채 분리채권 |
| `ensure_cutoff_inclusive` · `normalize_date_literals` · `align_maturity_year` · `raise_maturity_floor` | 기준일 8/24 `>=` · 무따옴표 날짜(`2029-08-22` = SQLite 뺄셈 1999) 교정 |
| `ensure_sort_axis` · `ensure_tie_break` · `ensure_maturity_sort` | **정렬축**(표면금리 질의가 수익률로 정렬되는 것) · 동률 2차 키 |
| `ensure_trimmed_compare` | 고정폭 패딩 컬럼 TRIM 비교 |
| `ensure_credit_backstop` · `ensure_coupon_type_split` · `strip_fabricated_risk_filter` · `ensure_top_safety` | 신용보강 · 이자유형 분리 · 없는 필터 조작 방지 · 안전 상위 |
| `risk_ambiguity_clarify` · `price_ambiguity_clarify` | 다의어 되묻기(HCX 0회 · 0.3초) |
| `ensure_grade_select_column` · `ensure_risk_name_column` · `ensure_top_row_cited` | 근거 컬럼 노출 · 1위 행 누락 방지 |

> 결정층 가드 수는 **22** — 세는 법과 이력은 `채권_회신_2026-09-03.md` §25(재실측 2026-09-04 15:45). 위 표는 대표만 추린 것이다.

**규칙 ↔ 가드 사이의 이관 장치** — "규칙에 적었는데 HCX 가 무시한다" 를 코드로 옮기는 절차가 따로 있다. 채권 규칙은 아직 슬롯을 쓰지 않지만(`evidence` 로 가드 이름만 지목), 이관을 결정하면 이 파일들이 필요하다.

## 5. 증상 → 고칠 파일 (역인덱스)

| 증상 | 고칠 곳 | 반영 |
| :-- | :-- | :-- |

## 6. 명령 순서 (붙여넣기용)

```bash
# 0) 환경
pip install -r requirements.txt
cp .env.example .env            # HYPERCLOVA_API_KEY 채우기

# 1) DB (배포본이 바뀔 때만)
python scripts/build_db.py

# 2) yaml 을 고쳤다면 — 중복 키 먼저, 그다음 생성물 재생성
python scripts/check_yaml_dupkeys.py         # 같은 키 두 번 = 판정이 조용히 사라진다
python scripts/gen_shared_auto.py            # shared 발행사 노드
python scripts/gen_value_vocab.py            # 값 사전
python scripts/build_ontology.py --check     # 검증만 (V1~V7)
python scripts/build_ontology.py             # ttl + kg_* 재생성

# 3) 채권 주장 전수 재현 (불일치면 exit 1)
python scripts/audit_bonds_claims.py
python scripts/audit_bonds_rules.py

# 4) 회귀
python -m pytest -q
python eval/run_gold_check.py

# 5) 로컬 챗봇
python -m src.chat -q "현재 판매 가능한 원화채권 중 AA- 이상 종목 알려줘"
uvicorn src.api.main:app --reload            # GET /answer?question_id=Q-001&question=...

# 6) 배포 (enums yaml 만 고쳤을 때)
bash deploy/deploy.sh --yaml-only
# shared/코드북/ttl/빌더를 고쳤으면: python scripts/build_ontology.py && bash deploy/deploy.sh

# 7) 배포 후 서버 실측
python eval/run_server_check.py --base https://<서버> --token <CHAT_TOKEN>
python eval/probe_server.py eval/probe_bond_recheck.txt -o eval/probe_bond_recheck.json
```
