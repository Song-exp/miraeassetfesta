## 1. 채권 온톨로지 — 원고가 말하는 것

### 1.1 데이터에서 판정으로 (§A → 2.1.1)

**결측 판정 프로세스(§A.1·§A.2, 09-03 밤 추가).** "비어 있다" 의 뜻을 일곱 유형으로 갈라 판정했고, 2차 데이터에서 같은 조건식을 다시 돌려 유형표를 갱신했다(④ 복구 가능은 컬럼이 사라져 소멸). 대표 사례는 신용등급 결측 — 국공채 2,840행 중 2,840 이 결측이라 "해당없음", 나머지 1,180 은 "미수록". 같은 NULL 이 두 뜻으로 갈리므로 답변 문장이 달라야 하고, 이것이 yaml `missing_reason`·`answer_policy` 한 줄로 선언되어 런타임에 그대로 나온다. 기각한 대안(대치 · "확인 불가" 일괄 · 조용한 제외)과 그 근거 실측도 적었다.

### 1.4 흐름도 · 현업 · 부록 (§C~§E)

- **§C 흐름도(→ 4.1)** — 공식 예시 #1 "판매 가능한 원화채권 중 AA- 이상". 09-03 서버 `think_trace` 10단 원문, 2.4초, 30행. Route → Ground(`CG_AAm`·`Curr_KRW`) → Gate 통과 → Plan → **[Guard] 등급 서열 확장** → 검증 → 기계 조립(HCX 0회). 표 형식은 리드의 4.4 와 같은 7단 세로표.

### 1.5 전수 대조 — yaml 에는 있으나 원고 §A 에 없는 결측·판정 (09-03 밤)

§A 본문 표 6줄이 판정의 전부인지 확인하기 위해 세 방향으로 대조했다.

| :-- | :-- | :-- |

**yaml 에조차 없는 것 — 1건, 영향 미미.** 등급값은 있는데 부여일이 없는 행 **3**(반대 경우 16행은 yaml 에 있음). `crd_grd_dt.answer_policy` 에 "등급은 있으나 부여일 미수록 3행은 일자 병기 생략" 한 줄이면 닫힌다.
