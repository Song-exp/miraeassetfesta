## 1. 이 작업이 뭔가 (쉬운 말)

**데이터를 고치는 게 아니라, 데이터에 붙은 "설명서"를 점검하는 일이다.**

```
주최가 준 데이터(DB)   ← 못 고침. 있는 그대로.
      +
우리가 쓴 설명서(yaml) ← 이걸 점검 중
      ↓
챗봇이 설명서를 읽고 SQL 을 짜서 고객에게 답함
```

약병(데이터)과 라벨(설명서) 관계다. 약은 못 바꾸지만 라벨이 틀리면 약사(챗봇)가 잘못 안내한다.

팀이 **"설명서와 실제 데이터가 어긋나는 곳" 408군데**를 자동으로 뽑아 놨고(A~E 문서), 그중 **채권 몫 17건**을 사람이 하나씩 판정한다.

판정 기준은 딱 하나: **"챗봇이 지금 상태로 고객 질문에 답하면 맞는 답이 나오나?"**

### 🔴 절대 어기면 안 되는 3가지

1. **한 번에 한 카테고리** — 문서 전체를 한 번에 채우면 검토가 안 됨
2. **승인 전에 문서·yaml 을 절대 고치지 않는다** (반려 사유 1순위)
3. **`python scripts/gen_review_workbook.py` 재실행 금지** — 채운 판정이 전부 날아감

### 반려당하는 행동

| 이렇게 하면 | 이렇게 반려됨 |

| 자동 수집 근거 숫자를 그대로 인용만 함 | "직접 SQL 돌려서 재현해" |
