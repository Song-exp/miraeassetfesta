# 📒 코드북 (codebooks) — 코드 ↔ 이름 매핑

> NEXT_STEPS §5.4 형식 준수: `code,name,short_name,source,as_of`
> **목적:** 상품군마다 운용사 표기가 달라 조인이 안 되는 문제 해결.
> - 펀드: `or_co_xtn_itt_cd = '00080012'` (숫자코드)
> - 국내ETF: `cu_fund_mgmt_co = '미래에셋'` (약칭)
> - 해외ETF: `cu_fund_mgmt_co = 'Mirae Asset…'` (영문)
> → 코드북이 셋을 이어줘야 *"미래에셋 운용 ETF+펀드"* 같은 교차질의가 됩니다.

> ℹ️ **두 종류의 코드북이 있습니다:**
> - **A. 펀드 기준 5종**(운용사·수탁사·펀드분류·거래소·환율) — NEXT_STEPS §4.2 지시. 코드가 펀드 테이블에만 있어 펀드 중심.
> - **B. ETF 전용 3종**(섹터코드·지역·자산군) — ETF·해외ETF에만 있는 코드/표기. **국내ETF↔해외ETF 교차질의**에 필수. → §7

## 1. `asset_manager.csv` — 운용사 코드 (37개) ✅

| 항목 | 내용 |
| :--- | :--- |
| 행 수 | **37개 운용사** (자산운용사) |
| 코드 | 금융투자협회 회원사 8자리 코드 (예: `00040010` = 삼성자산운용) |
| 커버리지 | 펀드 95,619행 중 매핑분이 **대부분** (미래에셋 24,374 · 삼성 8,932 · KB 6,126 …) |
| as_of | 2026-07-11 |

### 유도 방법 (재현 가능)

1. `public_funds.or_co_xtn_itt_cd` 는 `40010.0` (REAL) 로 오염 저장 → **8자리 0패딩 복원**
   (`40010.0 → 00040010`, NEXT_STEPS §5.4 지적대로 단사 복원 가능).
2. 펀드명(`itm_nm`) 접두어를 **알려진 운용사 약칭과 역매칭** → 코드↔약칭↔정식명 확정.
3. 코드가 여럿이면 **최빈 코드** 채택 (계열 분리사는 별도 처리: 삼성 vs 삼성액티브).

### 🔍 재검증 (유명 케이스 역대조, 2026-08)

**코드↔약칭은 데이터로 검증됨. 단, 정식 회사명은 표준지식 확장(추정).**

| 검증 항목 | 결과 |
| :--- | :--- |
| 순도(코드 펀드가 라벨 약칭으로 시작하는 비율) | **34/37이 95~100%** — 매핑 견고 |
| `00080008 = 미래에셋` | ✅ 순도 99.6% (24,472펀드) |
| 리드 예시 `00080012 = 미래에셋` | ⚠️ **데이터에 0건** — 리드 §5.4는 예시값, 실제는 `00080008` |
| `00080135 = 삼성액티브` vs `00040010 = 삼성` | ✅ 삼성액티브 리터럴 32펀드 전부 `00080135` / `00040010`은 삼성 패시브·글로벌 |

> ⚠️ **다중코드 운용사:** 키움(+`00040013`), 현대(+`00080041`,`00080157`), 삼성(+`00080135`)은
> 계열 별도법인이라 금투협 코드가 여러 개. 코드북은 **대표코드**만 수록 →
> 완전한 JOIN 시 계열코드 포함 필요.
> ⚠️ **`name`(정식 회사명)은 표준지식 기반 확장** — `code`·`short_name`은 데이터 검증, 정식명은 금투협 표기와 대조 권장.

펀드 코드는 67개인데 37개만 약칭 매핑됨. 나머지 ~30개는 소형·해산사 또는
약칭 사전 미등록분. **주요 운용사는 37개로 커버**되므로 우선순위 낮음.

> 📮 (a)(b) 는 금융투자협회 회원사 조회(https://www.kofia.or.kr) 로 보완 예정.

## 7. 🟢 ETF 전용 코드북 3종 (형 목록에 없던 것) ✅

> 펀드 기준 5종엔 없지만 **ETF/해외ETF에만 있는 코드·표기**. 전부 **데이터 교차검증**으로 확정.

### 7.1 `etf_sector.csv` — 국내ETF 섹터코드 (`pd_sect_cd`)

`pd_sect_nm`(이름) **100% 결측** → 코드만 있고 뜻 불명이던 것. `pd_grp_no`+상품명 교차로 해독:

| code | 뜻 | 건수 |
| :--- | :--- | ---: |
| `2` | 일반 ETF | 1,126 |
| `3` | 일반 ETN | 406 |
| `8` | 단일종목(레버리지) ETF | 16 |
| `9` | 단일종목(레버리지) ETN | 2 |
| `4` | 특수구조 ETN (금현물 Auto-KO) | 1 |
| `(null)` | 미분류 | 183 |

> 규칙: **2·8=ETF / 3·4·9=ETN**, **8·9=단일종목**. → "일반ETF만"·"단일종목 제외" 질의에 사용.

### 7.2 `region_map.csv` — 투자지역 국내한글 ↔ 해외영문

국내 `미국` ↔ 해외 `United States of America`. **매핑 없으면 "미국 투자 ETF"가 국내만 나옴.**
국내 11종(한글, 대분류) ↔ 해외 59종(영문, 세분) = **1:N**.

> ⚠️ 경계 판단 필요: 홍콩·대만(중국?아시아?), `남미/북미`는 국내가 형제 2개를 한 칸에 묶음.

### 7.3 `asset_type_map.csv` — 자산군 국내한글 ↔ 해외영문

주식=Equity 등 5종은 **1:1 깔끔**. 단 🔴 **비대칭 3종:**
국내 `통화`·`부동산`·`기타` ↔ 해외는 이를 **`Alternatives`(1,800건)로 뭉뚱그림** → 정확 매핑 불가.

> NEXT_STEPS ④ "Alternatives 국내 대응 없음" 지적과 일치. 교차질의 시 이 3종은 주의.
